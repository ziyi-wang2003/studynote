# LeetCode 189. 轮转数组

## 1. 题目描述
给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**示例 1：**
> **输入**：nums = [1,2,3,4,5,6,7], k = 3
> **输出**：[5,6,7,1,2,3,4]
> **解释**：
> 向右轮转 1 步: [7,1,2,3,4,5,6]
> 向右轮转 2 步: [6,7,1,2,3,4,5]
> 向右轮转 3 步: [5,6,7,1,2,3,4]

**示例 2：**
> **输入**：nums = [-1,-100,3,99], k = 2
> **输出**：[3,99,-1,-100]

---

## 2. 题目分析

### 核心思想：数组反转（三步反转法）
虽然可以使用额外的数组来辅助移动，但面试中通常要求原地（In-place）修改。最优雅的解法是利用**数学对称性**进行三次反转。

1.  **预处理**：如果 $k$ 大于数组长度 $n$，轮转 $k$ 次等同于轮转 $k \pmod n$ 次。
2.  **反转逻辑**：
    * **第一步**：反转整个数组。此时，原本在末尾的 $k$ 个元素移动到了数组前端，但顺序是反的。
    * **第二步**：反转前 $k$ 个元素。恢复这 $k$ 个元素的原始相对顺序。
    * **第三步**：反转剩余的 $n-k$ 个元素。恢复剩余部分的原始相对顺序。

## 3. Python 代码实现

```python
from typing import List

def rotate(nums: List[int], k: int) -> None:
    """
    不要返回任何内容，而是原地修改 nums。
    """
    n = len(nums)
    # 1. 预处理 k，防止 k 超过数组长度
    k %= n
    
    # 定义辅助函数：反转数组指定范围 [left, right] 的元素
    def reverse(left: int, right: int) -> None:
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
            
    # 2. 三步反转法
    # 第一步：翻转整个数组
    # [1, 2, 3, 4, 5, 6, 7] -> [7, 6, 5, 4, 3, 2, 1]
    reverse(0, n - 1)
    
    # 第二步：翻转前 k 个元素
    # [7, 6, 5, 4, 3, 2, 1] -> [5, 6, 7, 4, 3, 2, 1]
    reverse(0, k - 1)
    
    # 第三步：翻转剩余的 n-k 个元素
    # [5, 6, 7, 4, 3, 2, 1] -> [5, 6, 7, 1, 2, 3, 4]
    reverse(k, n - 1)
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 虽然进行了三次反转，但每个元素最多被访问两次，总时间复杂度与 $n$ 成正比。 |
| **空间复杂度** | $O(1)$ | 仅使用了常数个额外变量进行索引交换，属于原地修改。 |
