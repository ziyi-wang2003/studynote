# LeetCode 41. 缺失的第一个正数

## 1. 题目描述
给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。
请你实现时间复杂度为 $O(n)$ 并且只使用常数级别额外空间的解决方案。

**示例：**
> **输入**：nums = [3,4,-1,1]
> **输出**：2
> **解释**：1 在数组中，但 2 缺失了。

---

## 2. 题目分析

### 核心思想：原地哈希（萝卜端进坑里）
既然要求 $O(1)$ 空间，我们把数组本身当成哈希表。
* 理想状态下，数字 `1` 应该在索引 `0`，数字 `2` 应该在索引 `1`……
* 即：数字 `x` 应该放在索引 `x - 1` 的位置上。
* 我们遍历数组，如果发现 `nums[i]` 是一个合法的正整数（在 `1` 到 `n` 之间），且它不在它该在的位置上，就把它交换到属于它的位置。



---

## 3. Python 代码实现（稳健版）

```python
from typing import List

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        
        for i in range(n):
            # while 循环保证交换回来的新数字也能被送到正确的位置
            # 1. 只有在 1~n 范围内的数才处理
            # 2. nums[i] != nums[nums[i]-1] 保证了：
            #    a) 当前数字没在坑里
            #    b) 目标坑位里的数字和当前数字不一样（避免重复值导致死循环）
            while 0 < nums[i] <= n and nums[i] != nums[nums[i]-1]:
                # 关键：手动记录目标索引，规避 Python 赋值顺序陷阱
                target_idx = nums[i] - 1
                nums[i], nums[target_idx] = nums[target_idx], nums[i]

        # 二次遍历：寻找第一个“萝卜”不对的“坑”
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        
        # 如果 1~n 全部对号入座，则缺失的是 n+1
        return n + 1
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 虽然有 `while`，但每次交换都会让一个数字回到正确位置。每个数字最多被交换一次，总时间是线性的。 |
| **空间复杂度** | $O(1)$ | 直接在原数组上操作，没有使用额外的大型数据结构。 |
