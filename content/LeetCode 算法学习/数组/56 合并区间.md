# LeetCode 56. 合并区间

## 1. 题目描述
以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

**示例 1：**
> **输入**：intervals = [[1,3],[2,6],[8,10],[15,18]]
> **输出**：[[1,6],[8,10],[15,18]]
> **解释**：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6]。

**示例 2：**
> **输入**：intervals = [[1,4],[4,5]]
> **输出**：[[1,5]]
> **解释**：区间 [1,4] 和 [4,5] 可被视为重叠区间。

---

## 2. 题目分析

### 核心思想：排序 + 一次遍历
判断两个区间是否重叠的关键在于它们的边界关系。如果我们按照区间的**左端点**进行升序排序，那么合并逻辑就会变得非常简单。

1.  **排序**：首先根据每个区间的 `start` 升序排列。排序后，能够合并的区间一定是连续相邻的。
2.  **合并逻辑**：
    * 使用一个 `merged` 列表存放结果。
    * 遍历排序后的区间：
        * 如果 `merged` 为空，或者当前区间的左端点 `start` **大于** `merged` 最后一个区间的右端点 `end`，说明不重叠，直接放入 `merged`。
        * 否则（当前区间左端点 $\le$ `merged` 最后一个区间的右端点），说明有重叠。我们需要更新 `merged` 最后一个区间的右端点，取两者的最大值：`max(merged[-1][1], current_interval[1])`。



---

## 3. Python 代码实现

```python
from typing import List

def merge(intervals: List[List[int]]) -> List[List[int]]:
    # 1. 按照区间的起始位置进行升序排序
    # 这样可以保证如果两个区间重叠，它们在数组中一定是相邻的
    intervals.sort(key=lambda x: x[0])

    merged = []
    for interval in intervals:
        # 如果结果数组为空，或者当前区间的起始位置大于结果数组中最后的一个区间的结束位置
        # 则说明这两个区间不重叠，直接将当前区间加入结果数组中
        if not merged or merged[-1][1] < interval[0]:
            merged.append(interval)
        else:
            # 否则，说明当前区间与结果数组中的最后一个区间重叠
            # 我们需要合并它们，即更新结果数组中最后一个区间的结束位置
            # 取当前区间结束位置和原结束位置的最大值
            merged[-1][1] = max(merged[-1][1], interval[1])

    return merged
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n \log n)$ | 其中 $n$ 为区间的数量。主要的开销在于对区间进行排序，而随后的线性遍历只需要 $O(n)$。 |
| **空间复杂度** | $O(\log n)$ 或 $O(n)$ | 忽略存储答案的空间，这取决于排序算法所使用的辅助栈空间。在 Python 中，`sort` (Timsort) 的空间复杂度通常为 $O(n)$。 |
