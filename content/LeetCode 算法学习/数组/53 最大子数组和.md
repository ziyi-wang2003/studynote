# LeetCode 53. 最大子数组和

## 1. 题目描述
给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组** 是数组中的一个连续部分。

**示例 1：**
> **输入**：nums = [-2,1,-3,4,-1,2,1,-5,4]
> **输出**：6
> **解释**：连续子数组 [4,-1,2,1] 的和最大，为 6。

**示例 2：**
> **输入**：nums = [5,4,-1,7,8]
> **输出**：23

---

## 2. 题目分析

### 核心思想：动态规划 (Kadane 算法)
这道题的核心在于决策：对于当前元素 `nums[i]`，它是加入前面的子数组能获得更大的和，还是自立门户（以自己作为新子数组的开始）更好？

1.  **状态定义**：
    设 $f(i)$ 为以第 $i$ 个元素结尾的连续子数组的最大和。

2.  **转移方程**：
    对于 $f(i)$，有两种选择：
    * 将 `nums[i]` 加入到以 $i-1$ 结尾的最大子数组中：$f(i-1) + nums[i]$
    * `nums[i]` 单独作为新子数组的起点：$nums[i]$
    
    由此得出方程：
    $$f(i) = \max(f(i-1) + nums[i], nums[i])$$
    即：如果 $f(i-1) > 0$，则对当前值有贡献，保留；否则舍弃 $f(i-1)$。

3.  **空间优化**：
    由于 $f(i)$ 只与 $f(i-1)$ 有关，我们不需要数组来记录所有状态，只需一个变量 `pre` 来记录前一个位置的最大子数组和，再用一个变量 `max_ans` 记录全局最大值。



---

## 3. Python 代码实现

```python
from typing import List

def maxSubArray(nums: List[int]) -> int:
    if not nums:
        return 0
    
    # pre 记录以当前元素结尾的最大子数组和（相当于 dp[i-1]）
    pre = 0
    # max_ans 记录全局出现过的最大子数组和，初始化为第一个元素
    max_ans = nums[0]
    
    for x in nums:
        # 核心决策：是加上前面的增量，还是从当前位置重新开始
        # 如果 pre > 0，则 pre + x 肯定比 x 大
        pre = max(pre + x, x)
        
        # 更新全局最大值
        max_ans = max(max_ans, pre)
        
    return max_ans
```
