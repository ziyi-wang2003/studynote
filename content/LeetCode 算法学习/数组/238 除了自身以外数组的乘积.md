# LeetCode 238. 除自身以外数组的乘积

## 1. 题目描述
给你一个整数数组 `nums`，返回每个元素 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

**注意：** 题目要求不能使用除法，且必须在 $O(n)$ 时间复杂度内完成。

**示例 1：**
> **输入**：nums = [1,2,3,4]
> **输出**：[24,12,8,6]

**示例 2：**
> **输入**：nums = [-1,1,0,-3,3]
> **输出**：[0,0,9,0,0]

---

## 2. 题目分析

### 核心思想：前缀积 + 后缀积
由于不能使用除法，我们可以将 `answer[i]` 拆解为：
$$\text{answer}[i] = (\text{i 左侧所有元素的乘积}) \times (\text{i 右侧所有元素的乘积})$$

1.  **前缀积**：从左向右遍历，计算每个位置左侧所有元素的累积。
2.  **后缀积**：从右向左遍历，计算每个位置右侧所有元素的累积。

### 空间优化方案：
我们可以只用一个输出数组 `res`。
* 第一步：先将 `res[i]` 存储为 `nums[i]` 左侧所有元素的乘积。
* 第二步：使用一个临时变量 `R` 代表右侧元素的累积。从右向左遍历数组，每次将当前的 `res[i]` 乘以 `R`，并同步更新 `R`（乘以 `nums[i]`）。



---

## 3. Python 代码实现

```python
from typing import List

def productExceptSelf(nums: List[int]) -> List[int]:
    length = len(nums)
    # 初始化输出数组，res[i] 表示索引 i 左侧所有元素的乘积
    res = [1] * length
    
    # 1. 计算前缀积：res[i] 为 i 左侧所有元素的乘积
    # 对于索引 0，左侧没有元素，所以 res[0] = 1
    for i in range(1, length):
        res[i] = res[i - 1] * nums[i - 1]
        
    # 2. 计算后缀积并同时更新结果
    # R 为当前索引右侧所有元素的累乘积
    R = 1
    # 从右向左遍历
    for i in reversed(range(length)):
        # 此时的 res[i] 是左侧积，乘以 R（右侧积）即为除自身外的乘积
        res[i] = res[i] * R
        # 更新 R，为下一个位置（左边一位）准备右侧积
        R *= nums[i]
        
    return res
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 进行了两次线性遍历（一次向前，一次向后），每次操作均为常数时间。 |
| **空间复杂度** | $O(1)$ | 题目规定输出数组不计入空间复杂度。除了输出数组外，仅使用了常数个变量（如 `R`）。 |
