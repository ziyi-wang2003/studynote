# LeetCode 84. 柱状图中最大的矩形 (Largest Rectangle in Histogram)

## 题目描述
给定 $n$ 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。求在该柱状图中，能够勾勒出来的矩形的最大面积。

### 示例：
**输入：** `heights = [2, 1, 5, 6, 2, 3]`

**输出：** `10`

**解释：**
最大的矩形是在高度为 5 和 6 的柱子处勾勒出来的，面积为 $5 \times 2 = 10$。

---

## 题目分析
本题的目标是找到柱状图中的最大矩形。对于每一个柱子，如果以它的高度作为矩形的高度，那么该矩形的宽度取决于左边和右边第一个比它矮的柱子位置。

### 核心思路：单调栈 (Monotonic Stack)
为了高效找到左右两边第一个更矮的柱子，我们维护一个**单调递增栈**。



1.  **哨兵技巧 (Sentinels)**：在原数组左右两端各添加一个高度为 `0` 的柱子。
    * 左边的 `0` 避免了判空逻辑。
    * 右边的 `0` 强制在遍历结束时弹出栈中所有剩余的柱子，触发面积计算。
2.  **维护单调性**：
    * 当当前柱子高度 **大于** 栈顶柱子高度时，入栈（保持单调递增）。
    * 当当前柱子高度 **小于** 栈顶柱子高度时，说明栈顶柱子的“右边界”已找到。弹出栈顶，此时：
        * **高度 $h$**：弹出的柱子高度。
        * **左边界**：弹出后的新栈顶（它是左边第一个比 $h$ 矮的）。
        * **宽度 $w$**：当前索引 $i - \text{新栈顶索引} - 1$。
        * **面积**：$h \times w$。
3.  **全局最大值**：不断更新记录到的最大面积。

---

## Python 代码实现

```python
from typing import List

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        # 1. 哨兵技巧：前后加 0
        # 前面的 0 保证栈不为空；后面的 0 保证最后能弹出所有元素计算面积
        heights = [0] + heights + [0]
        stack = []  # 存放的是下标
        max_area = 0
        
        for i in range(len(heights)):
            # 2. 当当前高度小于栈顶高度，说明找到了栈顶元素的右边界
            while stack and heights[i] < heights[stack[-1]]:
                # 弹出要计算面积的柱子下标
                mid = stack.pop()
                # 栈顶柱子作为高度
                h = heights[mid]
                # 此时栈顶是 mid 左边第一个矮的，i 是 mid 右边第一个矮的
                # 宽度 = 右下标 - 左下标 - 1
                w = i - stack[-1] - 1
                # 更新最大面积
                max_area = max(max_area, h * w)
            
            # 3. 当前下标入栈，继续保持单调递增
            stack.append(i)
            
        return max_area
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：虽然有嵌套的 `while` 循环，但每个柱子的下标最多入栈一次、出栈一次。

### 空间复杂度
* **$O(n)$**：最坏情况下（柱子高度单调递增），栈的大小会达到 $n+2$。
