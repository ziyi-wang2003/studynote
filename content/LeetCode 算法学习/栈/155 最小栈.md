# LeetCode 155. 最小栈 (Min Stack)

## 题目描述
设计一个支持 `push` ，`pop` ，`top` 操作，并能在 **常数时间内** 检索到最小元素的栈。

* `push(val)`：将元素推入堆栈。
* `pop()`：删除堆栈顶部的元素。
* `top()`：获取堆栈顶部的元素。
* `getMin()`：检索堆栈中的最小元素。

### 示例：
**输入：**
`["MinStack","push","push","push","getMin","pop","top","getMin"]`
`[[],[-2],[0],[-3],[],[],[],[]]`

**输出：**
`[null,null,null,null,-3,null,0,-2]`

**解释：**
```python
minStack = MinStack()
minStack.push(-2)
minStack.push(0)
minStack.push(-3)
minStack.getMin()   # 返回 -3
minStack.pop()
minStack.top()      # 返回 0
minStack.getMin()   # 返回 -2
```

---

## 题目分析
对于栈来说，`push` 和 `pop` 操作本身就是 $O(1)$ 的。挑战在于如何在 $O(1)$ 时间内获取最小值。如果每次调用 `getMin` 都去遍历栈，复杂度会退化为 $O(n)$。

### 核心思路：辅助栈 (Sync Auxiliary Stack)
为了实现常数时间检索，我们需要记录栈在**每一个状态**下的最小值。
1.  **数据栈 (`stack`)**：正常存储所有进入的元素。
2.  **最小栈 (`min_stack`)**：存储与数据栈同步的当前最小值。
    * **入栈时**：将新元素与 `min_stack` 的栈顶（当前最小值）比较，取较小者压入 `min_stack`。
    * **出栈时**：两个栈同时执行 `pop`，保证 `min_stack` 的栈顶始终对应 `stack` 当前状态的最小值。



---

## Python 代码实现

```python
class MinStack:
    def __init__(self):
        # 数据栈：存储所有元素
        self.stack = []
        # 辅助栈：存储每个状态下的最小值
        # 初始放入一个无穷大值，简化 push 时的空栈判断
        self.min_stack = [float('inf')]

    def push(self, val: int) -> None:
        # 1. 正常存入数据栈
        self.stack.append(val)
        # 2. 比较当前值与辅助栈顶值，将新的最小值压入辅助栈
        # 保证辅助栈与数据栈长度同步
        curr_min = self.min_stack[-1]
        self.min_stack.append(min(val, curr_min))

    def pop(self) -> None:
        # 数据栈和辅助栈必须同步弹出
        if self.stack:
            self.stack.pop()
            self.min_stack.pop()

    def top(self) -> int:
        # 返回数据栈的栈顶元素
        return self.stack[-1]

    def getMin(self) -> int:
        # 辅助栈的栈顶永远是当前数据栈中的最小值
        return self.min_stack[-1]
```

## 复杂度分析

### 时间复杂度
* **$O(1)$**：`push`、`pop`、`top`、`getMin` 所有操作均只涉及对栈顶的操作，不随数据规模 $n$ 增加而增加。

### 空间复杂度
* **$O(n)$**：其中 $n$ 为入栈元素的总数。我们需要一个额外的辅助栈来存储对应每个元素的最小值状态，因此空间开销与数据规模成线性关系。
