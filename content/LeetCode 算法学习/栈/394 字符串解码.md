# LeetCode 394. 字符串解码 (Decode String)

## 题目描述
给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

### 示例：
**示例 1：**
* **输入：** `s = "3[a]2[bc]"`
* **输出：** `"aaabcbc"`

**示例 2：**
* **输入：** `s = "3[a2[c]]"`
* **输出：** `"accaccacc"`

---

## 题目分析
本题的核心难点在于 **嵌套结构**（如 `3[a2[c]]`）。处理嵌套括号问题的标准做法是使用 **栈（Stack）**。

### 核心逻辑
我们需要在遍历字符串时，实时维护两个信息：
1.  **当前的倍数 (`multi`)**：用于记录 `[` 前面的数字。
2.  **当前的字符串 (`res`)**：用于记录当前层级待拼接的字母。



**遍历字符时的四种情况：**
* **数字 (`0-9`)**：计算倍数。注意数字可能是多位数（如 `100[a]`），所以需要 `multi = multi * 10 + int(char)`。
* **左括号 (`[`)**：进入嵌套。将当前的 `res` 和 `multi` 同时压入栈中，随后**重置**它们，开始处理括号内部的新字符串。
* **右括号 (`]`)**：结束嵌套。从栈中弹出上一层的字符串 `last_res` 和倍数 `cur_multi`。更新当前 `res = last_res + cur_multi * res`。
* **普通字母**：直接累加到当前字符串 `res` 后面。

---

## Python 代码实现

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []  # 记录格式为: [(prev_res, multi), ...]
        res = ""    # 当前层级的字符串
        multi = 0   # 当前层级的倍数
        
        for c in s:
            if '0' <= c <= '9':
                # 处理多位数字的情况
                multi = multi * 10 + int(c)
            elif c == '[':
                # 遇到左括号，说明进入嵌套，把当前的进度压入栈
                # 栈内存放：(括号前的字符串, 括号前的倍数)
                stack.append((res, multi))
                # 重置当前变量，准备记录括号内的内容
                res, multi = "", 0
            elif c == ']':
                # 遇到右括号，说明当前嵌套结束，开始出栈
                last_res, cur_multi = stack.pop()
                # 拼接结果：上层字符串 + 倍数 * 当前括号内的字符串
                res = last_res + cur_multi * res
            else:
                # 普通字母直接拼接
                res += c
                
        return res
```

## 复杂度分析

### 时间复杂度
* **$O(S)$**：其中 $S$ 是解码后生成的字符串长度。我们需要遍历输入字符串一次，且构造输出结果时涉及到字符的复制。

### 空间复杂度
* **$O(S)$**：最坏情况下，栈的深度以及存储结果的中间变量会达到解码后字符串的长度级别。若嵌套极深，栈空间开销取决于嵌套深度 $D$ 和字符串长度。
