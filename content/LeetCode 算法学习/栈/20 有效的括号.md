# LeetCode 20. 有效的括号 (Valid Parentheses)

## 题目描述
给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

**有效字符串需满足：**
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

---

## 题目分析
本题是 **栈（Stack）** 数据结构的经典应用场景。由于括号必须以“后进先出”的顺序匹配（即最后进入的左括号必须最先被闭合），栈的特性完美契合这一需求。



### 解题思路
1.  **映射匹配关系**：使用字典（哈希表）存储右括号到左括号的映射，方便快速查找匹配。
2.  **遍历字符串**：
    * 遇到 **左括号**：将其推入栈中。
    * 遇到 **右括号**：
        * 检查栈是否为空。若为空，说明没有对应的左括号，直接返回 `False`。
        * 弹出栈顶元素，检查弹出的左括号是否与当前右括号匹配。若不匹配，返回 `False`。
3.  **最终检查**：遍历结束后，如果栈为空，说明所有括号都已成功匹配；若栈内仍有元素，说明有未闭合的左括号，返回 `False`。

---

## Python 代码实现

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 如果字符串长度为奇数，必然无效
        if len(s) % 2 != 0:
            return False
        
        # 构建右括号到左括号的映射字典
        mapping = {
            ")": "(",
            "}": "{",
            "]": "["
        }
        
        # 初始化栈
        stack = []
        
        for char in s:
            # 如果当前字符是右括号
            if char in mapping:
                # 弹出栈顶元素，如果栈为空则给一个占位符 '#'
                top_element = stack.pop() if stack else '#'
                
                # 检查弹出的左括号是否匹配当前右括号的映射
                if mapping[char] != top_element:
                    return False
            else:
                # 如果是左括号，直接入栈
                stack.append(char)
        
        # 最后检查栈是否为空
        return not stack
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：其中 $n$ 是字符串的长度。我们只遍历了字符串一次，每次入栈和出栈的操作时间复杂度均为 $O(1)$。

### 空间复杂度
* **$O(n)$**：在最坏的情况下（例如字符串全部由左括号组成），栈中需要存储所有的字符。哈希表使用的空间为 $O(1)$，因为括号类型是固定的（只有 3 种）。
