# LeetCode 739. 每日温度 (Daily Temperatures)

## 题目描述
给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

### 示例：
**输入：** `temperatures = [73, 74, 75, 71, 69, 72, 76, 73]`

**输出：** `[1, 1, 4, 2, 1, 1, 0, 0]`

**解释：**
* 第 0 天 73°，第 1 天 74° 比它高，差距 1 天。
* 第 2 天 75°，直到第 6 天 76° 才比它高，差距 4 天。
* 第 6 天 76°，后面没有更高的了，填 0。

---

## 题目分析
本题的核心是寻找 **下一个更大元素 (Next Greater Element)** 的位置。暴力法的时间复杂度为 $O(n^2)$，在数据量较大时会超时。最优秀的解法是使用 **单调栈 (Monotonic Stack)**。

### 核心思路
我们需要维护一个 **存储下标** 的栈，并保持栈内元素对应温度是 **单调递减** 的。



1.  **遍历数组**：从左到右遍历温度数组。
2.  **比较与弹出**：
    * 如果当前温度 **大于** 栈顶下标对应的温度，说明我们找到了栈顶元素“更高的一天”。
    * **弹出栈顶**，计算下标差值：`answer[stack_top] = i - stack_top`。
    * 重复此过程，直到栈为空或当前温度不再大于栈顶温度。
3.  **入栈**：将当前下标 `i` 压入栈中，等待后续更高的温度。
4.  **默认值**：结果数组初始化为全 `0`，这样未被弹出的下标（即找不到更高温度的）自动满足题目要求。

## Python 代码实现

```python
from typing import List

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        # 初始化结果数组，默认值为 0
        ans = [0] * n
        # 单调栈，用来存储还没有找到“下一个更高温度”的下标
        stack = []
        
        for i in range(n):
            current_temp = temperatures[i]
            
            # 当栈不为空，且当前温度大于栈顶温度时
            while stack and current_temp > temperatures[stack[-1]]:
                # 弹出栈顶下标
                prev_index = stack.pop()
                # 计算当前天与那天的时间差
                ans[prev_index] = i - prev_index
                
            # 将当前下标入栈
            stack.append(i)
            
        return ans
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：虽然代码中有嵌套的 `while` 循环，但每个下标最多只会被压入栈一次、弹出栈一次。总的操作次数与数组长度 $n$ 成线性关系。

### 空间复杂度
* **$O(n)$**：在最坏情况下（如温度是单调递减的），栈中可能需要存储所有的下标，因此空间复杂度为 $O(n)$。
