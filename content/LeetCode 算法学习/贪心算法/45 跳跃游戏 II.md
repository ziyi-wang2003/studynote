# LeetCode 45. 跳跃游戏 II (Jump Game II)

## 题目描述
给你一个非负整数数组 `nums` ，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。

你的目标是使用 **最少的跳跃次数** 到达数组的最后一个下标。假设你总是可以到达数组的最后一个下标。

### 示例：
**输入：** `nums = [2, 3, 1, 1, 4]`

**输出：** `2`

**解释：** 跳到最后一个下标的最少跳跃次数是 2。从下标 0 跳到下标 1，跳 1 步，然后跳 3 步到达数组的最后一个下标。

---

## 题目分析
这道题是“跳跃游戏 I”的进阶版。在 I 中我们只关心能否到达，而在 II 中我们需要求出**最少**步数。这通常暗示我们可以使用 **贪心算法**。

### 核心思路：维护跳跃边界
我们不需要尝试所有可能的跳跃组合，而是维护当前跳跃步数能覆盖的“最远范围”。



1.  **三个关键变量**：
    * `jumps`：记录跳跃次数。
    * `current_jump_end`：当前这一步跳跃能达到的最远边界。
    * `farthest`：在当前边界范围内，下一步跳跃能达到的最远位置。
2.  **执行逻辑**：
    * 遍历数组（不需要遍历最后一个元素，因为到达最后边界时，步数已经确定）。
    * 在每一个位置 `i`，不断更新 `farthest = max(farthest, i + nums[i])`。
    * 当遍历指针 `i` 到达 `current_jump_end` 时：
        * 说明无论如何必须再跳一次才能继续前进。
        * `jumps += 1`。
        * 将 `current_jump_end` 更新为 `farthest`。
3.  **贪心本质**：每次都在上一步能到达的范围内，寻找能跳得最远的点作为起跳点，从而保证步数最少。

## Python 代码实现

```python
from typing import List

class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0
            
        jumps = 0          # 跳跃次数
        current_jump_end = 0  # 当前步数能达到的最远边界
        farthest = 0       # 下一步能达到的最远边界
        
        # 遍历数组（不访问最后一个元素）
        # 因为一旦到达或超过 n-1，我们就完成了任务
        for i in range(n - 1):
            # 在当前范围内，更新下一步能跳到的最远位置
            farthest = max(farthest, i + nums[i])
            
            # 当到达当前跳跃步数的边界时
            if i == current_jump_end:
                # 必须再跳一次
                jumps += 1
                # 更新当前边界为之前探测到的最远位置
                current_jump_end = farthest
                
                # 如果当前边界已经覆盖了终点，可以直接结束
                if current_jump_end >= n - 1:
                    break
                    
        return jumps
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：只需对数组进行一次线性遍历。

### 空间复杂度
* **$O(1)$**：只使用了常数个辅助变量（`jumps`, `current_jump_end`, `farthest`）。
