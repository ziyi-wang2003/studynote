# LeetCode 763. 划分字母区间 (Partition Labels)

## 题目描述
给你一个字符串 `s` 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。

注意，划分结果需要按顺序连接，使得结果刚好与原字符串相等。返回一个表示每个字符串片段的长度的列表。

### 示例：
**输入：** `s = "ababcbacadefegdehijhklij"`

**输出：** `[9, 7, 8]`

**解释：**
划分结果为 `"ababcbaca"`、`"defegde"`、`"hijhklij"`。
每个字母最多出现在一个片段中。
像 `"ababcbacadefegde"`、`"hijhklij"` 这样的划分是错误的，因为划分的片段数不是最多的。

---

## 题目分析
本题的目标是“尽可能多”地划分区间，且保证每个字母只能出现在其中一个区间内。这意味着，**如果一个字母出现在某个区间，那么该字母最后一次出现的位置也必须在这个区间内。**

### 核心思路：贪心算法 + 哈希表记录最后位置
我们可以通过维护当前区间的“最远边界”来决定在哪里进行切割。



1.  **预处理**：先遍历一遍字符串，使用哈希表（或长度为 26 的数组）记录每个字符在字符串中最后一次出现的下标。
2.  **确定边界**：再次遍历字符串，维护两个变量：
    * `start`：当前区间的起始下标。
    * `end`：当前区间内所有字符能到达的最远位置。
3.  **动态更新**：对于当前字符，找到它最后出现的位置 `last_pos`，更新 `end = max(end, last_pos)`。这保证了当前区间包含了所有已出现字符的全部实例。
4.  **切割区间**：当遍历下标 `i` 到达 `end` 时，说明当前区间内的所有字符都不会出现在后面了，此时可以进行切割。
    * 区间长度为 `end - start + 1`。
    * 更新 `start = i + 1` 进入下一个区间的寻找。

---

## Python 代码实现

```python
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # 1. 记录每个字符最后出现的位置
        last_occurrence = {char: i for i, char in enumerate(s)}
        
        result = []
        start = 0  # 当前区间的起点
        end = 0    # 当前区间的终点（最远边界）
        
        # 2. 遍历字符串，确定划分边界
        for i, char in enumerate(s):
            # 更新当前区间所有字符中，最远的那个最后出现位置
            end = max(end, last_occurrence[char])
            
            # 如果当前下标已经到达了最远边界，说明可以切分了
            if i == end:
                # 记录当前区间的长度
                result.append(end - start + 1)
                # 更新下一个区间的起始位置
                start = i + 1
                
        return result
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：其中 $n$ 为字符串的长度。我们对字符串进行了两次遍历：第一次记录字符最后位置，第二次确定划分区间。

### 空间复杂度
* **$O(1)$**：虽然使用了哈希表存储位置，但由于字符集仅包含小写英文字母，空间占用最多为 26 个条目，属于常数空间。不计入返回结果所需的空间。
