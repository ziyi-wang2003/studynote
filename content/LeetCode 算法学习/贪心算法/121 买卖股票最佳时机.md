# LeetCode 121. 买卖股票的最佳时机 (Best Time to Buy and Sell Stock)

## 题目描述
给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

### 示例：
**输入：** `[7, 1, 5, 3, 6, 4]`

**输出：** `5`

**解释：**
在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = $6 - 1 = 5$ 。注意利润不能是 $7 - 1 = 6$ , 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

---

## 题目分析
本题的核心是在历史最低点买入，在之后的最高点卖出。

### 核心思路：一次遍历（贪心/动态规划）
我们不需要两层循环暴力计算，只需要在遍历过程中维护两个变量：
1.  **最低价格 (`min_price`)**：遍历到目前为止遇到的最低股价。
2.  **最大利润 (`max_profit`)**：如果今天卖出（即 `今日价格 - 历史最低价格`），能获得的最大收益。



**执行逻辑：**
* 如果当前价格比 `min_price` 还小，更新 `min_price`（寻找更廉价的买入点）。
* 否则，计算当前价格卖出的收益 `price - min_price`，并尝试更新 `max_profit`。

---

## Python 代码实现

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 初始化最低价格为无穷大，最大利润为 0
        min_price = float('inf')
        max_profit = 0
        
        for price in prices:
            # 1. 尝试更新历史最低价格
            if price < min_price:
                min_price = price
            # 2. 如果当前价格卖出更有利可图，则更新最大利润
            elif price - min_price > max_profit:
                max_profit = price - min_price
                
        return max_profit
```

---

## 复杂度分析

### 时间复杂度
* **$O(n)$**：其中 $n$ 为数组 `prices` 的长度。我们只需要遍历一遍数组。

### 空间复杂度
* **$O(1)$**：只使用了两个常数级别的变量（`min_price` 和 `max_profit`）来存储状态。
