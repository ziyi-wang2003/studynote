# LeetCode 2. 两数相加 (Add Two Numbers)

### 1. 题目描述
给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。请你将两个数相加，并以相同形式返回一个表示和的链表。

**示例 1：**
> **输入：** l1 = [2,4,3], l2 = [5,6,4]  
> **输出：** [7,0,8]  
> **解释：** 342 + 465 = 807.

**示例 2：**
> **输入：** l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]  
> **输出：** [8,9,9,9,0,0,0,1]

---

### 2. 题目分析
由于链表是 **逆序** 存储的（即头节点是个位，第二个节点是十位...），这非常符合我们进行加法运算的习惯：从低位开始相加，处理进位，然后移动到高位。

**核心逻辑：模拟加法竖式运算**
1.  **进位处理**：设置变量 `carry` 存储进位。每一位的结果为 `(v1 + v2 + carry) % 10`，新的进位为 `(v1 + v2 + carry) // 10`。
2.  **指针同步**：同时遍历两个链表。如果一个链表较短，则缺失的位补 0。
3.  **循环条件**：只要 `l1` 不为空，或 `l2` 不为空，或进位 `carry` 不为 0，循环就必须继续。
4.  **哨兵节点**：使用 `dummy` 节点简化结果链表的构造过程。



---

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        # 创建哨兵节点作为结果链表的起点
        dummy = ListNode(0)
        curr = dummy
        # 记录进位
        carry = 0
        
        # 只要 l1, l2 没走完，或者最后还有一个进位没处理
        while l1 or l2 or carry:
            # 获取当前位的值，如果链表已空则补 0
            v1 = l1.val if l1 else 0
            v2 = l2.val if l2 else 0
            
            # 计算总和与进位
            total = v1 + v2 + carry
            carry = total // 10      # 更新进位
            val = total % 10         # 当前位存储的数字
            
            # 建立新节点并移动指针
            curr.next = ListNode(val)
            curr = curr.next
            
            # 移动原链表指针
            if l1: l1 = l1.next
            if l2: l2 = l2.next
            
        return dummy.next
```

---

### 4. 复杂度分析

* **时间复杂度：$O(\max(M, N))$**
    * 其中 $M$ 和 $N$ 分别为两个链表的长度。算法需要遍历两个链表中较长的那个，循环次数等于 $\max(M, N)$ 或 $\max(M, N) + 1$（最后一位有进位时）。
* **空间复杂度：$O(1)$**
    * 注意：如果不算存储结果链表所需的空间，我们只使用了常数个额外变量（`dummy`, `curr`, `carry`）。但在 LeetCode 评价标准中，通常认为结果链表需要 $O(\max(M, N))$ 的空间。
