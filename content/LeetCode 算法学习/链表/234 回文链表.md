# LeetCode 234. 回文链表 (Palindrome Linked List)

### 1. 题目描述
给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

**示例 1：**
> **输入：** head = [1,2,2,1]  
> **输出：** true

**示例 2：**
> **输入：** head = [1,2]  
> **输出：** false

---

### 2. 题目分析
本题要求在 **$O(n)$ 时间复杂度** 和 **$O(1)$ 空间复杂度** 下完成，这意味着我们不能使用额外的数组来存储节点值。

**最优策略：快慢指针 + 局部反转**
1.  **寻找中点**：使用快慢指针（`fast` 走两步，`slow` 走一步）。当 `fast` 到达末尾时，`slow` 恰好指向链表的中点（对于偶数长度，指向后半部分的起始；对于奇数长度，指向正中间）。
2.  **反转后半部分**：从 `slow` 开始，将链表的后半部分原地反转。
3.  **双指针比较**：一个指针从头节点 `head` 开始，另一个指针从反转后的后半部分头节点 `pre` 开始，逐个比较节点值。
4.  **结论**：如果所有对应值都相等，则为回文。



---

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        # 1. 使用快慢指针找到链表中点
        fast, slow = head, head
        while fast and fast.next:
            fast = fast.next.next  # 每次走两步
            slow = slow.next       # 每次走一步
        
        # 2. 反转后半部分链表 (从 slow 开始)
        pre = None
        curr = slow
        while curr:
            nxt = curr.next        # 暂存后继节点
            curr.next = pre        # 指针反转
            pre = curr             # 移动 pre
            curr = nxt             # 移动 curr
        
        # 3. 比较前半部分和反转后的后半部分
        # 注意：这里 head 长度可能比 pre 长（奇数情况），但以 pre 为准即可
        while pre:
            if head.val != pre.val:
                return False       # 值不相等，不是回文
            pre = pre.next
            head = head.next
        
        return True
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 找中点耗时 $O(N/2)$，反转后半部分耗时 $O(N/2)$，比较耗时 $O(N/2)$。总时间复杂度为 $O(N)$。
* **空间复杂度：$O(1)$**
    * 仅使用了 `fast`, `slow`, `pre`, `curr`, `nxt` 等有限的指针变量，是在原链表上进行的操作，没有使用额外的数据结构。
