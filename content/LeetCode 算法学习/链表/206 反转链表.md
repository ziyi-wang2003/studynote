# LeetCode 206. 反转链表 (Reverse Linked List)

### 1. 题目描述
给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

**示例 1：**
> **输入：** head = [1,2,3,4,5]  
> **输出：** [5,4,3,2,1]

**示例 2：**
> **输入：** head = [1,2]  
> **输出：** [2,1]

---

### 2. 题目分析
本题采用的是 **迭代法（双指针/三指针）**。核心思想是在遍历原链表的过程中，逐个改变节点的 `next` 指针方向，使其指向前一个节点。

**算法逻辑：**
1.  **初始化**：
    * `pre` 指针：指向当前节点的前一个节点，初始为 `None`（反转后，原头节点将变成尾节点，指向 `None`）。
    * `curr` 指针：指向当前正在处理的节点，初始为 `head`。
2.  **循环迭代**：
    * 首先用 `nxt` 暂时保存当前节点的下一个节点（否则断开连接后会找不到后面的节点）。
    * 将当前节点的 `next` 指向 `pre`（实现反转）。
    * 将 `pre` 和 `curr` 分别向后移动一位，准备处理下一个节点。
3.  **返回结果**：当 `curr` 为空时，`pre` 正好指向原链表的最后一个节点，即新链表的头节点。



---

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # pre 指向前一个节点，初始为 None
        pre = None
        # curr 指向当前正在处理的节点
        curr = head
        # nxt 用于暂存当前节点的后继节点
        nxt = None

        while curr:
            # 1. 暂存：记录当前节点的下一个节点，防止链表断裂
            nxt = curr.next
            
            # 2. 反转：将当前节点的指针指向它的前驱节点
            curr.next = pre
            
            # 3. 推进：pre 移动到当前位置，curr 移动到下一个位置
            pre = curr
            curr = nxt
        
        # 最终 pre 指向反转后的新头节点
        return pre
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是链表的长度。算法需要遍历链表一次，每个节点的操作都是常数时间。
* **空间复杂度：$O(1)$**
    * 仅使用了 `pre`, `curr`, `nxt` 三个辅助指针变量，不依赖链表的长度。
