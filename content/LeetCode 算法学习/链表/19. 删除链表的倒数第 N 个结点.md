# LeetCode 19. 删除链表的倒数第 N 个结点 (Remove Nth Node From End of List)

### 1. 题目描述
给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**
> **输入：** head = [1,2,3,4,5], n = 2  
> **输出：** [1,2,3,5]  
> **解释：** 倒数第二个节点是 4，删除后链表变为 [1,2,3,5]。

**示例 2：**
> **输入：** head = [1], n = 1  
> **输出：** []

---

### 2. 题目分析
本题最直观的解法是先遍历一遍获取长度，再遍历第二遍进行删除。但为了实现**一次遍历**完成任务，最佳方案是使用 **快慢指针 (Fast & Slow Pointers)**。

**核心逻辑：**
1.  **哨兵节点 (Dummy Node)**：创建一个 `dummy` 节点指向 `head`。这是处理边界情况（如删除头节点）的万能钥匙。
2.  **拉开间距**：让 `fast` 指针先走 `n + 1` 步。此时，`fast` 与 `slow` 之间恰好隔了 `n` 个节点。
3.  **同步移动**：同时移动 `fast` 和 `slow`，直到 `fast` 指向 `None`（到达尾部）。
4.  **精确定位**：当 `fast` 走到尽头时，`slow` 恰好停在**被删除节点的前驱节点**位置。
5.  **执行删除**：通过 `slow.next = slow.next.next` 跳过待删除节点。



---

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        # 基础边界检查：如果链表为空，直接返回 None
        if not head:
            return None
        
        # 引入哨兵节点，处理删除头节点的情况
        dummy = ListNode(0)
        dummy.next = head

        # 初始化快慢指针都指向哨兵节点
        slow, fast = dummy, dummy

        # 1. 快指针先走 n + 1 步
        # 这样当快指针走到末尾(None)时，慢指针正好在倒数第 n 个节点的前一个位置
        for i in range(n + 1):
            fast = fast.next
        
        # 2. 快慢指针同步向后移动
        while fast:
            slow = slow.next
            fast = fast.next
        
        # 3. 此时 slow.next 就是要删除的倒数第 n 个节点
        # 将 slow 的 next 指向被删除节点的下一个节点
        slow.next = slow.next.next

        # 返回真实的头节点
        return dummy.next
```

---

### 4. 复杂度分析

* **时间复杂度：$O(L)$**
    * 其中 $L$ 是链表的长度。算法仅对链表进行了一次完整的遍历。
* **空间复杂度：$O(1)$**
    * 只使用了 `dummy`, `slow`, `fast` 等常数个额外指针空间，与链表长度无关。
