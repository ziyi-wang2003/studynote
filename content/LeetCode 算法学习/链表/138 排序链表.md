# LeetCode 148. 排序链表 (Sort List)

## 1. 题目描述
给你链表的头结点 `head` ，请将其按 **升序** 排列并返回 **排序后的链表** 。

**进阶：** 你可以在 $O(n \log n)$ 时间复杂度和常数级空间复杂度下解决这个问题吗？

---

### 示例 1：

* **输入**：`head = [4,2,1,3]`
* **输出**：`[1,2,3,4]`

---

## 2. 核心分析：归并排序 (Merge Sort)
要在 $O(n \log n)$ 时间内排序，**归并排序**是链表排序的最佳选择。由于链表不支持随机访问（不支持快速排序的索引操作），归并排序的“拆分”和“合并”特性非常适合链表。

### 算法步骤：
1.  **找到中点 (Split)**：利用**快慢指针 (Fast & Slow pointers)**。快指针走两步，慢指针走一步，当快指针到达末尾时，慢指针即指向中点。
    
2.  **递归拆分 (Conquer)**：将链表从中点断开，递归地对左半部分和右半部分进行排序，直到每个子链表只剩一个节点。
3.  **合并有序链表 (Merge)**：类似于“合并两个有序链表”的问题，将两个有序的子链表合并成一个完整的有序链表。

---

## 3. Python 代码实现 (递归版)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 递归终止条件：链表为空或只有一个节点，无需排序
        if not head or not head.next:
            return head
        
        # 1. 寻找链表中点
        # 使用快慢指针，pre 记录 slow 的前一个位置，用于断开链表
        slow, fast = head, head
        pre = None
        while fast and fast.next:
            pre = slow
            slow = slow.next
            fast = fast.next.next
            
        # 将链表断开为两个独立部分：head -> ... -> pre 和 slow -> ...
        pre.next = None
        
        # 2. 递归排序左右两部分
        left = self.sortList(head)
        right = self.sortList(slow)
        
        # 3. 合并两个有序链表并返回
        return self.merge(left, right)

    def merge(self, l1, l2):
        """合并两个有序链表的辅助函数"""
        dummy = ListNode(0)
        curr = dummy
        
        while l1 and l2:
            if l1.val < l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
            
        # 连接剩余部分
        curr.next = l1 if l1 else l2
        return dummy.next
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n \log n)$ | 归并排序的递归深度为 $\log n$，每一层处理 $n$ 个节点。 |
| **空间复杂度** | $O(\log n)$ | 递归版本需要系统栈空间。若要达到进阶要求的 $O(1)$，需使用迭代版的底向上归并法。 |

---

## 5. 进阶说明：如何达到 $O(1)$ 空间？
要实现 **$O(1)$ 空间复杂度**，需要采用**自底向上 (Bottom-up)** 的迭代归并：
1.  先 1 个 1 个节点归并，合并成长度为 2 的有序段。
2.  再 2 个 2 个归并，合并成长度为 4 的有序段。
3.  循环直到 `step >= 链表总长度`。
这种方式避免了递归栈的开销，但在代码逻辑上比递归版本复杂得多。对于面试，熟练掌握递归版的归并排序是第一优先级。
