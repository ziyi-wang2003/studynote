# LeetCode 25. K 个一组翻转链表 (Reverse Nodes in k-Group)

### 1. 题目描述
给你一个链表，每 `k` 个节点一组进行翻转，请你返回翻转后的链表。`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么最后剩余的节点应当保持原有的顺序。

**注意：** 你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**示例 1：**
> **输入：** head = [1,2,3,4,5], k = 2  
> **输出：** [2,1,4,3,5]

**示例 2：**
> **输入：** head = [1,2,3,4,5], k = 3  
> **输出：** [3,2,1,4,5]

---

### 2. 题目分析
本题是“反转链表”的进阶版，核心在于**分组处理**和**边界连接**。

**核心逻辑：**
1.  **分段确认**：使用 `fast` 指针向前走 `k` 步。如果中途遇到 `None`，说明剩余节点不足 `k` 个，直接跳出并返回。
2.  **切断连接**：记录下这一组的下一个节点 `next_node`，并将当前组的末尾 `fast.next` 置为空，使其成为一个独立的长度为 `k` 的小链表。
3.  **局部反转**：调用反转函数。注意反转后，原先的 `start`（头）变成了 `end`（尾），原先的 `end` 变成了 `start`。
4.  **重新连接**：
    * 将上一组的末尾（或哨兵节点）`slow.next` 指向反转后的新头部。
    * 将反转后的新尾部指向 `next_node`。
5.  **指针重置**：将 `slow` 和 `fast` 都移动到当前组反转后的尾部，准备开始下一组。

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        
        # 辅助函数：反转一个小链表
        def reverse_list(start, end):
            pre = None
            curr = start
            while curr:
                nxt = curr.next
                curr.next = pre
                pre = curr
                curr = nxt
            # 返回反转后的新头 (pre) 和新尾 (start)
            return pre, start
        
        # 哨兵节点，方便处理头部翻转
        dummy = ListNode(0)
        dummy.next = head

        # slow 代表当前待翻转组的前驱节点
        # fast 代表当前待翻转组的末尾节点
        slow, fast = dummy, dummy

        while fast:
            # 1. 尝试找到当前组的第 k 个节点
            for i in range(k):
                fast = fast.next
                if not fast:
                    # 如果剩余节点不足 k 个，直接返回结果
                    return dummy.next
            
            # 2. 记录下一组的起始节点，并断开当前组
            next_node = fast.next
            fast.next = None
            
            # 3. 反转当前组（传入原头和原尾）
            # reversed_start 是这一组反转后的新头，reversed_end 是新尾
            reversed_start, reversed_end = reverse_list(slow.next, fast)
            
            # 4. 将翻转后的部分接回原链表
            slow.next = reversed_start
            reversed_end.next = next_node
            
            # 5. 更新指针，将 slow 和 fast 移到下一组的前驱位置（即当前组的新尾）
            slow = reversed_end
            fast = reversed_end
        
        return dummy.next
```

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * $N$ 为链表长度。虽然有嵌套循环，但每个节点仅被遍历两次（一次用于确定分组，一次用于执行反转），因此是线性复杂度。
* **空间复杂度：$O(1)$**
    * 除了辅助反转时的几个临时指针变量外，没有使用额外的存储空间，符合原地反转的要求。
