# LeetCode 21. 合并两个有序链表 (Merge Two Sorted Lists)

### 1. 题目描述
将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。 

**示例 1：**
> **输入：** l1 = [1,2,4], l2 = [1,3,4]  
> **输出：** [1,1,2,3,4,4]

**示例 2：**
> **输入：** l1 = [], l2 = [0]  
> **输出：** [0]

---

### 2. 题目分析
本题采用 **迭代法**，利用两个指针同步遍历。

**核心逻辑：**
1.  **哨兵节点 (Dummy Node)**：引入一个伪头节点 `dummy`。这样做的好处是无需单独处理新链表头节点为空的逻辑，最后只需返回 `dummy.next`。
2.  **比较与拼接**：
    * 比较 `l1` 和 `l2` 当前节点的值。
    * 将较小值的节点接在 `curr.next` 上，并将对应的 `l1` 或 `l2` 指针后移。
    * 移动 `curr` 指针。
3.  **收尾处理**：当其中一个链表遍历完后，另一个链表可能还有剩余节点。由于原链表是有序的，直接将剩余部分连接到新链表末尾即可。



---

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        # 初始化两个指针分别指向两个链表的头
        l1, l2 = list1, list2
        
        # 创建哨兵节点，方便处理头节点逻辑
        dummy = ListNode()
        # curr 指针用于构建新链表
        curr = dummy

        # 遍历两个链表，直到其中一个为空
        while l1 and l2:
            if l1.val <= l2.val:
                # 如果 l1 的值更小，接上 l1
                curr.next = l1
                l1 = l1.next
            else:
                # 如果 l2 的值更小，接上 l2
                curr.next = l2
                l2 = l2.next
            # 构建完一个节点，curr 向后移动
            curr = curr.next
        
        # 此时最多只有一个链表还有剩余节点
        # 直接将剩余部分拼接到末尾
        curr.next = l1 if l1 else l2

        # 返回哨兵节点的下一个节点，即合并后链表的头
        return dummy.next
```

---

### 4. 复杂度分析

* **时间复杂度：$O(M + N)$**
    * 其中 $M$ 和 $N$ 分别为两个链表的长度。算法需要遍历两个链表的所有节点。
* **空间复杂度：$O(1)$**
    * 仅使用了 `dummy`、`curr`、`l1`、`l2` 等常数个指针变量。注意这里是“拼接”原节点，并没有创建新的节点空间（除了哨兵节点）。
