# LeetCode 23. 合并 K 个升序链表 (分治法实现)

## 1. 题目描述
给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

---

### 示例 1：
* **输入**：`lists = [[1,4,5],[1,3,4],[2,6]]`
* **输出**：`[1,1,2,3,4,4,5,6]`

---

## 2. 核心分析：分治 (Divide and Conquer)
分治法的思路类似于**归并排序**。与其一个一个地累加合并，不如将 $k$ 个链表从中间分成两部分，先合并左半部分，再合并右半部分，最后将这两个结果合并。

### 算法步骤：
1.  **分解 (Divide)**：如果 $k > 1$，将链表数组从中点拆分为左右两组。
2.  **解决 (Conquer)**：递归地对左右两组分别进行合并处理。
3.  **合并 (Combine)**：调用“合并两个有序链表”的算法，将两个递归返回的结果合并成一个。



---

## 3. Python 代码实现

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        if not lists:
            return None
        return self.divide_and_conquer(lists, 0, len(lists) - 1)

    def divide_and_conquer(self, lists, left, right):
        """分治递归函数"""
        # 终止条件：只有一个链表，直接返回
        if left == right:
            return lists[left]
        
        # 计算中点，分左右递归
        mid = (left + right) // 2
        l1 = self.divide_and_conquer(lists, left, mid)
        l2 = self.divide_and_conquer(lists, mid + 1, right)
        
        # 合并两个有序链表
        return self.mergeTwoLists(l1, l2)

    def mergeTwoLists(self, l1, l2):
        """经典的合并两个有序链表辅助函数"""
        dummy = ListNode(0)
        curr = dummy
        
        while l1 and l2:
            if l1.val < l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        
        curr.next = l1 if l1 else l2
        return dummy.next
```

## 4. 复杂度分析

设 $k$ 为链表的数量，$N$ 为所有链表中的节点总数。

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(N \log k)$ | 分治过程形成了深度为 $\log k$ 的二叉树。每一层合并涉及的总节点数为 $N$。 |
| **空间复杂度** | $O(\log k)$ | 递归调用的系统栈深度。相较于堆排序，$O(\log k)$ 略逊于 $O(k)$ 的堆空间，但属于同一数量级。 |

---

## 5. 为什么选择分治法？
* **稳定性**：分治法在处理超大规模数据（如外部排序）时非常自然。
* **并行化潜力**：左侧合并和右侧合并是完全独立的，可以在多核 CPU 上并行处理，这是“逐一合并”或“堆排序”法难以直接实现的优势。
