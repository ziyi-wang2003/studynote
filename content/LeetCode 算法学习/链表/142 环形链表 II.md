# LeetCode 142. 环形链表 II (Linked List Cycle II)

### 1. 题目描述
给定一个链表的头节点  `head` ，返回链表开始入环的第一个节点。 如果链表无环，则返回 `null`。**不允许修改** 链表。

**示例 1：**
> **输入：** head = [3,2,0,-4], pos = 1  
> **输出：** 返回索引为 1 的链表节点  
> **解释：** 链表中有一个环，其尾部连接到第二个节点。

---

### 2. 题目分析
本题是“判断是否有环”的升级版，不仅要判断环的存在，还要找到**环的入口**。这需要用到数学推导。

**核心原理：Floyd 判圈算法 + 阶段性相遇**

1.  **第一阶段：找相交点**
    * 使用快慢指针（`slow` 走 1 步，`fast` 走 2 步）。
    * 若两者相遇，说明有环。设此时 `slow` 走了 $k$ 步，则 `fast` 走了 $2k$ 步。

2.  **第二阶段：找环入口（数学推导）**
    * 设头节点到环入口的距离为 $a$，环入口到相遇点的距离为 $b$，相遇点再走距离 $c$ 回到环入口。
    * 则相遇时：$slow = a + b$， $fast = a + b + n(b + c)$（$n$ 为圈数）。
    * 因为 $fast = 2 \times slow$，推导得出：$a = c + (n-1)(b+c)$。
    * **结论**：从**头节点**出发一个指针，从**相遇点**出发一个指针，两者速度相同，它们最终一定会在**环入口**处相遇。



---

### 3. 代码实现 (Python)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 初始化快慢指针
        slow, fast = head, head

        # 第一阶段：判断是否有环并找到相遇点
        while fast and fast.next:
            slow = slow.next          # 慢指针走一步
            fast = fast.next.next     # 快指针走两步
            
            if slow == fast:
                # 第二阶段：寻找环的入口
                # 将其中一个指针重置到头节点
                fast = head
                # 两个指针以相同的速度（每次一步）移动
                while fast != slow:
                    fast = fast.next
                    slow = slow.next
                # 再次相遇的位置即为环的入口
                return fast

        # 若循环正常结束，说明无环
        return None
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 第一阶段寻找相遇点的时间复杂度为 $O(N)$。
    * 第二阶段寻找入口的时间复杂度也为 $O(N)$。
    * 总体时间复杂度与链表长度呈线性关系。
* **空间复杂度：$O(1)$**
    * 仅使用了 `slow` 和 `fast` 指针，没有使用额外的集合（如 HashSet）来记录访问过的节点。
