# LeetCode 198. 打家劫舍 (House Robber)

## 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是**相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums` ，计算你 **不惊动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

### 示例：
**输入：** `nums = [2, 7, 9, 3, 1]`

**输出：** `12`

**解释：**
偷窃 1 号房屋 (金额 = 2), 3 号房屋 (金额 = 9) 和 5 号房屋 (金额 = 1)。
偷窃到的最高金额 = $2 + 9 + 1 = 12$ 。

---

## 题目分析
这是一个典型的 **动态规划 (Dynamic Programming)** 问题。由于不能抢相邻的房子，每来到一间新房子时，你都面临一个抉择：**抢还是不抢？**

### 核心思路
1.  **状态定义**：设 $dp[i]$ 为前 $i$ 间房屋能偷窃到的最高金额。
2.  **状态转移方程**：
    对于第 $i$ 间房子：
    * **如果不抢**：那么你能拿到的最大钱数就是到第 $i-1$ 间房为止的最大钱数，即 $dp[i] = dp[i-1]$。
    * **如果抢**：那么你一定不能抢第 $i-1$ 间房。你的总钱数就是到第 $i-2$ 间房为止的最大钱数加上当前房间的钱数，即 $dp[i] = dp[i-2] + nums[i]$。
    * **最终选择**：两者取最大值。
    $$dp[i] = \max(dp[i-1], dp[i-2] + nums[i])$$



### 空间优化
由于 $dp[i]$ 仅取决于 $dp[i-1]$ 和 $dp[i-2]$，我们不需要维护整个 $dp$ 数组，只需要用两个变量来滚动记录“前一家”和“前两家”的最大收益即可。

---

## Python 代码实现

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums:
            return 0
        n = len(nums)
        if n == 1:
            return nums[0]
        
        # prev2 相当于 dp[i-2]，初始为第 0 间房
        # prev1 相当于 dp[i-1]，初始为前两间房中较大的那一间
        prev2 = nums[0]
        prev1 = max(nums[0], nums[1])
        
        # 如果只有两间房，直接返回 prev1
        if n == 2:
            return prev1
            
        # 从第 3 间房（下标 2）开始迭代
        for i in range(2, n):
            # 当前最大收益 = max(不抢这家, 抢这家 + 前两家的收益)
            current = max(prev1, prev2 + nums[i])
            # 状态滚动更新
            prev2 = prev1
            prev1 = current
            
        return prev1
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：其中 $n$ 为数组的长度。我们只需要对数组进行一次遍历。

### 空间复杂度
* **$O(1)$**：通过滚动变量优化的方式，我们只使用了常数个额外变量，不再需要 $O(n)$ 的 $dp$ 数组。
