# LeetCode 70. 爬楼梯 (Climbing Stairs)

## 题目描述
假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

### 示例：
**输入：** `n = 3`

**输出：** `3`

**解释：** 有三种方法可以爬到楼顶：
1.  1 阶 + 1 阶 + 1 阶
2.  1 阶 + 2 阶
3.  2 阶 + 1 阶

---

## 题目分析
本题是经典的 **动态规划 (Dynamic Programming)** 入门题目，其本质是 **斐波那契数列**。

### 核心思路
1.  **状态定义**：设 $f(i)$ 为爬到第 $i$ 阶楼梯的方法总数。
2.  **转移方程**：
    * 要到达第 $i$ 阶，最后一步只有两种可能：
        * 从第 $i-1$ 阶跨 1 步上来。
        * 从第 $i-2$ 阶跨 2 步上来。
    * 因此，到达第 $i$ 阶的方法数等于到达前两阶的方法数之和：$f(i) = f(i-1) + f(i-2)$。
3.  **边界条件**：
    * $f(1) = 1$
    * $f(2) = 2$



### 空间优化
由于 $f(i)$ 只与前两个状态有关，我们不需要开辟整个数组，只需使用两个变量滚动记录前两步的结果，将空间复杂度从 $O(n)$ 降低到 $O(1)$。

---

## Python 代码实现

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 边界情况：1阶或2阶直接返回
        if n <= 2:
            return n
        
        # p 表示前两步 (f[i-2])，q 表示前一步 (f[i-1])
        # 初始对应 n=1 和 n=2 的情况
        p, q = 1, 2
        
        # 从第 3 阶开始迭代计算到第 n 阶
        for i in range(3, n + 1):
            # 当前阶数的方法数 = 前两阶之和
            current = p + q
            # 滚动更新：p 变成原来的 q，q 变成当前的 current
            p = q
            q = current
            
        return q
```

---

## 复杂度分析

### 时间复杂度
* **$O(n)$**：需要从 3 遍历到 $n$，执行一次线性循环。

### 空间复杂度
* **$O(1)$**：仅使用了常数个变量（`p`, `q`, `current`）来存储状态，未占用额外数组空间。
