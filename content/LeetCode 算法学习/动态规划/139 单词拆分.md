# LeetCode 139. 单词拆分 (Word Break)

## 题目描述
给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` ，则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

### 示例：
**输入：** `s = "leetcode", wordDict = ["leet", "code"]`

**输出：** `true`

**解释：** 返回 `true` 因为 `"leetcode"` 可以由 `"leet"` 和 `"code"` 拼接成。

**输入：** `s = "applepenapple", wordDict = ["apple", "pen"]`

**输出：** `true`

**解释：** 返回 `true` 因为 `"applepenapple"` 可以由 `"apple" "pen" "apple"` 拼接成。注意你可以重复使用字典中的单词。

---

## 题目分析
本题属于 **字符串类动态规划** 问题。我们需要判断一个长字符串是否能由若干个短字符串（子问题）组成。

### 核心思路：动态规划 (DP)
1.  **状态定义**：设 `dp[i]` 是一个布尔值，表示字符串 `s` 的前 `i` 个字符（即 `s[0:i]`）是否可以被拆分为字典中的单词。
2.  **转移方程**：
    对于 `dp[i]`，我们需要检查在它之前的每一个位置 `j` ($0 \le j < i$)：
    * 如果 `dp[j]` 为 `true`（说明前 `j` 个字符可以拆分）；
    * 并且子串 `s[j:i]` 出现在 `wordDict` 中；
    * 那么 `dp[i]` 就可以被标记为 `true`。
3.  **初始状态**：
    * `dp[0] = True`：空字符串可以被拆分（作为所有后续推导的基石）。
4.  **优化提示**：为了提高查找效率，可以将 `wordDict` 转换为 `set`（哈希集合），使单词查询的时间复杂度从 $O(L)$ 降到 $O(1)$。

## Python 代码实现

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        # 1. 将字典转化为集合，提高查找效率
        word_set = set(wordDict)
        n = len(s)
        
        # 2. 初始化 dp 数组，长度为 n+1
        # dp[i] 表示 s 的前 i 个字符是否可以拆分
        dp = [False] * (n + 1)
        dp[0] = True  # 初始状态，空字符合法
        
        # 3. 遍历字符串的每一个截止位置 i
        for i in range(1, n + 1):
            # 4. 尝试寻找分割点 j，将 s[0:i] 分成 s[0:j] 和 s[j:i]
            for j in range(i):
                # 如果前 j 个字符合法，且剩余的后缀子串在字典中
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    # 只要找到一种拆分方案，dp[i] 就可以成立，跳出内层循环
                    break
                    
        return dp[n]
```

## 复杂度分析

### 时间复杂度
* **$O(n^2 \cdot k)$**：其中 $n$ 为字符串 `s` 的长度。我们需要两层嵌套循环来遍历所有可能的子串（$O(n^2)$），而每次截取子串 `s[j:i]` 以及在集合中查找也涉及 $O(k)$ 的开销（$k$ 为子串平均长度）。

### 空间复杂度
* **$O(n + m)$**：需要 $O(n)$ 的空间存储 `dp` 数组，$O(m)$ 的空间存储字典集合 `word_set`（$m$ 为字典中所有单词的总长度）。
