# LeetCode 152. 乘积最大子数组 (Maximum Product Subarray)

## 题目描述
给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32位** 整数。

### 示例：
**输入：** `nums = [2, 3, -2, 4]`

**输出：** `6`

**解释：** 子数组 `[2, 3]` 有最大乘积 `6`。

**输入：** `nums = [-2, 0, -1]`

**输出：** `0`

**解释：** 结果只能为 `0`，不能是 `2`，因为子数组必须是连续的。

---

## 题目分析
本题是“最大子数组和”的变体。主要难点在于 **负数** 的存在：一个极小的负数乘以另一个负数，会瞬间变成一个极大的正数。

### 核心思路：动态规划 (DP)
由于负号可以使大小反转，我们不仅需要记录当前位置的**最大乘积**，还需要记录**最小乘积**。

1.  **状态定义**：
    * `max_f[i]`：以第 `i` 个元素结尾的乘积最大子数组的乘积。
    * `min_f[i]`：以第 `i` 个元素结尾的乘积最小子数组的乘积。

2.  **转移方程**：
    对于 `nums[i]`，当前的最大值和最小值只可能从以下三个值中产生：
    * 当前数本身：`nums[i]`（重新开始一个子数组）。
    * 前一位置的最大值乘以当前数：`max_f[i-1] * nums[i]`。
    * 前一位置的最小值乘以当前数：`min_f[i-1] * nums[i]`（处理 **负负得正** 的情况）。

    $$max\_f[i] = \max(nums[i], max\_f[i-1] \times nums[i], min\_f[i-1] \times nums[i])$$
    $$min\_f[i] = \min(nums[i], max\_f[i-1] \times nums[i], min\_f[i-1] \times nums[i])$$



3.  **空间优化**：
    由于 `i` 时刻的状态只与 `i-1` 时刻有关，我们不需要数组，只需用两个变量 `cur_max` 和 `cur_min` 滚动更新即可。

## Python 代码实现

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        # 初始化全局最大值，以及当前位置的最大/最小乘积
        res = nums[0]
        cur_max = nums[0]
        cur_min = nums[0]
        
        # 从第二个元素开始遍历
        for i in range(1, len(nums)):
            num = nums[i]
            
            # 在更新 cur_max 之前先保存它的旧值，因为更新 cur_min 时要用到
            temp_max = cur_max
            
            # 三者取其大：本身、最大*本身、最小*本身
            cur_max = max(num, temp_max * num, cur_min * num)
            # 三者取其小
            cur_min = min(num, temp_max * num, cur_min * num)
            
            # 更新全局最大乘积
            res = max(res, cur_max)
            
        return res
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：其中 $n$ 为数组长度。我们只需对数组进行一次线性扫描。

### 空间复杂度
* **$O(1)$**：我们只使用了三个常数级别的辅助变量（`res`, `cur_max`, `cur_min`），没有使用额外的数组空间。
