# LeetCode 416. 分割等和子集 (Partition Equal Subset Sum)

## 题目描述
给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

### 示例：
**示例 1：**
* **输入：** `nums = [1, 5, 11, 5]`
* **输出：** `true`
* **解释：** 数组可以分割成 `[1, 5, 5]` 和 `[11]` 。

**示例 2：**
* **输入：** `nums = [1, 2, 3, 5]`
* **输出：** `false`
* **解释：** 数组不能分割成两个元素和相等的子集。

---

## 题目分析
本题可以转化为典型的 **0/1 背包问题**。

### 问题转换
1.  **求和**：先计算数组总和 `total_sum`。
2.  **奇偶判断**：如果 `total_sum` 是奇数，直接返回 `false`（因为无法平分为两个整数和）。
3.  **确定目标**：如果 `total_sum` 是偶数，我们的目标是从数组中挑选一些数字，使得它们的和恰好等于 `target = total_sum // 2`。

### 核心思路：动态规划 (DP)
1.  **状态定义**：设 `dp[j]` 表示是否可以从数组中挑选若干个数字，使其总和恰好为 `j`。
2.  **状态转移方程**：
    对于数组中的每一个数字 `num`，我们更新所有可能的和 `j`：
    * 如果 `dp[j - num]` 为 `true`，那么 `dp[j]` 也可以为 `true`（表示加上当前的 `num` 就能凑成 `j`）。
    * 方程：`dp[j] = dp[j] or dp[j - num]`
3.  **初始状态**：`dp[0] = true`（不选任何数字，和为 0 是成立的）。
4.  **优化技巧**：为了节省空间，使用一维数组。在遍历金额 `j` 时，必须从 **后往前（从 target 到 num）** 遍历，以防止同一个数字被重复计算多次（0/1 背包的特性）。

## Python 代码实现

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total_sum = sum(nums)
        
        # 1. 如果总和是奇数，不可能分成两个相等的整数集
        if total_sum % 2 != 0:
            return False
        
        target = total_sum // 2
        max_num = max(nums)
        
        # 2. 如果数组中的最大值已经超过了目标和，直接返回 False
        if max_num > target:
            return False
        
        # 3. 初始化 dp 数组，dp[j] 表示是否能凑出总和 j
        dp = [False] * (target + 1)
        dp[0] = True
        
        # 4. 遍历每一个数字
        for num in nums:
            # 5. 倒序遍历每一个可能的和，确保每个数字只使用一次
            # 范围是 [target, num]
            for j in range(target, num - 1, -1):
                # 如果当前的 target 之前已经是 True，或者加上当前 num 后能变 True
                dp[j] = dp[j] or dp[j - num]
            
            # 提前优化：如果已经找到了目标和，直接返回
            if dp[target]:
                return True
                
        return dp[target]
```

## 复杂度分析

### 时间复杂度
* **$O(n \times target)$**：其中 $n$ 为数组长度，$target$ 为数组总和的一半。我们需要遍历数组中的每个数字，并在内层循环中更新 DP 状态。

### 空间复杂度
* **$O(target)$**：我们使用了一个长度为 `target + 1` 的一维 DP 数组来存储中间状态。
