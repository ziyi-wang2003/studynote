# LeetCode 279. 完全平方数 (Perfect Squares)

## 题目描述
给你一个整数 `n` ，返回和为 `n` 的完全平方数的最少数量。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

### 示例：
**输入：** `n = 12`

**输出：** `3` 

**解释：** `12 = 4 + 4 + 4`

**输入：** `n = 13`

**输出：** `2`

**解释：** `13 = 4 + 9`

---

## 题目分析
本题可以看作是 **完全背包问题** 的变体：
* **物品**：所有的完全平方数（$1, 4, 9, 16, \dots$），每个物品可以无限次使用。
* **目标**：凑成总和 `n` 所需的最少物品数量。

### 核心思路：动态规划 (DP)
1.  **状态定义**：设 `dp[i]` 表示和为 `i` 的完全平方数的最少数量。
2.  **状态转移方程**：
    对于每个数字 `i`，我们可以尝试减去一个比 `i` 小的完全平方数 $j^2$（即 $j \times j \le i$），那么：
    $$dp[i] = \min(dp[i], dp[i - j^2] + 1)$$
    这里的 `+1` 表示我们使用了一个完全平方数 $j^2$。
3.  **初始状态**：
    * `dp[0] = 0`：凑成 0 需要 0 个数。
    * 其他 `dp[i]` 初始化为正无穷（或 `i`，因为最坏情况是由 `i` 个 1 组成）。

## Python 代码实现

```python
import math

class Solution:
    def numSquares(self, n: int) -> int:
        # 1. 初始化 dp 数组，dp[i] 表示凑成 i 所需的最少平方数数量
        # 最坏情况下，所有的数都由 1 组成，所以初始化为 i
        dp = [i for i in range(n + 1)]
        
        # 2. 遍历每一个状态 i
        for i in range(1, n + 1):
            # 3. 尝试每一个小于等于 i 的完全平方数 j*j
            j = 1
            while j * j <= i:
                # 状态转移：当前数量与 (减去一个平方数后的数量 + 1) 取最小值
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1
        
        return dp[n]
```

---

## 复杂度分析

### 时间复杂度
* **$O(n\sqrt{n})$**：外层循环遍历 $n$ 次，内层循环尝试完全平方数，次数约为 $\sqrt{n}$ 次。

### 空间复杂度
* **$O(n)$**：需要一个长度为 $n+1$ 的 `dp` 数组来存储中间状态。

## 进阶提示
本题除了动态规划外，还可以利用数学中的 **四平方和定理 (Lagrange's four-square theorem)** 在 $O(\sqrt{n})$ 时间内解决，但面试中通常以动态规划作为标准解法。
