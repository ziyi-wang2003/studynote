# LeetCode 118. 杨辉三角 (Pascal's Triangle)

## 题目描述
给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

### 示例：
**输入：** `numRows = 5`

**输出：** `[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`

---

## 题目分析
杨辉三角具有非常明显的数学规律，适合使用动态规划的思想按行构建。

### 核心规律
1. **首尾固定**：每一行的第一个元素和最后一个元素都是 `1`。
2. **中间求和**：从第三行（下标为 2）开始，中间的每个元素等于它上一行对应下标的元素与上一行前一个下标元素之和。
   * 公式：`res[i][j] = res[i-1][j-1] + res[i-1][j]`



### 构建步骤
1. 初始化一个空列表 `res` 存放所有行。
2. 循环 `i` 从 0 到 `numRows - 1`：
   * 创建一个长度为 `i + 1` 的行，并将首尾设为 `1`。
   * 如果该行长度大于 2，则通过公式填充中间的元素。
   * 将构建好的行加入 `res`。

---

## Python 代码实现

```python
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        res = []
        
        for i in range(numRows):
            # 1. 初始化当前行，长度为 i + 1，初始值全为 1
            row = [1] * (i + 1)
            
            # 2. 填充中间的元素（第一行和第二行不进入此循环）
            # 只有下标在 [1, i-1] 之间的元素需要计算
            for j in range(1, i):
                # 每个数等于它上方两数之和
                row[j] = res[i-1][j-1] + res[i-1][j]
            
            # 3. 将构建好的行添加到结果中
            res.append(row)
            
        return res
```

---

## 复杂度分析

### 时间复杂度
* **$O(numRows^2)$**：杨辉三角中元素的总数约为 $\frac{numRows \times (numRows + 1)}{2}$。我们需要计算每一个元素，因此时间复杂度与行数的平方成正比。

### 空间复杂度
* **$O(numRows^2)$**：不考虑返回值的空间，内部没有使用额外的复杂数据结构。如果算上存储杨辉三角结果的空间，则为 $O(numRows^2)$。
