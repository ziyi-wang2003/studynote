# LeetCode 300. 最长递增子序列 (Longest Increasing Subsequence)

## 题目描述
给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

### 示例：
**输入：** `nums = [10, 9, 2, 5, 3, 7, 101, 18]`

**输出：** `4`

**解释：** 最长递增子序列是 `[2, 3, 7, 101]`，因此长度为 `4` 。

---

## 题目分析
这道题是动态规划（DP）的教科书级案例。我们要从局部最优推导全局最优。

### 解法一：动态规划 (Dynamic Programming)
1.  **状态定义**：设 `dp[i]` 为以 `nums[i]` **结尾**的最长递增子序列的长度。
2.  **状态转移方程**：
    对于每一个 `i`，我们需要遍历它之前的所有位置 `j`（$0 \le j < i$）：
    * 如果 `nums[i] > nums[j]`，说明 `nums[i]` 可以接在以 `nums[j]` 结尾的序列后面。
    * 此时长度变为 `dp[j] + 1`。
    * 我们要在所有可能的 `j` 中取最大值：`dp[i] = max(dp[i], dp[j] + 1)`。
3.  **初始状态**：`dp` 数组所有元素初始化为 `1`（每个元素自身就是一个长度为 1 的子序列）。
4.  **最终结果**：整个 `dp` 数组中的最大值。



### 解法二：贪心 + 二分查找 (Greedy + Binary Search)——进阶优化
* **核心思想**：如果我们想让递增子序列尽可能长，那么序列上升的速度就要尽可能**慢**。也就是说，我们希望序列末尾的数字越小越好。
* **维护一个数组 `tails`**：`tails[k]` 存储长度为 `k+1` 的所有递增子序列中最小的末尾元素。
* **遍历 `nums`**：
    * 如果 `num` 比 `tails` 的最后一个元素还大，直接加在末尾。
    * 否则，用二分查找在 `tails` 中找到第一个大于等于 `num` 的数并替换它。

## Python 代码实现 (动态规划版)

```python
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        # 1. 初始化 dp 数组，每个位置最小长度都是 1
        dp = [1] * len(nums)
        
        # 2. 遍历每一个元素 i
        for i in range(len(nums)):
            # 3. 遍历 i 之前的每一个元素 j
            for j in range(i):
                # 4. 如果当前元素大于前面的元素，说明可以接上去
                if nums[i] > nums[j]:
                    # 更新以 i 结尾的最大长度
                    dp[i] = max(dp[i], dp[j] + 1)
        
        # 5. 返回整个 dp 数组中的最大值，即为全局最长递增子序列长度
        return max(dp)
```

## 复杂度分析 (动态规划版)

### 时间复杂度
* **$O(n^2)$**：其中 $n$ 为数组长度。内部存在两层嵌套循环。

### 空间复杂度
* **$O(n)$**：需要一个长度为 $n$ 的 `dp` 数组。

> **Pro Tip:** 如果使用“贪心 + 二分查找”优化，时间复杂度可以达到 **$O(n \log n)$**。在面试中如果能写出 $O(n^2)$ 是及格，能讲出 $O(n \log n)$ 则是加分项。
