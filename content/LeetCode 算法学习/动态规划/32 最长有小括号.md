# LeetCode 32. 最长有效括号 (Longest Valid Parentheses)

## 题目描述
给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

### 示例：
**示例 1：**
* **输入：** `s = "(()"`
* **输出：** `2`
* **解释：** 最长有效括号子串是 `"()"`。

**示例 2：**
* **输入：** `s = ")()())"`
* **输出：** `4`
* **解释：** 最长有效括号子串是 `"()()"`。

---

## 题目分析
这道题之所以被评为 **Hard**，是因为有效括号不仅要成对，还得 **连续**。处理括号问题的常规思路是栈，但如何记录“最长连续长度”是难点。

我们可以通过 **栈（Stack）** 或 **双向遍历** 来解决。

### 方法一：栈（记录下标法）
我们维护一个栈，里面存放的是 **括号的下标**。

1.  **核心技巧（哨兵）**：在栈底预置一个 `-1`。它代表“上一个不匹配的右括号的下标”。
2.  **遍历字符串**：
    * 遇到 **左括号 `(`**：将其下标入栈。
    * 遇到 **右括号 `)`**：
        * **先弹出栈顶元素**（尝试匹配刚才的左括号）。
        * **如果栈为空**：说明当前这个右括号没有匹配的左括号，它成为了“新的边界”。我们将它的下标压入栈中，作为新的起点（替换之前的哨兵）。
        * **如果栈不为空**：说明匹配成功。当前有效括号的长度 = `当前下标 - 弹出后新的栈顶下标`。
3.  **全局最大值**：在每次匹配成功时，更新结果。



### 方法二：左右双向扫描（空间 $O(1)$）
这个方法不需要栈，思路非常巧妙：
1.  **从左向右扫**：记录 `left` 和 `right` 括号的数量。
    * 如果 `left == right`，更新最大长度 `max_len = 2 * right`。
    * 如果 `right > left`，说明右括号多了，非法，将 `left` 和 `right` 全部清零。
2.  **从右向左扫**：逻辑对称，处理 `left > right` 的情况。
    * 如果 `left == right`，更新最大长度。
    * 如果 `left > right`，清零。

## Python 代码实现（栈方法）

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        # 1. 初始化栈，并放入哨兵 -1
        # 栈内存放的是下标，-1 表示“当前起始匹配点的前一个位置”
        stack = [-1]
        max_len = 0
        
        for i, char in enumerate(s):
            if char == '(':
                # 2. 遇到左括号，将其下标入栈
                stack.append(i)
            else:
                # 3. 遇到右括号，先弹出栈顶（尝试匹配）
                stack.pop()
                
                if not stack:
                    # 4. 如果栈变空了，说明刚才弹出的不是左括号，而是之前的哨兵
                    # 说明这个右括号无法匹配，它成为了新的“分界线”
                    stack.append(i)
                else:
                    # 5. 如果栈不为空，计算当前有效长度
                    # 当前下标减去“现在”的栈顶下标
                    # 比如：s = "()()"，当 i=1 时，pop后剩下-1，长度 1 - (-1) = 2
                    current_len = i - stack[-1]
                    max_len = max(max_len, current_len)
                    
        return max_len
```

## 复杂度分析

### 时间复杂度
* **$O(n)$**：只需遍历一次字符串。

### 空间复杂度
* **$O(n)$**：最坏情况下（全是左括号），栈的深度会达到 $n$。
> **注**：如果使用上述的“双向扫描法”，空间复杂度可以优化到 **$O(1)$**，但需要扫描两遍字符串。

---

## 避坑指南
* **为什么 pop 之后还要检查是否为空？** 因为栈底的那个元素可能是“哨兵”。如果是哨兵被弹出了，说明当前的右括号已经断开了之前的连续性，它必须成为新的哨兵。
* **如果不加 -1 会怎样？** 你会发现计算长度变得极其麻烦，因为无法处理 `"()"` 这种从 0 开始且长度为 2 的情况。`-1` 让逻辑归一化了。
