# LeetCode 322. 零钱兑换 (Coin Change)

## 题目描述
给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

### 示例：
**输入：** `coins = [1, 2, 5], amount = 11`

**输出：** `3` 

**解释：** `11 = 5 + 5 + 1`

**输入：** `coins = [2], amount = 3`

**输出：** `-1`

---

## 题目分析
本题是经典的 **完全背包问题** 变体。由于每种硬币可以无限次使用，且求的是“最少数量”，最适合使用 **动态规划 (Dynamic Programming)**。

### 核心思路
1.  **状态定义**：设 `dp[i]` 为凑齐金额 `i` 所需的最少硬币个数。
2.  **状态转移方程**：
    对于金额 `i`，我们可以尝试使用 `coins` 中的每一种面额 `coin`：
    * 如果 `i - coin >= 0`，说明可以用一枚面额为 `coin` 的硬币加上凑齐金额 `i - coin` 的最少硬币数。
    * 方程：`dp[i] = min(dp[i], dp[i - coin] + 1)`
3.  **初始状态**：
    * `dp[0] = 0`：凑齐金额 0 需要 0 枚硬币。
    * 其余 `dp[i]` 初始化为一个不可能的大值（如 `amount + 1`），用于后续取最小值。

## Python 代码实现

```python
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # 1. 初始化 dp 数组，长度为 amount + 1
        # 初始值设为 amount + 1（因为即使全部用 1 元硬币，最多也就 amount 枚）
        dp = [amount + 1] * (amount + 1)
        
        # 2. 基础状态：凑齐金额 0 需要 0 枚硬币
        dp[0] = 0
        
        # 3. 外层循环遍历金额，内层循环遍历硬币
        for i in range(1, amount + 1):
            for coin in coins:
                # 如果当前硬币面额小于等于当前目标金额
                if i - coin >= 0:
                    # 尝试更新当前金额所需的最小硬币数
                    # dp[i - coin] + 1 表示使用了一枚当前硬币后，剩余金额所需的最小硬币数
                    dp[i] = min(dp[i], dp[i - coin] + 1)
        
        # 4. 如果 dp[amount] 仍然是初始值，说明无法凑齐，返回 -1
        return dp[amount] if dp[amount] != amount + 1 else -1
```

## 复杂度分析

### 时间复杂度
* **$O(S \times n)$**：其中 $S$ 是总金额 `amount`，$n$ 是硬币面额数。我们需要计算 $S$ 个状态，每个状态都要遍历 $n$ 枚硬币。

### 空间复杂度
* **$O(S)$**：需要一个长度为 `amount + 1` 的 `dp` 数组。
