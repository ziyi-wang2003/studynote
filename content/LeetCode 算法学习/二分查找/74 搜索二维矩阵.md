# LeetCode 074. 搜索二维矩阵 (Search a 2D Matrix)

## 1. 题目描述
给你一个 `m x n` 的整数矩阵 `matrix` ，它具有以下特性：
1.  每行中的整数从左到右按升序排列。
2.  每行的第一个整数大于前一行的最后一个整数。

给你一个目标值 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

---

## 2. 方法一：Z 字形查找 (Staircase Search)

### 分析
虽然这道题的特性更适合二分，但“Z 字形查找”是一种更通用的矩阵搜索技巧（也常用于 240 题）。
* **核心逻辑**：从矩阵的**右上角** $(0, n-1)$ 开始搜索。
* **决策过程**：
    * 如果当前值 **等于** `target`：找到了！
    * 如果当前值 **大于** `target`：由于当前值已经是所在列最小的了，说明这一列剩下的数都太大，向**左**移一列。
    * 如果当前值 **小于** `target`：由于当前值已经是所在行最大的了，说明这一行剩下的数都太小，向**下**移一行。



### 代码实现 (Python)
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        
        rows, cols = len(matrix), len(matrix[0])
        # 从右上角开始：第 0 行，最后一列
        r, c = 0, cols - 1
        
        while r < rows and c >= 0:
            if matrix[r][c] == target:
                return True
            elif matrix[r][c] > target:
                # 当前值太大，往左找
                c -= 1
            else:
                # 当前值太小，往下找
                r += 1
        return False
```

### 复杂度分析
* **时间复杂度**：$O(m + n)$。最坏情况下，我们要从右上角走到左下角，总共走过 $m$ 行 $n$ 列。
* **空间复杂度**：$O(1)$。

---

## 3. 方法二：一次二分查找 (Binary Search)

### 分析
利用题目“每一行接在上一行后面仍是有序”的特性，我们可以把二维矩阵看作一个长度为 $m \times n$ 的一维数组。
* **虚拟索引映射**：
    对于一个虚拟的一维索引 `idx`，它在二维矩阵中的位置是：
    * `row = idx // n` (n 为总列数)
    * `col = idx % n`
* **逻辑**：在 $[0, m \times n - 1]$ 的范围内进行标准二分。



### 代码实现 (Python)
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m = len(matrix)
        if m == 0: return False
        n = len(matrix[0])
        
        # 将二维矩阵视作长度为 m*n 的一维有序数组
        left, right = 0, m * n - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            # 核心：将一维索引 mid 还原为二维坐标 (row, col)
            # row = mid // 列数，col = mid % 列数
            mid_val = matrix[mid // n][mid % n]
            
            if mid_val == target:
                return True
            elif mid_val < target:
                left = mid + 1
            else:
                right = mid - 1
                
        return False
```

### 复杂度分析
* **时间复杂度**：$O(\log(m \cdot n))$。这是标准的二分查找时间。
* **空间复杂度**：$O(1)$。

---

## 总结与对比

| 维度 | Z 字形查找 (Staircase) | 二分查找 (Binary Search) |
| :--- | :--- | :--- |
| **效率** | $O(m + n)$ | $O(\log(m \cdot n))$ |
| **适用范围** | 只要行、列各自有序即可 | 必须整个矩阵严格“蛇形”有序 |
| **易错点** | 起点必须是右上角或左下角 | 索引映射公式 `mid // n` 和 `mid % n` |

**Gemini 的建议**：在面试中，如果题目明确说了“下一行首大于上一行尾”，**二分查找**是面试官期待的最优解。如果只说行内有序、列内有序，那就要掏出 **Z 字形查找** 了。
