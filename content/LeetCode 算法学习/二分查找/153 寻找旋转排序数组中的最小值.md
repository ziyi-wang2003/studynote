# LeetCode 153. 寻找旋转排序数组中的最小值 (Find Minimum in Rotated Sorted Array)

## 1. 题目描述
已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组 `nums` 。

* 例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：
    * 若旋转 4 次，则可以得到 `[4,5,6,7,0,1,2]`
    * 若旋转 7 次，则可以得到 `[0,1,2,4,5,6,7]`
* 请你找出并返回数组中的 **最小元素** 。
* **注意**：数组中的所有整数都是 **互不相同** 的。

---

## 2. 题目分析

### 核心思想：二分查找 (Binary Search)
旋转排序数组的一个重要特征是：它由两个**升序子数组**组成。我们的目标就是找到第二个升序子数组的第一个元素（即整个数组的最小值，也叫“拐点”）。



### 为什么选择与右边界 `right` 比较？
在二分查找中，我们取中间值 `nums[mid]` 与右端点 `nums[right]` 进行比较：

1.  **情况一：`nums[mid] > nums[right]`**
    * 说明 `mid` 还在第一个（较大的）升序段中，而最小值一定在 `mid` 的右侧。
    * 因此，收缩左边界：`left = mid + 1`。
2.  **情况二：`nums[mid] < nums[right]`**
    * 说明 `mid` 已经落在了第二个（较小的）升序段中，或者整个数组就是有序的。
    * 此时 `mid` 有可能是最小值，也可能最小值在 `mid` 的左侧。
    * 因此，收缩右边界：`right = mid`（注意不能是 `mid - 1`，因为 `mid` 本身可能是解）。

---

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        """
        通过比较中间值与右边界，不断缩小搜索空间
        """
        left, right = 0, len(nums) - 1
        
        # 这里的循环条件是 left < right
        # 因为我们要找的是具体的一个点，当 left == right 时，搜索结束
        while left < right:
            mid = left + (right - left) // 2
            
            # 如果中间值大于右边界值，说明最小值在右半部分
            if nums[mid] > nums[right]:
                # 最小值肯定不是 mid，所以从 mid + 1 开始
                left = mid + 1
            # 如果中间值小于右边界值，说明最小值在左半部分（包含 mid 自身）
            else:
                # mid 可能是最小值，所以不能排除，right = mid
                right = mid
                
        # 最后 left 和 right 重合，指向的就是最小值
        return nums[left]
```

## 4. 复杂度分析

### 时间复杂度：$O(\log n)$
* 典型的二分查找过程。
* 每一次比较都将搜索范围缩小一半。
* 对于长度为 $n$ 的数组，最多需要 $\log_2 n$ 次检查。

### 空间复杂度：$O(1)$
* 算法仅使用了 `left`, `right`, `mid` 三个辅助变量。
* 不随输入规模 $n$ 的增大而增加额外空间开销。

---

### 💡 常见误区：为什么不用 `nums[mid]` 与 `nums[left]` 比较？
如果数组没有旋转（即完全升序，例如 `[1, 2, 3, 4, 5]`），`nums[mid] > nums[left]` 成立，最小值在左边；但如果数组旋转了（例如 `[3, 4, 5, 1, 2]`），`nums[mid] > nums[left]` 依然成立，最小值却在右边。
**结论**：与左边界比较会产生歧义，而与右边界比较则能唯一确定最小值所在的区间。
