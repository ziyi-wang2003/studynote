# LeetCode 035. 搜索插入位置 (Search Insert Position)

## 1. 题目描述
给定一个排序数组 `nums` 和一个目标值 `target`，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

* **限制条件**：必须使用时间复杂度为 $O(\log n)$ 的算法。
* **数组特性**：数组已按升序排列，且无重复元素。

**示例：**
> **输入**：nums = [1, 3, 5, 6], target = 5
> **输出**：2

> **输入**：nums = [1, 3, 5, 6], target = 2
> **输出**：1

---

## 2. 题目分析

### 核心思想：二分查找
由于数组是有序的，我们可以通过不断将搜索区间减半来快速定位。

1.  **初始化**：设置两个指针，`left` 指向数组起始位置（0），`right` 指向数组末尾位置（len - 1）。
2.  **循环条件**：只要 `left <= right`，就继续搜索。
3.  **中间位置判断**：
    * 计算中间索引 `mid = (left + right) // 2`。
    * 如果 `nums[mid] == target`：直接找到，返回 `mid`。
    * 如果 `nums[mid] < target`：目标在右半部分，更新 `left = mid + 1`。
    * 如果 `nums[mid] > target`：目标在左半部分，更新 `right = mid - 1`。

### 为什么循环结束时返回 `left`？
如果循环结束仍未找到 `target`，此时 `left` 指向的正是第一个**大于** `target` 的元素位置。根据二分查找的逻辑，这个位置就是 `target` 应该插入的地方，因为它保持了数组的有序性。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        """
        使用标准二分查找算法实现 O(log n)
        """
        left, right = 0, len(nums) - 1
        
        while left <= right:
            # 计算中间位置，防止 (left + right) 溢出（Python 虽无此忧，但养成好习惯）
            mid = left + (right - left) // 2
            
            if nums[mid] == target:
                # 找到目标值，直接返回索引
                return mid
            elif nums[mid] < target:
                # 目标值在右侧区间，收缩左边界
                left = mid + 1
            else:
                # 目标值在左侧区间，收缩右边界
                right = mid - 1
        
        # 如果循环结束未找到 target：
        # 此时 right < left，且 left 恰好指向第一个大于 target 的元素位置
        return left
```

## 4. 复杂度分析

### 时间复杂度：$O(\log n)$
* 每次循环都会将搜索区间缩小一半。
* 对于长度为 $n$ 的数组，最多需要进行 $\log_2 n$ 次比较。

### 空间复杂度：$O(1)$
* 算法只使用了常数个额外变量（`left`, `right`, `mid`）。
* 没有使用额外的集合或递归调用栈，因此空间复杂度为 $O(1)$。
