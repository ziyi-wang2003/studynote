# LeetCode 004. 寻找两个正序数组的中位数 (Median of Two Sorted Arrays)

## 1. 题目描述
给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

* **要求**：算法的时间复杂度应该为 $O(\log(m+n))$ 。

**示例：**
> **输入**：nums1 = [1, 3], nums2 = [2]
> **输出**：2.00000
> **解释**：合并数组 = [1, 2, 3] ，中位数 2。

---

## 2. 题目分析

### 核心思想：寻找分割线
中位数的本质是将一个集合划分为两个长度相等的子集，且左半部分的最大值 $\le$ 右半部分的最小值。

1.  **切割数组**：我们在 `nums1` 中切一刀，位置为 `i`；在 `nums2` 中切一刀，位置为 `j`。
    * `nums1` 被分成：`nums1[0...i-1]` (左) | `nums1[i...m-1]` (右)
    * `nums2` 被分成：`nums2[0...j-1]` (左) | `nums2[j...n-1]` (右)
2.  **满足条件**：
    * **数量平衡**：左半部分的总长度等于右半部分（或多 1）。即 `i + j = (m + n + 1) // 2`。
    * **数值有序**：`nums1[i-1] <= nums2[j]` 且 `nums2[j-1] <= nums1[i]`。
3.  **二分搜索**：我们只需要在较短的数组（假设是 `nums1`）中二分查找 `i` 的位置，`j` 会根据公式自动算出。
    * 如果 `nums1[i-1] > nums2[j]`：说明 `i` 太大了，需要向左移。
    * 如果 `nums2[j-1] > nums1[i]`：说明 `i` 太小了，需要向右移。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 确保 nums1 是较短的数组，这样二分的时间复杂度就是 O(log(min(m, n)))
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
            
        m, n = len(nums1), len(nums2)
        # 总左半部分的长度
        total_left = (m + n + 1) // 2
        
        # 在 nums1 的区间 [0, m] 里二分查找切割位置 i
        left, right = 0, m
        
        while left <= right:
            i = left + (right - left) // 2
            j = total_left - i
            
            # 边界处理：如果 i=0，说明 nums1 左边没数；如果 i=m，说明右边没数
            # float('-inf') 和 float('inf') 用于方便边界比较
            nums1_left_max = nums1[i-1] if i > 0 else float('-inf')
            nums1_right_min = nums1[i] if i < m else float('inf')
            nums2_left_max = nums2[j-1] if j > 0 else float('-inf')
            nums2_right_min = nums2[j] if j < n else float('inf')
            
            # 检查是否找到了完美的分割线
            if nums1_left_max <= nums2_right_min and nums2_left_max <= nums1_right_min:
                # 如果是奇数，中位数就是左半部分的最大值
                if (m + n) % 2 == 1:
                    return float(max(nums1_left_max, nums2_left_max))
                # 如果是偶数，中位数是 (左半最大 + 右半最小) / 2
                else:
                    return (max(nums1_left_max, nums2_left_max) + 
                            min(nums1_right_min, nums2_right_min)) / 2.0
            
            elif nums1_left_max > nums2_right_min:
                # nums1 取多了，左移
                right = i - 1
            else:
                # nums1 取少了，右移
                left = i + 1
                
        return 0.0
```

## 4. 复杂度分析

### 时间复杂度：$O(\log(\min(m, n)))$
* 我们只对长度较短的那个数组进行二分查找。
* 每次循环都将搜索区间减半，因此复杂度是对数级别的。
* 这完全符合题目 $O(\log(m+n))$ 的性能要求。

### 空间复杂度：$O(1)$
* 只使用了常数个变量来存储指针和临时数值（`i`, `j`, `left`, `right` 等）。
* 没有开辟额外的数组空间。
