# LeetCode 034. 在排序数组中查找元素的第一个和最后一个位置 (Find First and Last Position of Element in Sorted Array)

## 1. 题目描述
给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

* 如果数组中不存在目标值 `target`，返回 `[-1, -1]`。
* **进阶要求**：算法时间复杂度必须是 $O(\log n)$。

**示例：**
> **输入**：nums = [5, 7, 7, 8, 8, 10], target = 8
> **输出**：[3, 4]

---

## 2. 题目分析

### 核心思想：二分查找 (Binary Search) 寻找边界
因为数组是有序的，且要求 $O(\log n)$，二分查找是唯一的选择。但与标准二分查找不同，这里我们需要在找到 `target` 后继续向左或向右收缩，以锁定**左边界**和**右边界**。

1.  **查找左边界**：
    * 当 `nums[mid] == target` 时，说明找到了目标值，但它不一定是第一个。
    * 我们需要继续在左侧区间查找，即令 `right = mid - 1`。
2.  **查找右边界**：
    * 当 `nums[mid] == target` 时，说明找到了目标值，但它不一定是最后一个。
    * 我们需要继续在右侧区间查找，即令 `left = mid + 1`。



---

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        """
        通过两次二分查找分别锁定左边界和右边界
        """
        def get_boundary(is_left: bool) -> int:
            left, right = 0, len(nums) - 1
            boundary = -1
            
            while left <= right:
                mid = left + (right - left) // 2
                
                if nums[mid] < target:
                    left = mid + 1
                elif nums[mid] > target:
                    right = mid - 1
                else:
                    # 找到了 target，先记录位置
                    boundary = mid
                    # 如果找左边界，向左收缩；找右边界，向右收缩
                    if is_left:
                        right = mid - 1
                    else:
                        left = mid + 1
            return boundary

        # 两次调用二分查找
        left_idx = get_boundary(is_left=True)
        right_idx = get_boundary(is_left=False)
        
        return [left_idx, right_idx]
```

---

## 4. 复杂度分析

### 时间复杂度：$O(\log n)$
* 我们执行了两次独立的二分查找。
* 单次二分查找的时间复杂度为 $O(\log n)$。
* 总时间复杂度为 $2 \times O(\log n) = O(\log n)$。

### 空间复杂度：$O(1)$
* 只使用了常数个额外变量（`left`, `right`, `mid`, `boundary`）。
* 没有使用递归或额外的集合空间。
