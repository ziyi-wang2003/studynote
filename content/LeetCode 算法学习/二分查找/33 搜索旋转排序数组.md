# LeetCode 033. 搜索旋转排序数组 (Search in Rotated Sorted Array)

## 1. 题目描述
整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。在传递给函数之前，`nums` 在预先未知的某个下标 `k` 上进行了 **旋转**（例如，`[0,1,2,4,5,6,7]` 变为 `[4,5,6,7,0,1,2]`）。

给你 **旋转后** 的数组 `nums` 和一个整数 `target` ，如果 `nums` 中存在这个目标值 `target` ，则返回它的下标，否则返回 `-1` 。

* **要求**：设计一个时间复杂度为 $O(\log n)$ 的算法。

---

## 2. 题目分析

### 核心思想：二分查找 (Binary Search)
尽管数组经过了旋转，但它依然具有“局部有序”的性质。二分查找的关键在于：**将数组从中间分开，左右两部分中至少有一部分是升序排列的。**



### 逻辑步骤：
1.  计算中间索引 `mid`。
2.  **判断哪一半是有序的**：
    * 如果 `nums[left] <= nums[mid]`，说明 **左半部分** `[left, mid]` 是有序的。
    * 否则，说明 **右半部分** `[mid, right]` 是有序的。
3.  **在有序部分判断 `target` 的范围**：
    * 如果在左半部分有序，且 `target` 在 `[nums[left], nums[mid]]` 之间，则向左收缩：`right = mid - 1`。否则向右找。
    * 如果在右半部分有序，且 `target` 在 `[nums[mid], nums[right]]` 之间，则向右收缩：`left = mid + 1`。否则向左找。

---

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        """
        利用二分查找，每次排除掉一定不包含 target 的那一半
        """
        if not nums:
            return -1
            
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            
            # 1. 直接找到目标值
            if nums[mid] == target:
                return mid
            
            # 2. 判断哪一段是有序的
            # 情况 A: 左半部分 [left, mid] 是有序的
            if nums[left] <= nums[mid]:
                # 检查 target 是否在这一段有序区间内
                if nums[left] <= target < nums[mid]:
                    right = mid - 1  # 在左边
                else:
                    left = mid + 1   # 在右边
            
            # 情况 B: 右半部分 [mid, right] 是有序的
            else:
                # 检查 target 是否在这一段有序区间内
                if nums[mid] < target <= nums[right]:
                    left = mid + 1   # 在右边
                else:
                    right = mid - 1  # 在左边
                    
        return -1
```

## 4. 复杂度分析

### 时间复杂度：$O(\log n)$
* 虽然数组不是全局有序的，但每次迭代我们依然能排除掉一半的搜索区间。
* 符合题目要求的对数级别复杂度。

### 空间复杂度：$O(1)$
* 只使用了常数个指针变量（`left`, `right`, `mid`），不涉及额外的空间开销。
