# LeetCode 022. 括号生成 (Generate Parentheses)

## 1. 题目描述
数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

**示例：**
> **输入**：n = 3
> **输出**：["((()))","(()())","(())()","()(())","()()()"]

---

## 2. 题目分析

### 核心思想：回溯算法 + 有效性限制
这道题可以看作是在构建一棵深度为 $2n$ 的二叉树。在每个节点，我们都有两个选择：添加一个左括号 `(` 或添加一个右括号 `)`。

但并不是所有的路径都是有效的，我们需要在搜索过程中进行**“剪枝”**，遵循以下规则：
1.  **左括号数量限制**：只要左括号的数量 `left` 小于 `n`，我们就可以继续添加左括号。
2.  **右括号有效性限制**：只有当右括号的数量 `right` 小于左括号的数量 `left` 时，我们才能添加右括号（否则会出现 `)(` 这种非法结构）。
3.  **结束条件**：当已使用的左括号和右括号数量都达到 `n` 时，说明生成了一个完整的有效组合。

---

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        """
        使用回溯算法生成有效括号组合
        """
        res = []  # 存储所有有效的括号组合
        
        def backtrack(current_str: str, left: int, right: int):
            # 【结束条件】当左右括号都用完了，说明构成了一个完整的有效组合
            if len(current_str) == 2 * n:
                res.append(current_str)
                return
            
            # 【选择 1】如果左括号还没用完，可以添加左括号
            if left < n:
                # 递归进入下一层，left 计数加 1
                backtrack(current_str + "(", left + 1, right)
            
            # 【选择 2】如果右括号数量少于左括号，可以添加右括号
            # 这一步保证了括号的有效性（即任意时刻右括号不会多于左括号）
            if right < left:
                # 递归进入下一层，right 计数加 1
                backtrack(current_str + ")", left, right + 1)
        
        # 从空字符串，0个左括号，0个右括号开始递归
        backtrack("", 0, 0)
        return res
```

## 4. 复杂度分析

### 时间复杂度：$O(\frac{4^n}{\sqrt{n}})$
* 这是一个非常有趣的复杂度。括号生成的序列总数实际上是第 $n$ 个 **卡特兰数 (Catalan Number)**。
* 卡特兰数 $C_n = \frac{1}{n+1} \binom{2n}{n}$，其渐进增长速度约为 $\frac{4^n}{n^{3/2}}$。
* 在回溯过程中，每个有效解的构建耗时 $O(n)$，因此总时间复杂度在 $O(\frac{4^n}{\sqrt{n}})$ 数量级。

### 空间复杂度：$O(n)$
* **递归栈深度**：递归树的最大深度为 $2n$，因此系统栈的开销为 $O(n)$。
* **辅助空间**：在递归过程中，我们需要存储当前的字符串，其最大长度为 $2n$，空间复杂度为 $O(n)$。
* （注：不计入存储最终 $C_n$ 个结果字符串的 `res` 列表空间）。

为什么这道题目不需要使用 pop 呢：

1. 核心区别：不可变类型 vs 可变类型

| 特性 | **字符串 (String)** | **列表 (List)** |
| :--- | :--- | :--- |
| **类型** | 不可变 (Immutable) | 可变 (Mutable) |
| **操作方式** | `s + "("` 会创建一个**全新的字符串** | `path.append()` 是在**原数组**上修改 |
| **回溯需求** | 不需要手动还原（旧变量没变） | **必须**手动还原（否则会影响其他分支） |

---

2. 为什么字符串不需要 `pop`？

在括号生成的代码中：
```python
# 这里产生了“隐式回溯”
backtrack(current_str + "(", left + 1, right)
```
当你执行 `current_str + "("` 时，Python 实际上在内存中申请了一个**新的空间**来存放这个新字符串，并把它传递给下一层递归。而**当前层**的 `current_str` 变量指向的原始字符串并没有被改变。

当递归返回到当前层时，`current_str` 还是它原来的样子，所以你不需要做任何“撤销”操作，直接就可以进行下一个 `if` 判断。

---

3. 为什么列表需要 `pop`？

在之前的全排列代码中：
```python
path.append(nums[i]) # 修改了 path 指向的堆内存
backtrack()          # 递归
path.pop()           # 必须撤销，否则 path 永远带着刚才加进去的数
```
这里的 `path` 是一个列表。在整个递归过程中，所有层级的函数其实都在**共用同一个列表对象**（指向同一个内存地址）。

如果你在第 2 层往列表里加了个数字 `1`，当递归返回到第 1 层时，那个 `1` 依然留在列表里。如果你不手动 `pop` 掉它，当你尝试开启另一个分支时，列表的状态就是错误的。
