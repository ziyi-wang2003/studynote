# LeetCode 051. N 皇后 (N-Queens)

## 1. 题目描述
按照国际象棋的规则，皇后可以攻击与她在同一行、同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

**返回形式**：每一种解法包含一个不同的棋盘状态，其中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例：**

![](https://assets.leetcode.com/uploads/2020/11/13/queens.jpg)

> **输入**：n = 4
> **输出**：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]

---

## 2. 题目分析

### 核心思想：回溯算法 + 约束校验
这是一个经典的约束满足问题。我们按**行**进行递归，每一行只放置一个皇后，这样就天然解决了“行冲突”。

### 关键：如何快速判断列和对角线冲突？
为了提高效率，我们使用三个集合（Set）来记录已经被占用的区域：
1.  **列集合 (`cols`)**：记录哪些列已经放了皇后。
2.  **正对角线集合 (`pos_diag`)**：同一条从左下到右上的对角线上，行索引与列索引之和（$row + col$）是固定的常数。
3.  **负对角线集合 (`neg_diag`)**：同一条从左上到右下的对角线上，行索引与列索引之差（$row - col$）是固定的常数。



### 回溯流程
1.  **从第 0 行开始**，尝试在每一列放置皇后。
2.  **检查冲突**：如果当前列、正对角线或负对角线已被占用，则跳过。
3.  **递归**：放置皇后并更新集合，进入下一行。
4.  **回溯**：从集合中移除记录，将棋盘还原，尝试当前行的下一列。
5.  **终止**：当行索引等于 $n$ 时，记录当前棋盘布局。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        res = []
        # 初始化棋盘，全部填为 '.'
        board = [['.' for _ in range(n)] for _ in range(n)]
        
        # 使用集合记录已占用的列和两条对角线
        cols = set()      # 纵向列
        pos_diag = set()  # 正对角线 (row + col)
        neg_diag = set()  # 负对角线 (row - col)
        
        def backtrack(row: int):
            # 【结束条件】当放置完最后一行时，收集结果
            if row == n:
                # 将二维字符数组转换为题目要求的字符串列表格式
                res.append(["".join(r) for r in board])
                return
            
            # 在当前行的每一列尝试放置皇后
            for col in range(n):
                # 【剪枝】检查当前位置是否会被攻击
                if col in cols or (row + col) in pos_diag or (row - col) in neg_diag:
                    continue
                
                # 做选择：放置皇后并标记占用
                board[row][col] = 'Q'
                cols.add(col)
                pos_diag.add(row + col)
                neg_diag.add(row - col)
                
                # 递归：处理下一行
                backtrack(row + 1)
                
                # 【回溯】撤销选择：移除皇后并取消占用标记
                board[row][col] = '.'
                cols.remove(col)
                pos_diag.remove(row + col)
                neg_diag.remove(row - col)
        
        # 从第 0 行开始递归
        backtrack(0)
        return res
```

## 4. 复杂度分析

### 时间复杂度：$O(n!)$
* 第一行有 $n$ 种放法，第二行由于受第一行限制，最多有 $n-2$ 种放法，以此类推。
* 虽然对角线约束更严苛，但其上界仍为 $O(n!)$。

### 空间复杂度：$O(n)$
* **递归栈深度**：最大为 $n$。
* **辅助空间**：`cols`、`pos_diag`、`neg_diag` 三个集合以及 `board` 数组的大小均为 $O(n)$ 或 $O(n^2)$（但 `board` 是必须的输出结构基础，其递归深度空间主要是 $O(n)$）。
* （注：不计入存储最终所有方案的 $res$ 空间）。
