# LeetCode 017. 电话号码的字母组合 (Letter Combinations of a Phone Number)

## 1. 题目描述
给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

* `2`: "abc", `3`: "def", `4`: "ghi", `5`: "jkl", `6`: "mno", `7`: "pqrs", `8`: "tuv", `9`: "wxyz"

**示例：**
> **输入**：digits = "23"
> **输出**：["ad","ae","af","bd","be","bf","cd","ce","cf"]

## 2. 题目分析

### 核心思想：回溯算法 / 深度优先搜索 (DFS)
这道题本质上是一个**多级排列组合**问题。每输入一个数字，就代表在当前的组合路径上增加一个层级。

1.  **映射关系**：首先需要一个哈希表（或数组）来存储数字到字母的映射。
2.  **搜索树**：
    * 树的深度：等于输入字符串 `digits` 的长度。
    * 每一层的分支：等于当前数字所对应的字母个数（3个或4个）。
3.  **递归逻辑**：
    * 从第一个数字开始，遍历其对应的所有字母。
    * 选定一个字母后，递归进入下一个数字。
    * 当递归深度等于 `digits` 长度时，说明找到了一个完整的字母组合。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        # 如果输入为空，直接返回空列表
        if not digits:
            return []
        
        # 建立数字到字母的映射表
        phone_map = {
            "2": "abc", "3": "def", "4": "ghi", "5": "jkl",
            "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"
        }
        
        res = []      # 存储最终结果
        path = []     # 存储当前构建的字母路径
        
        def backtrack(index: int):
            # 【结束条件】如果当前处理的索引等于字符串长度，说明组合完成
            if index == len(digits):
                # 将路径中的字符拼接成字符串存入结果
                res.append("".join(path))
                return
            
            # 获取当前数字对应的所有字母
            digit = digits[index]
            letters = phone_map[digit]
            
            # 遍历当前数字对应的每一个字母
            for letter in letters:
                # 做选择：将字母加入当前路径
                path.append(letter)
                
                # 递归：处理下一个数字
                backtrack(index + 1)
                
                # 【回溯】撤销选择，返回上一层尝试其他字母
                path.pop()
        
        # 从第 0 个数字开始回溯
        backtrack(0)
        return res
```

## 4. 复杂度分析

### 时间复杂度：$O(3^N \times 4^M)$
* 其中 $N$ 是对应 3 个字母的数字个数，$M$ 是对应 4 个字母的数字个数，$N+M$ 是输入字符串的总长度。
* 总组合数即为 $3^N \times 4^M$，每个组合都需要 $O(N+M)$ 的时间进行构建和存储。
* 在 LeetCode 规模下，这属于指数级增长，但由于 `digits` 长度限制较小，回溯法是最高效的解法。

### 空间复杂度：$O(N+M)$
* **递归栈空间**：递归的深度等于 `digits` 的长度，即 $O(N+M)$。
* **辅助空间**：`path` 数组用于存储当前组合，长度同样为 $O(N+M)$。
* （注：不计入存储结果集 `res` 的空间）。
