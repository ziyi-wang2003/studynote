# LeetCode 078. 子集 (Subsets)

## 1. 题目描述
给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

* **解集**：不能包含重复的子集。
* **返回形式**：你可以按任意顺序返回解集。

**示例：**
> **输入**：nums = [1, 2, 3]
> **输出**：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

---

## 2. 题目分析

### 核心思想：回溯算法 (Backtracking) / 深度优先搜索 (DFS)
子集问题本质上是在询问：对于数组中的每一个元素，我们是“选”还是“不选”？

1.  **决策树模型**：
    * 从空集开始。
    * 第一层：考虑数字 `nums[0]`，有两种路径：加入路径或不加入。
    * 第二层：考虑数字 `nums[1]`，在之前的基础上又有两种路径。
    * 以此类推，对于 $n$ 个数字，总共会产生 $2^n$ 个叶子节点。



2.  **搜索策略**：
    * 为了避免产生重复的组合（如 `[1, 2]` 和 `[2, 1]` 被视为同一个子集），我们通过一个变量 `start` 来控制搜索的起始位置，保证后续选择的数字都在当前数字之后。
    * **每一个节点都是一个合法的子集**，因此在递归的每一步，我们都需要将当前的 `path` 加入到结果集中。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        """
        使用回溯算法生成所有子集
        """
        res = []   # 存储所有子集的结果集
        path = []  # 存储当前正在构建的子集路径
        
        def backtrack(start: int):
            # 每一个节点都是一个解，直接加入结果集
            # 使用 path[:] 创建当前路径的副本
            res.append(path[:])
            
            # 从 start 开始遍历，避免重复选择之前的元素
            for i in range(start, len(nums)):
                # 做选择：将当前元素加入路径
                path.append(nums[i])
                
                # 递归：进入下一层决策，从 i + 1 开始，保证元素不重复使用
                backtrack(i + 1)
                
                # 回溯：撤销选择，恢复状态，尝试包含下一个元素的情况
                path.pop()
        
        # 从索引 0 开始回溯
        backtrack(0)
        return res
```

## 4. 复杂度分析

### 时间复杂度：$O(n \cdot 2^n)$
* **子集数量**：长度为 $n$ 的集合，其子集（幂集）的总数为 $2^n$。
* **单个路径操作**：对于每一个生成的子集，我们需要将其复制到结果列表中，复制操作的时间复杂度为 $O(n)$。
* 因此，总时间复杂度为 $O(n \cdot 2^n)$。

### 空间复杂度：$O(n)$
* **递归深度**：递归树的最大深度为数组的长度 $n$，因此系统栈的开销为 $O(n)$。
* **辅助空间**：用于存储当前路径的列表 `path` 最大长度也为 $n$，空间复杂度为 $O(n)$。
* （注：不计入存储最终 $2^n$ 个子集结果的 `res` 空间）。
