# LeetCode 131. 分割回文串 (Palindrome Partitioning)

## 1. 题目描述
给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

**回文串**：正着读和反着读都一样的字符串。

**示例：**
> **输入**：s = "aab"
> **输出**：[["a","a","b"],["aa","b"]]

---

## 2. 题目分析

### 核心思想：回溯算法 (Backtracking)
分割问题本质上是在字符串的间隔中选择“切割点”。

1.  **切割过程**：
    * 假设字符串长度为 $n$，有 $n-1$ 个潜在的切割位置。
    * 从索引 `start` 开始，尝试每一个可能的切割终点 `i`。
    * 如果子串 `s[start:i+1]` 是回文，则将其加入当前路径 `path`，并递归处理剩余部分 `s[i+1:]`。
2.  **决策树结构**：
    * **路径**：当前已经分割出的回文子串列表。
    * **选择列表**：从当前位置到字符串末尾的所有子串。
    * **结束条件**：起始索引 `start` 到达字符串末尾，说明整个字符串已成功分割。



### 优化：回文判断
* **双指针法**：每次切割后，使用左右指针向中间移动来判断。
* **动态规划预处理（可选）**：如果 $s$ 很长，可以先用 $O(n^2)$ 的 DP 预计算出所有子串的回文状态，避免重复计算。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        res = []   # 存储所有成功的分割方案
        path = []  # 存储当前正在构建的分割方案
        
        def is_palindrome(left: int, right: int) -> bool:
            """检查 s[left:right+1] 是否为回文"""
            while left < right:
                if s[left] != s[right]:
                    return False
                left += 1
                right -= 1
            return True

        def backtrack(start: int):
            # 【结束条件】如果起始索引等于字符串长度，说明找到了一组完整的分割
            if start == len(s):
                res.append(path[:])
                return
            
            # 【选择过程】从 start 开始尝试所有可能的切割点 i
            for i in range(start, len(s)):
                # 只有当前切割出的子串是回文时，才继续向下递归
                if is_palindrome(start, i):
                    # 做选择：将当前回文子串加入路径
                    path.append(s[start : i + 1])
                    
                    # 递归：从下一个位置 i + 1 继续切割
                    backtrack(i + 1)
                    
                    # 回溯：撤销选择
                    path.pop()
        
        backtrack(0)
        return res
```

## 4. 复杂度分析

### 时间复杂度：$O(n \cdot 2^n)$
* **分割方案数量**：在最坏情况下（如 `s = "aaaa"`），每个字符间都可以切或不切，共有 $2^{n-1}$ 种分割组合。
* **操作开销**：对于每种方案，我们需要 $O(n)$ 的时间进行回文检查和字符串拷贝。
* 因此，总时间复杂度为 $O(n \cdot 2^n)$。

### 空间复杂度：$O(n)$
* **递归栈深度**：递归树的最大深度为 $n$。
* **辅助空间**：`path` 列表存储当前方案，最大长度为 $n$。
* （注：不计入存储最终所有分割方案结果集的空间）。
