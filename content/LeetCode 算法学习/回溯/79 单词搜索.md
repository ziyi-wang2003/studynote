# LeetCode 079. 单词搜索 (Word Search)

## 1. 题目描述
给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

* **规则**：单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。
* **限制**：同一个单元格内的字母不允许被重复使用。

**示例：**
> **输入**：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
> **输出**：true

## 2. 题目分析

### 核心思想：DFS + 回溯
我们需要在矩阵中找到一个起点，使其等于 `word[0]`，然后从这个点出发，向四周（上下左右）探索。

1.  **搜索起点**：遍历整个矩阵，找到所有与 `word` 第一个字符匹配的位置，作为 DFS 的入口。
2.  **递归逻辑**：
    * **匹配成功**：如果当前字符匹配，且已经是 `word` 的最后一个字符，返回 `true`。
    * **标记已访问**：为了防止“回头路”，我们需要标记当前格子已访问。一个小技巧是暂时将其修改为特殊字符（如 `#`），递归结束后再改回来（即回溯）。
    * **四方向扩散**：向上下左右四个方向继续寻找 `word` 的下一个字符。
3.  **终止条件**：
    * 越界（坐标超出矩阵范围）。
    * 当前格子字符与 `word` 对应位置字符不匹配。
    * 当前格子已经访问过。

## 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        rows, cols = len(board), len(board[0])
        
        def dfs(r, c, k):
            """
            r, c: 当前格子的行列索引
            k: 当前匹配到 word 的第几个字符
            """
            # 【终止条件 1】如果不匹配，直接返回 False
            if board[r][c] != word[k]:
                return False
            
            # 【终止条件 2】如果已经匹配到单词的最后一个字符
            if k == len(word) - 1:
                return True
            
            # 【做选择】暂存当前字符，并标记为已访问，防止同一路径重复使用
            temp = board[r][c]
            board[r][c] = '#'
            
            # 【探索】向四个方向延伸 (上, 下, 左, 右)
            # 只要有一个方向能走通，就返回 True
            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                nr, nc = r + dr, c + dc
                # 检查边界条件
                if 0 <= nr < rows and 0 <= nc < cols:
                    if dfs(nr, nc, k + 1):
                        return True
            
            # 【回溯】撤销选择，恢复当前格子的字符，以便其他路径使用
            board[r][c] = temp
            return False

        # 遍历矩阵，寻找起始点
        for i in range(rows):
            for j in range(cols):
                if dfs(i, j, 0):
                    return True
                    
        return False
```

## 4. 复杂度分析

### 时间复杂度：$O(M \cdot N \cdot 3^L)$
* $M, N$ 分别为矩阵的行数和列数，$L$ 为字符串 `word` 的长度。
* 我们需要遍历 $M \cdot N$ 个起点。
* 在 DFS 过程中，除了起点有 4 个方向，后续每个点由于不能走回头路，最多只有 3 个方向可以探索。递归深度最大为 $L$。
* 因此，最坏情况下的总复杂度约为 $O(M \cdot N \cdot 3^L)$。

### 空间复杂度：$O(L)$
* **递归栈深度**：递归调用的最大深度即为单词的长度 $L$。
* **辅助空间**：由于我们采用了“原地修改”矩阵的技巧（把字符改成 `#`），我们不需要额外的 `visited` 数组（$O(MN)$），成功将额外空间降低到 $O(L)$。
