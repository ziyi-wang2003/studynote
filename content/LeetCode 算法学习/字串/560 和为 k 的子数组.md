# LeetCode 560. 和为 K 的子数组

## 1. 题目描述
给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回该数组中和为 `k` 的连续子数组的个数。

**示例 1：**
> **输入**：nums = [1,1,1], k = 2
> **输出**：2

**示例 2：**
> **输入**：nums = [1,2,3], k = 3
> **输出**：2

---

## 2. 题目分析

### 核心思想：前缀和 + 哈希表优化
1.  **前缀和（Prefix Sum）**：
    定义 $pre[i]$ 为从索引 $0$ 到 $i$ 的元素之和。那么任意子数组 $[j, i]$ 的和可以表示为：
    $$\text{sum}(j, i) = pre[i] - pre[j-1]$$
    我们的目标是找到满足 $pre[i] - pre[j-1] = k$ 的索引对数。

2.  **公式变形**：
    将等式变形为：$pre[j-1] = pre[i] - k$。
    当我们遍历数组计算当前的前缀和 $pre[i]$ 时，我们只需要知道在索引 $i$ 之前，有多少个前缀和等于 $pre[i] - k$。

3.  **哈希表优化**：
    使用一个哈希表（在 Python 中为 `dict`）来存储每个前缀和出现的**次数**。
    * **Key**: 前缀和的值。
    * **Value**: 该前缀和出现的次数。
    * **初始化**：`{0: 1}`。这代表前缀和为 0 已经出现过一次（用于处理从索引 0 开始且和刚好为 $k$ 的子数组）。



---

## 3. Python 代码实现

```python
from typing import List

def subarraySum(nums: List[int], k: int) -> int:
    # count 用于记录满足条件的子数组数量
    count = 0
    # pre_sum 用于记录当前的前缀和
    pre_sum = 0
    # hash_map 存储前缀和出现的次数
    # 初始化 {0: 1} 是为了处理当前缀和正好等于 k 的情况 (pre_sum - k = 0)
    hash_map = {0: 1}
    
    for num in nums:
        # 更新当前前缀和
        pre_sum += num
        
        # 如果 pre_sum - k 在哈希表中，说明找到了之前的一个位置，
        # 到当前位置的子数组和正好为 k
        target = pre_sum - k
        if target in hash_map:
            count += hash_map[target]
        
        # 将当前前缀和存入哈希表，如果已存在则次数加 1
        hash_map[pre_sum] = hash_map.get(pre_sum, 0) + 1
        
    return count
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 其中 $n$ 为数组的长度。我们只需要遍历一遍数组，哈希表的查询和插入操作均为 $O(1)$。 |
| **空间复杂度** | $O(n)$ | 在最坏的情况下（所有前缀和都不同），哈希表需要存储 $n+1$ 个键值对。 |
