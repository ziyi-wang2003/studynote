# LeetCode 239. 滑动窗口最大值

## 1. 题目描述
给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 **滑动窗口中的最大值** 。

**示例 1：**
> **输入**：nums = [1,3,-1,-3,5,3,6,7], k = 3
> **输出**：[3,3,5,5,6,7]
> **解释**：
> 滑动窗口的位置                最大值
> ---------------               -----
> [1  3  -1] -3  5  3  6  7       **3**
>  1 [3  -1  -3] 5  3  6  7       **3**
>  1  3 [-1  -3  5] 3  6  7       **5**
>  1  3  -1 [-3  5  3] 6  7       **5**
>  1  3  -1  -3 [5  3  6] 7       **6**
>  1  3  -1  -3  5 [3  6  7]      **7**

---

## 2. 题目分析

### 核心思想：单调队列（Monotonic Queue）
要高效地获取滑动窗口的最大值，我们需要一种数据结构，能够随着窗口滑动：
1.  **移除** 离开窗口的元素。
2.  **加入** 新进入窗口的元素。
3.  **快速获取** 当前窗口内的最大值。

普通的队列或堆（Priority Queue）无法在 $O(n)$ 时间内完成。我们使用 **双端队列（deque）** 来维护一个**单调递减**的队列。

**维护策略：**
* **存储索引**：队列中存储元素的索引而非数值，方便判断元素是否已超出当前窗口范围。
* **保持单调性**：当新元素 `nums[i]` 进入窗口时，从队尾开始比较。如果队尾索引对应的元素小于等于 `nums[i]`，则这些元素永远不可能成为后续窗口的最大值，直接将其弹出。
* **过期移除**：检查队首索引是否小于 `i - k + 1`，如果是，说明该最大值已不在窗口内，将其从队首移除。
* **获取结果**：每当窗口填满（`i >= k - 1`）时，队首索引对应的元素即为当前窗口的最大值。

## 3. Python 代码实现

```python
from collections import deque
from typing import List

def maxSlidingWindow(nums: List[int], k: int) -> List[int]:
    if not nums:
        return []
    
    # result 用于存储每个窗口的最大值
    res = []
    # dq 存储的是元素的索引，且 nums[dq[i]] 在队列中单调递减
    dq = deque()
    
    for i in range(len(nums)):
        # 1. 移除超出窗口左边界的索引
        # 窗口范围是 [i-k+1, i]，如果队首索引等于 i-k，说明它已经失效
        if dq and dq[0] == i - k:
            dq.popleft()
            
        # 2. 维护单调递减属性
        # 如果当前元素比队尾元素大，则队尾元素不可能是最大值，弹出
        while dq and nums[dq[-1]] <= nums[i]:
            dq.pop()
            
        # 3. 将当前索引加入队列
        dq.append(i)
        
        # 4. 当窗口形成（长度达到 k）时，记录队首元素（最大值）
        if i >= k - 1:
            res.append(nums[dq[0]])
            
    return res
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 虽然有 `while` 循环，但每个索引最多被 `append` 一次、`pop` 一次，总体操作次数与 $n$ 成正比。 |
| **空间复杂度** | $O(k)$ | 双端队列中最多同时存储 $k$ 个元素的索引（实际通常远小于 $k$）。 |
