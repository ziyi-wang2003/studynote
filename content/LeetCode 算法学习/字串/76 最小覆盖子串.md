# LeetCode 76. 最小覆盖子串

## 1. 题目描述
给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中包含 `t` 所有字符的最小子串。如果 `s` 中不存在符合条件的子串，则返回空字符串 `""` 。

**注意：** 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符的数量。

**示例 1：**
> **输入**：s = "ADOBECODEBANC", t = "ABC"
> **输出**："BANC"
> **解释**：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

**示例 2：**
> **输入**：s = "a", t = "a"
> **输出**："a"

---

## 2. 题目分析

### 核心思想：滑动窗口（Sliding Window）
这道题是典型的双指针滑动窗口问题。我们需要维护一个窗口 `[left, right]`，使其包含 `t` 中所有的字符。

1.  **初始化**：使用两个哈希表，`need` 记录 `t` 中每个字符出现的次数，`window` 记录当前窗口内各字符出现的次数。
2.  **移动右边界 (`right`)**：不断扩大窗口，将字符加入 `window` 中，直到窗口包含了 `t` 中的所有字符。
3.  **收缩左边界 (`left`)**：当窗口满足条件后，尝试通过移动 `left` 来缩小窗口。在缩小的过程中，如果窗口依然满足包含 `t` 的所有字符，则更新“最小子串”的结果。
4.  **有效字符计数 (`valid`)**：使用一个变量 `valid` 表示窗口中满足 `need` 条件的字符个数。当 `window[c] == need[c]` 时，`valid` 加 1。



---

## 3. Python 代码实现

```python
from collections import Counter

def minWindow(s: str, t: str) -> str:
    # need 存储 t 中各字符出现的次数
    need = Counter(t)
    # window 存储当前窗口中各字符出现的次数
    window = {}
    
    left, right = 0, 0
    # valid 表示窗口中满足 need 条件的字符种类数
    valid = 0
    # 记录最小覆盖子串的起始索引及长度
    start, min_len = 0, float('inf')
    
    while right < len(s):
        # c 是即将移入窗口的字符
        c = s[right]
        # 右移窗口
        right += 1
        
        # 进行窗口内数据的一系列更新
        if c in need:
            window[c] = window.get(c, 0) + 1
            if window[c] == need[c]:
                valid += 1
        
        # 判断左侧窗口是否需要收缩
        while valid == len(need):
            # 在这里更新最小覆盖子串
            if right - left < min_len:
                start = left
                min_len = right - left
            
            # d 是即将移出窗口的字符
            d = s[left]
            # 左移窗口
            left += 1
            
            # 进行窗口内数据的一系列更新
            if d in need:
                if window[d] == need[d]:
                    valid -= 1
                window[d] -= 1
                
    # 返回最终结果
    return "" if min_len == float('inf') else s[start:start + min_len]
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(M + N)$ | 其中 $M$ 和 $N$ 分别是字符串 `s` 和 `t` 的长度。每个字符最多进窗口一次、出窗口一次。 |
| **空间复杂度** | $O(K)$ | $K$ 为字符集的大小（如 ASCII 字符集）。哈希表 `need` 和 `window` 最多存放 $K$ 个键值对。 |
