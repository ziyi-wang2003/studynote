# LeetCode 295. 数据流的中位数 (Find Median from Data Stream)

## 1. 题目描述
中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

请设计一个支持以下两种操作的数据结构：
* `void addNum(int num)`：从数据流中添加一个整数到数据结构中。
* `double findMedian()`：返回目前所有元素的中位数。

---

### 示例 1：
* **输入**：
  `["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]`
  `[[], [1], [2], [], [3], []]`
* **输出**：
  `[null, null, null, 1.5, null, 2.0]`
* **解释**：
  MedianFinder medianFinder = new MedianFinder();
  medianFinder.addNum(1);    // arr = [1]
  medianFinder.addNum(2);    // arr = [1, 2]
  medianFinder.findMedian(); // 返回 1.5 (1 + 2) / 2
  medianFinder.addNum(3);    // arr[1, 2, 3]
  medianFinder.findMedian(); // 返回 2.0

---

## 2. 核心分析：对顶堆 (Dual Heaps)
为了在 $O(1)$ 时间内找到中位数，同时在 $O(\log n)$ 时间内完成插入，最经典的策略是维护**两个堆**。

### 算法逻辑：
我们将所有数字分成两部分：
1.  **左半部分（较小的一半）**：用一个 **大顶堆 (Max-Heap)** 存储。堆顶是左半部分的最大值。
2.  **右半部分（较大的一半）**：用一个 **小顶堆 (Min-Heap)** 存储。堆顶是右半部分的最小值。



### 维护原则：
* **数量平衡**：大顶堆的元素个数 `n1` 与小顶堆的元素个数 `n2` 满足：$n1 = n2$ 或 $n1 = n2 + 1$。
* **数值有序**：大顶堆的所有元素 $\le$ 小顶堆的所有元素。这意味着中位数只可能在两个堆的堆顶产生。

### 插入流程 (`addNum`)：
1.  先将新元素插入大顶堆。
2.  将大顶堆的堆顶弹出，并插入小顶堆（确保数值有序）。
3.  如果小顶堆的元素比大顶堆多了，则将小顶堆的堆顶弹出并还给大顶堆（确保数量平衡）。

## 3. Python 代码实现

```python
import heapq

class MedianFinder:
    def __init__(self):
        # Python 的 heapq 默认是小顶堆
        # small_half: 大顶堆（存储较小的一半），为了实现大顶堆，存入负数
        self.small_half = [] 
        # large_half: 小顶堆（存储较大的一半），存入正数
        self.large_half = []

    def addNum(self, num: int) -> None:
        # 1. 始终先放入大顶堆（小半部分）
        # 注意：Python 的 heapq 是小顶堆，存负数来模拟大顶堆
        heapq.heappush(self.small_half, -num)
        
        # 2. 为了保证数值有序，将大顶堆的最大值移到小顶堆（大半部分）
        max_from_small = -heapq.heappop(self.small_half)
        heapq.heappush(self.large_half, max_from_small)
        
        # 3. 维护数量平衡：大顶堆的长度可以等于或比小顶堆多 1
        # 如果小顶堆元素多了，就移一个回大顶堆
        if len(self.large_half) > len(self.small_half):
            min_from_large = heapq.heappop(self.large_half)
            heapq.heappush(self.small_half, -min_from_large)

    def findMedian(self) -> float:
        # 如果总数是奇数，中位数在大顶堆的堆顶
        if len(self.small_half) > len(self.large_half):
            return float(-self.small_half[0])
        # 如果总数是偶数，中位数是两个堆顶的平均值
        else:
            return (-self.small_half[0] + self.large_half[0]) / 2.0
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度 (addNum)** | $O(\log n)$ | 涉及堆的插入和弹出操作，每次操作耗时 $\log n$。 |
| **时间复杂度 (findMedian)** | $O(1)$ | 直接获取两个堆的堆顶元素即可。 |
| **空间复杂度** | $O(n)$ | 需要两个堆存储数据流中的所有 $n$ 个元素。 |

## 5. 进阶思考
* **如果数据流中的整数都在 0 到 100 之间**：可以使用计数排序（桶排序）的思想，维护一个频率数组和中位数指针，时间复杂度可优化至 $O(1)$。
* **如果 99% 的整数都在 0 到 100 之间**：可以用频率数组处理 0-100 的数据，对于超出范围的极少数数据使用对顶堆或单独记录。
