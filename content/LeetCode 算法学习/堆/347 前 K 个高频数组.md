# LeetCode 347. 前 K 个高频元素 (堆 / 优先队列实现)

## 1. 题目描述
给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。

---

## 2. 核心分析：小顶堆 (Min-Heap)
虽然大顶堆也可以解决问题，但维护一个大小为 `k` 的**小顶堆**是更优的空间策略。

### 算法逻辑：
1.  **统计频率**：使用哈希表（`Counter`）统计每个元素出现的次数。
2.  **维护小顶堆**：
    * 遍历频率统计结果。
    * 将元素及其频率依次放入堆中。
    * **关键点**：如果堆的大小超过了 `k`，就弹出堆顶元素。
    * **为什么用小顶堆？** 因为小顶堆的堆顶是当前堆中频率最小的元素。当我们排除掉那些频率最小的元素后，最后留在堆里的 $k$ 个元素一定是频率最高的。
3.  **提取结果**：堆中剩下的 $k$ 个元素即为答案。



---

## 3. Python 代码实现

```python
import heapq
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 1. 统计频率
        # count 存储 {数字: 出现次数}
        count = Counter(nums)
        
        # 2. 维护一个大小为 k 的小顶堆
        # 堆中存储元组 (频率, 数字)，因为 heapq 默认根据元组第一个元素排序
        min_heap = []
        
        for num, freq in count.items():
            # 将当前 (频率, 数字) 入堆
            heapq.heappush(min_heap, (freq, num))
            
            # 如果堆的大小超过了 k，弹出频率最小的那个（堆顶）
            if len(min_heap) > k:
                heapq.heappop(min_heap)
        
        # 3. 提取堆中的数字返回即可
        # 结果不要求顺序，直接列表推导
        return [item[1] for item in min_heap]

    # 补充：Python 库函数一行代码版本
    # def topKFrequent(self, nums, k):
    #     return [item[0] for item in Counter(nums).most_common(k)]
```

## 4. 复杂度分析

设 $n$ 为数组长度，$m$ 为数组中不重复元素的个数。

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n \log k)$ | 统计频率耗时 $O(n)$。遍历 $m$ 个不重复元素，每次堆操作耗时 $O(\log k)$，总耗时 $O(m \log k)$。由于 $m \le n$，最终为 $O(n \log k)$。 |
| **空间复杂度** | $O(n)$ | 哈希表需要 $O(n)$ 空间，堆需要 $O(k)$ 空间。 |

---

## 5. 堆解法 vs 桶排序
* **桶排序 ($O(n)$)**：在频率范围已知且分布较均匀时最快，但在数据极度稀疏或频率跨度极大时，桶的空间利用率较低。
* **堆排序 ($O(n \log k)$)**：非常稳定，特别适合**海量数据流**场景。如果你只需要前 $k$ 个高频元素，而数据是在线不断产生的，堆可以实时维护这 $k$ 个结果。
