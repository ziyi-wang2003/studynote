# LeetCode 215. 数组中的第K个最大元素 (Kth Largest Element in an Array)

## 1. 题目描述
给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。
你必须设计并实现时间复杂度为 $O(n)$ 的算法解决此问题。

---

### 示例 1：
* **输入**: `[3,2,1,5,6,4]`, `k = 2`
* **输出**: `5`

### 示例 2：
* **输入**: `[3,2,3,1,2,4,5,5,6]`, `k = 4`
* **输出**: `4`

---

## 2. 核心分析：快速选择 (Quick Select)
虽然可以使用堆排序（$O(n \log k)$），但题目要求 $O(n)$ 的复杂度，这通常指向 **快速选择算法**。它是快速排序（Quick Sort）的变体。

### 算法逻辑：
1.  **分治思想**：在数组中随机选择一个基准值 `pivot`。
2.  **分区 (Partition)**：将数组划分为三部分：
    * `big`: 大于 `pivot` 的元素
    * `equal`: 等于 `pivot` 的元素
    * `small`: 小于 `pivot` 的元素
3.  **递归判断**：
    * 如果 `k` 在 `big` 的长度范围内，说明第 `k` 大元素在 `big` 中，递归进入 `big`。
    * 如果 `k` 不在 `big` 中，但在 `big + equal` 的长度范围内，说明 `pivot` 本身就是第 `k` 大元素，直接返回。
    * 否则，第 `k` 大元素在 `small` 中，递归进入 `small`，此时要更新 `k` 的值为 `k - len(big) - len(equal)`。



---

## 3. Python 代码实现

```python
import random

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 快速选择函数
        def quick_select(nums, k):
            # 随机选择基准值，防止最坏情况发生
            pivot = random.choice(nums)
            
            # 将数组划分为大于、等于、小于基准值的三部分
            big, equal, small = [], [], []
            
            for num in nums:
                if num > pivot:
                    big.append(num)
                elif num == pivot:
                    equal.append(num)
                else:
                    small.append(num)
            
            # 第 k 大元素在 big 部分
            if k <= len(big):
                return quick_select(big, k)
            
            # 第 k 大元素在 equal 部分（即 pivot 自身）
            if len(big) + len(equal) >= k:
                return pivot
            
            # 第 k 大元素在 small 部分
            # 此时需要减去 big 和 equal 的长度，在剩下的元素里找第 n 小的
            return quick_select(small, k - len(big) - len(equal))
            
        return quick_select(nums, k)
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | 期望 $O(n)$ | 平均情况下，每次分区都能排除一部分元素，收敛于 $O(n)$。最坏为 $O(n^2)$（随机 pivot 可极大概率规避）。 |
| **空间复杂度** | $O(n)$ | 递归过程中使用的辅助数组空间。若使用原地（In-place）分区，可优化至 $O(\log n)$ 栈空间。 |

## 5. 补充：小顶堆解法 (Min-Heap)
如果面试官要求在数据流中实时查找，或者限制辅助空间，可以使用堆：
1.  维护一个大小为 `k` 的最小堆。
2.  遍历数组，将元素入堆。
3.  如果堆的大小超过 `k`，弹出堆顶（最小的）。
4.  遍历结束，堆顶元素即为第 `k` 个最大值。
* **时间复杂度**: $O(n \log k)$
* **空间复杂度**: $O(k)$
