# LeetCode 101. 对称二叉树 (Symmetric Tree)

### 1. 题目描述
给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

**示例 1：**
> **输入：** root = [1,2,2,3,4,4,3]  
> **输出：** true

**示例 2：**
> **输入：** root = [1,2,2,null,3,null,3]  
> **输出：** false

---

### 2. 题目分析
判断一棵树是否对称，本质上是判断其**左子树**和**右子树**是否互为镜像。

两个子树 $L$ 和 $R$ 互为镜像的条件：
1.  它们的根节点的值相等。
2.  $L$ 的**左**子树和 $R$ 的**右**子树互为镜像。
3.  $L$ 的**右**子树和 $R$ 的**左**子树互为镜像。



**递归逻辑（DFS）：**
* **终止条件**：
    * 两个节点都为空：对称（`True`）。
    * 只有一个节点为空：不对称（`False`）。
    * 两个节点值不相等：不对称（`False`）。
* **递归过程**：
    * 继续比较 `left.left` 与 `right.right`。
    * 继续比较 `left.right` 与 `right.left`。

---

### 3. 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        
        # 调用辅助函数比较左右子树
        return self.check(root.left, root.right)

    def check(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        # 1. 两个节点都为空，是对称的
        if not p and not q:
            return True
        
        # 2. 只有一个节点为空，或者两个节点值不同，不对称
        if not p or not q or p.val != q.val:
            return False
        
        # 3. 递归比较：
        # 外侧比较：p 的左孩子与 q 的右孩子比较
        # 内侧比较：p 的右孩子与 q 的左孩子比较
        return self.check(p.left, q.right) and self.check(p.right, q.left)
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树的节点数。每个节点都会被访问一次，且每次比较操作的时间复杂度为 $O(1)$。
* **空间复杂度：$O(H)$**
    * 其中 $H$ 是树的高度。空间复杂度主要取决于递归调用栈。
    * 在最坏情况下（树呈链状），空间复杂度为 $O(N)$。
    * 在平均情况下（平衡二叉树），空间复杂度为 $O(\log N)$。
