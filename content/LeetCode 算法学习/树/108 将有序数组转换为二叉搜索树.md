# LeetCode 108. 将有序数组转换为二叉搜索树 (Convert Sorted Array to Binary Search Tree)

### 1. 题目描述
给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 **高度平衡** 二叉搜索树（BST）。

**高度平衡** 二叉树是指一个二叉树每个节点的左右两个子树的高度差的绝对值不超过 1 。

**示例 1：**
> **输入：** nums = [-10,-3,0,5,9]  
> **输出：** [0,-3,9,-10,null,5]  
> **解释：** [0,-10,5,null,-3,null,9] 也将被视为正确答案。

**示例 2：**
> **输入：** nums = [1,3]  
> **输出：** [3,1]  
> **解释：** [1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。

---

### 2. 题目分析
由于输入的数组已经按 **升序** 排列，这实际上就是二叉搜索树（BST）**中序遍历**的结果。要构建一棵 **高度平衡** 的 BST，核心思想是：**总是选择数组的中间元素作为根节点。**

**算法逻辑：**
1.  **取中点**：选择数组中间位置的数字作为当前子树的根节点。这样可以保证左侧剩余数字和右侧剩余数字的数量尽可能相等，从而实现平衡。
2.  **递归构建**：
    * 数组中点左边的部分，递归构建成当前根节点的左子树。
    * 数组中点右边的部分，递归构建成当前根节点的右子树。
3.  **终止条件**：当子数组的区间为空（左索引大于右索引）时，返回 `None`。



这种“取中点”的方法确保了生成的树在结构上是左右对称或接近对称的，满足高度平衡的要求。

### 3. 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        
        # 辅助递归函数，处理区间 [left, right]
        def build(left: int, right: int) -> Optional[TreeNode]:
            # 基准情形：区间无效，说明子树为空
            if left > right:
                return None
            
            # 选择中间位置的元素作为根节点
            # (left + right) // 2 总是选择中间偏左的位置（如果长度为偶数）
            mid = (left + right) // 2
            
            # 创建根节点
            root = TreeNode(nums[mid])
            
            # 递归构建左子树：使用中间元素左边的区间
            root.left = build(left, mid - 1)
            
            # 递归构建右子树：使用中间元素右边的区间
            root.right = build(mid + 1, right)
            
            return root
        
        # 初始调用，传入整个数组的索引范围
        return build(0, len(nums) - 1)
```

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是数组的长度。每个数字都会被访问且仅访问一次，并被转换为一个树节点。
* **空间复杂度：$O(\log N)$**
    * 虽然我们是在原数组上操作，没有使用额外的存储结构，但递归调用会占用系统栈空间。
    * 由于这棵树是严格平衡的，递归深度（树的高度）固定为 $\lceil \log_2(N+1) \rceil$。因此，在平衡情况下，空间复杂度为 $O(\log N)$。
