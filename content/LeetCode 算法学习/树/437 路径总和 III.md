# LeetCode 437. 路径总和 III (Path Sum III)

## 1. 题目描述
给定一个二叉树的根节点 `root` ，和一个整数 `targetSum` ，求该二叉树中路径和等于 `targetSum` 的 **路径的数目** 。

路径 **不需要** 从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

---

### 示例 1：

* **输入**：`root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8`
* **输出**：`3`
* **解释**：和等于 8 的路径有：
  1.  5 -> 3
  2.  5 -> 2 -> 1
  3.  -3 -> 11

---

## 2. 核心分析：前缀和 (Prefix Sum)
这道题如果用双重 DFS（对每个节点都做一次路径探测），时间复杂度会退化到 $O(N^2)$ 或 $O(N \log N)$。最优解法是借鉴数组中的**前缀和**思想。

### 算法逻辑：
1.  **前缀和定义**：定义 `curr_sum` 为从根节点到当前节点的路径总和。
2.  **数学转换**：如果在当前路径上，存在一个祖先节点，其前缀和为 `prev_sum`，且满足 `curr_sum - prev_sum == targetSum`，那么从该祖先节点到当前节点的路径和正好就是 `targetSum`。
3.  **哈希表加速**：使用一个哈希表（Dictionary）存储 `前缀和 : 出现的次数`。
    * 当我们到达一个节点，计算当前的 `curr_sum`。
    * 查找哈希表中是否存在 `curr_sum - targetSum`。如果存在，说明找到了对应数量的路径。
4.  **回溯 (Backtracking)**：**非常重要！** 在处理完当前节点的左右子树后，必须将 `curr_sum` 从哈希表中减去（或次数减一）。这是因为路径必须是向下的，我们不能让左子树的前缀和影响到右子树。

---

## 3. Python 代码实现

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        # prefix_sums 存储：{当前路径和 : 该路径和出现的次数}
        # 初始化 {0: 1} 是为了处理从根节点开始就直接等于 targetSum 的情况
        prefix_sums = {0: 1}
        
        def dfs(node, curr_sum):
            if not node:
                return 0
            
            res = 0
            # 更新当前路径的前缀和
            curr_sum += node.val
            
            # 看看在此之前，有没有哪个祖先节点的前缀和满足条件
            # 目标公式：curr_sum - prev_sum = targetSum  =>  prev_sum = curr_sum - targetSum
            res += prefix_sums.get(curr_sum - targetSum, 0)
            
            # 将当前前缀和放入哈希表，供子节点使用
            prefix_sums[curr_sum] = prefix_sums.get(curr_sum, 0) + 1
            
            # 递归遍历左右子树
            res += dfs(node.left, curr_sum)
            res += dfs(node.right, curr_sum)
            
            # 【回溯】状态恢复：当前节点处理完后，将其前缀和次数减1
            # 这样在回到父节点并进入另一条子树分支时，不会受到当前分支的干扰
            prefix_sums[curr_sum] -= 1
            
            return res

        return dfs(root, 0)
```

---

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 每个节点仅被访问一次，哈希表的查询和插入操作均为 $O(1)$。 |
| **空间复杂度** | $O(n)$ | 在最坏情况下（链状树），递归栈深度为 $n$，哈希表也将存储 $n$ 个前缀和。 |

---

## 5. 易错点拨
* **哈希表初始化**：别忘了 `prefix_sums = {0: 1}`。如果没有它，所有从根节点起始的路径（即 `curr_sum == targetSum`）都无法被统计到。
* **回溯的必要性**：二叉树的 DFS 遍历是深度优先的。如果你在回到父节点时不清理哈希表，那么左子树生成的“前缀和”会被带入到右子树的计算中，导致逻辑错误。
