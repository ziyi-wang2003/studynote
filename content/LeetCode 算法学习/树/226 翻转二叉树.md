# LeetCode 226. 翻转二叉树 (Invert Binary Tree)

### 1. 题目描述
给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

**示例 1：**
> **输入：** root = [4,2,7,1,3,6,9]  
> **输出：** [4,7,2,9,6,3,1]

**示例 2：**
> **输入：** root = [2,1,3]  
> **输出：** [2,3,1]

---

### 2. 题目分析
翻转二叉树的核心在于：**对于树中的每一个节点，交换其左子节点和右子节点。**

**解题思路：递归 (DFS)**
1.  **终止条件**：如果当前节点为 `None`，说明已经到达叶子节点的下方，直接返回 `None`。
2.  **交换操作**：交换当前节点的左孩子和右孩子。
3.  **递归下沉**：
    * 递归地对左子树进行翻转。
    * 递归地对右子树进行翻转。
4.  **返回结果**：返回当前翻转完成后的根节点。



这道题本质上是对二叉树进行一次遍历（前序或后序均可），在遍历过程中完成左右孩子的交换。

---

### 3. 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        # 1. 递归终止条件：如果节点为空，则无需翻转，返回 None
        if not root:
            return None
        
        # 2. 交换当前节点的左右子节点
        # Python 支持这种简便的变量交换写法
        root.left, root.right = root.right, root.left
        
        # 3. 递归地翻转左子树
        self.invertTree(root.left)
        
        # 4. 递归地翻转右子树
        self.invertTree(root.right)
        
        # 5. 返回翻转后的根节点
        return root
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树中的节点个数。每个节点都会被访问一次并进行常数时间的交换操作。
* **Space Complexity：$O(H)$**
    * 其中 $H$ 是二叉树的高度。
    * 空间复杂度取决于递归调用栈的深度。在最坏的情况下（树退化为链表），深度为 $N$；在平衡二叉树的情况下，深度为 $\log N$。
