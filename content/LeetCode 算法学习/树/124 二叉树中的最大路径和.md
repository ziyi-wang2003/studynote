# LeetCode 124. 二叉树中的最大路径和 (Binary Tree Maximum Path Sum)

## 1. 题目描述
路径 被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。同一个节点在一条路径序列中 **至多出现一次** 。该路径 **至少包含一个** 节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

---

### 示例 1：

* **输入**：`root = [-10,9,20,null,null,15,7]`
* **输出**：`42`
* **解释**：最大路径为 `15 -> 20 -> 7` ，路径和为 `15 + 20 + 7 = 42`。

---

## 2. 核心分析：递归与贡献值

解决本题的关键在于理解一个节点在路径中的两种“角色”：

1.  **作为路径的“转折点”**：路径通过该节点连接左子树和右子树。此时，以该节点为顶点的最大路径和为：`node.val + 左子树提供的最大贡献 + 右子树提供的最大贡献`。
2.  **作为路径的一部分向上延伸**：为了形成更长的路径，该节点只能选择左子树或右子树中路径和较大的那一个，连接到其父节点。此时，该节点能为父节点提供的**最大贡献值**为：`node.val + max(左子树贡献, 右子树贡献)`。

### 算法逻辑：
* 由于节点值可能为负数，如果子树提供的贡献值为负，我们宁愿不选该子树（即贡献视为 0）。
* 使用一个全局变量 `max_sum` 记录遍历过程中产生的最大路径和（角色 1 的情况）。
* 递归函数返回该节点能向父节点提供的最大贡献值（角色 2 的情况）。

---

## 3. Python 代码实现

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        # 初始化为负无穷，用于记录全局最大路径和
        self.max_sum = float('-inf')

        def get_contribution(node):
            if not node:
                return 0
            
            # 递归计算左右子节点的最大贡献
            # 如果贡献为负，则取 0（即不把该子树包含进路径）
            left_gain = max(get_contribution(node.left), 0)
            right_gain = max(get_contribution(node.right), 0)
            
            # 【核心点】计算以当前节点为“转折点”的路径和
            # 这条路径连接了左子树、当前节点、右子树
            current_path_sum = node.val + left_gain + right_gain
            
            # 更新全局最大值
            self.max_sum = max(self.max_sum, current_path_sum)
            
            # 【返回值】返回当前节点能为父节点提供的最大贡献
            # 只能选择左或者右的一条路径延伸上去，不能同时选
            return node.val + max(left_gain, right_gain)

        get_contribution(root)
        return self.max_sum
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 其中 $n$ 是二叉树中的节点数。每个节点仅被访问一次。 |
| **空间复杂度** | $O(h)$ | $h$ 是二叉树的高度。空间复杂度主要取决于递归调用的栈空间。最坏情况下（树呈链状）为 $O(n)$，平均情况下为 $O(\log n)$。 |

---

## 5. 易错提醒
* **负数处理**：必须使用 `max(gain, 0)`。如果某个分支的和是负数，包含它只会让总和变小，此时我们应该丢弃该分支。
* **返回值与更新值的区别**：递归函数的**返回值**是单侧延伸的最大和，而**全局更新值**是考虑了左右双侧合并后的完整路径和。
