# LeetCode 94. 二叉树的中序遍历 (Binary Tree Inorder Traversal) - 迭代法

### 1. 题目描述
给定一个二叉树的根节点 `root` ，返回它的 **中序** 遍历。

**中序遍历顺序**：左子树 -> 根节点 -> 右子树。

**示例 1：**
> **输入：** root = [1,null,2,3]  
> **输出：** [1,3,2]

**示例 2：**
> **输入：** root = [1,2,3,4,5,null,null]  
> **输出：** [4,2,5,1,3]

---

### 2. 题目分析
递归方法虽然简洁，但在树深度很大时可能导致栈溢出。**迭代法**利用显式的数据结构 **栈 (Stack)** 来模拟递归的过程。

**核心逻辑：**
1.  **左路入栈**：从根节点开始，只要当前节点不为空，就将其推入栈中，并继续向左走（`curr = curr.left`）。这一步是为了找到最左侧的“起点”。
2.  **出栈访问**：当无法继续向左（遇到 `None`）时，说明左子树已经处理完。从栈中弹出节点，该节点就是当前的“根”，记录其值。
3.  **转向右路**：将指针指向弹出节点的右孩子（`curr = curr.right`），然后重复上述步骤，处理右子树。



通过这种方式，我们保证了访问顺序严格遵循“左 -> 根 -> 右”。

---

### 3. 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []      # 存储最终遍历结果
        stack = []    # 显式栈，用于模拟递归调用栈
        curr = root   # 当前遍历的指针

        # 当指针不为空，或者栈内还有节点时，继续循环
        while curr or stack:
            # 1. 尽可能向左走，将路径上的节点全部入栈
            while curr:
                stack.append(curr)
                curr = curr.left
            
            # 2. 到达最左侧后，弹出栈顶元素（即当前的“根”节点）
            curr = stack.pop()
            res.append(curr.val) # 记录节点值
            
            # 3. 转向当前节点的右子树，开始下一轮“左路入栈”
            curr = curr.right
            
        return res
```

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树的节点数。每个节点都会被压入栈和弹出栈各一次。
* **空间复杂度：$O(N)$**
    * 空间复杂度取决于栈的深度。在最坏的情况下（树呈链状），栈的高度为 $N$。在平衡二叉树的情况下，空间复杂度为 $O(\log N)$。
