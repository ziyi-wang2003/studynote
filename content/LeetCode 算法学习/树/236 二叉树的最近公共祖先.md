# LeetCode 236. 二叉树的最近公共祖先 (Lowest Common Ancestor of a Binary Tree)

## 1. 题目描述
给定一个二叉树, 找到该树中两个指定节点 $p$ 和 $q$ 的最近公共祖先 (LCA)。

**最近公共祖先的定义**：对于有根树 $T$ 的两个节点 $p、q$，最近公共祖先表示为一个节点 $x$，满足 $x$ 是 $p、q$ 的祖先且 $x$ 的深度尽可能大（一个节点也可以是它自己的祖先）。

---

### 示例 1：

* **输入**：`root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1`
* **输出**：`3`
* **解释**：节点 5 和节点 1 的最近公共祖先是节点 3 。

---

## 2. 核心分析：递归（后序遍历）

寻找 LCA 的过程本质上是**自底向上**的信息传递。我们使用递归，通过观察左右子树的返回值来判断当前节点是否为 LCA。

### 递归逻辑：
1.  **终止条件**：
    * 如果当前节点 `root` 为空，返回 `None`。
    * 如果当前节点 `root` 等于 `p` 或 `q`，直接返回 `root`（说明找到了其中一个目标）。
2.  **递归搜索**：
    * 去左子树找 $p$ 和 $q$，结果记为 `left`。
    * 去右子树找 $p$ 和 $q$，结果记为 `right`。
3.  **结果合并（判断）**：
    * **情况 1**：`left` 和 `right` 都不为空。说明 $p$ 和 $q$ 分别分布在当前节点的两侧，那么当前节点 `root` 就是它们的最近公共祖先。
    * **情况 2**：`left` 为空，`right` 不为空。说明 $p$ 和 $q$ 都在右子树中，返回 `right`。
    * **情况 3**：`left` 不为空，`right` 为空。说明 $p$ 和 $q$ 都在左子树中，返回 `left`。
    * **情况 4**：都为空，说明没找到，返回 `None`。

---

## 3. Python 代码实现

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # 1. 终止条件：越过叶子节点，或者直接找到了 p 或 q
        if not root or root == p or root == q:
            return root
        
        # 2. 递归左子树和右子树
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        
        # 3. 根据左右子树的返回值判断
        
        # 如果左子树没找到，说明 p 和 q 都在右子树（或者根本不存在，题目保证存在）
        if not left: 
            return right
        
        # 如果右子树没找到，说明 p 和 q 都在左子树
        if not right: 
            return left
        
        # 如果 left 和 right 同时非空，说明 p 和 q 分居 root 异侧
        # 此时 root 就是最近公共祖先
        return root
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 在最坏情况下（如 $p, q$ 是叶子节点），需要遍历树的所有节点。 |
| **空间复杂度** | $O(n)$ | 递归深度取决于树的高度。在最坏情况下（树退化为链表），系统栈空间为 $n$。 |

---

## 5. 关键直觉
* **自底向上**：由于我们是先递归左右子树，再根据子树结果处理当前节点，这实际上是一个**后序遍历**的过程。
* **向上汇报**：每个节点都向父节点汇报：“我这边的子树里有没有 $p$ 或 $q$？”当一个节点发现两边都有汇报时，它就是那个最终的“交汇点”。
