# LeetCode 98. 验证二叉搜索树 (Validate Binary Search Tree) - 中序遍历法

### 1. 题目描述
给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：
* 节点的左子树只包含 **小于** 当前节点的数。
* 节点的右子树只包含 **大于** 当前节点的数。
* 所有左子树和右子树自身必须也是二叉搜索树。

**示例：**
> **输入：** root = [5,1,4,null,null,3,6]  
> **输出：** false  
> **解释：** 中序遍历结果为 [1, 5, 3, 4, 6]，其中 5 > 3，不符合升序要求。

---

### 2. 题目分析
利用二叉搜索树（BST）的一个重要性质：**BST 的中序遍历（左-根-右）序列必须是严格递增的。**

**核心逻辑：**
1.  **遍历顺序**：按照中序遍历的顺序访问每一个节点。
2.  **状态记录**：使用一个变量 `pre` 记录上一个访问到的节点的值。
3.  **有效性比较**：每次访问当前节点时，判断 `current.val` 是否大于 `pre`。
    * 如果 `current.val <= pre`，说明破坏了递增性，不是合法的 BST。
    * 如果遍历完整棵树都满足递增要求，则是合法的 BST。



**实现方式**：
* **递归中序遍历**：在递归过程中记录全局变量。
* **迭代中序遍历**：使用栈（Stack）手动模拟，逻辑更清晰且容易在发现不合法时立即跳出。

---

### 3. 代码实现 (Python - 迭代法)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        # 使用栈进行迭代式中序遍历
        stack = []
        # pre 记录上一个访问节点的值，初始化为负无穷
        pre = float('-inf')
        curr = root

        # 只要指针不为空或栈内还有元素，就继续遍历
        while curr or stack:
            # 1. 尽可能向左走，将路径上的节点入栈
            while curr:
                stack.append(curr)
                curr = curr.left
            
            # 2. 弹出栈顶节点（即当前中序遍历序列中的下一个节点）
            node = stack.pop()
            
            # 3. 比较当前节点值与前一个节点值
            # 如果当前值小于或等于前一个值，说明不是严格递增，返回 False
            if node.val <= pre:
                return False
            
            # 更新 pre 为当前节点的值
            pre = node.val
            
            # 4. 转向右子树
            curr = node.right
            
        return True
```

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树的节点数。在最坏情况下（合法 BST 或最后一个节点才不合法），需要遍历所有节点。
* **空间复杂度：$O(H)$**
    * 其中 $H$ 是二叉树的高度。
    * 空间复杂度取决于栈的深度。在最坏情况下（树呈链状），空间复杂度为 $O(N)$；在平衡树情况下，为 $O(\log N)$。
