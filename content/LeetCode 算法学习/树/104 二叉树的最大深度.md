# LeetCode 104. 二叉树的最大深度 (Maximum Depth of Binary Tree)

### 1. 题目描述
给定一个二叉树的根节点 `root` ，找出其最大深度。二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

**示例 1：**
> **输入：** root = [3,9,20,null,null,15,7]  
> **输出：** 3  
> **解释：** 根节点到叶子节点 [15, 7] 的路径长度为 3。

**示例 2：**
> **输入：** root = [1,null,2]  
> **输出：** 2

---

### 2. 题目分析
计算二叉树的最大深度，最经典的方法是使用 **深度优先搜索 (DFS)** 的递归实现。

**核心逻辑：**
1.  **递归出口**：如果当前节点为空（`None`），说明已经越过了叶子节点，高度为 **0**。
2.  **递归过程**：
    * 递归计算左子树的最大深度。
    * 递归计算右子树的最大深度。
3.  **合并结果**：当前节点的最大深度 = **左、右子树深度的最大值 + 1**（这里的 1 代表当前节点本身这一层）。



这种自底向上的计算方式实际上是二叉树的**后序遍历**应用。

---

### 3. 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        # 基准情形：如果节点为空，深度为 0
        if not root:
            return 0
        
        # 递归计算左子树的最大深度
        left_height = self.maxDepth(root.left)
        
        # 递归计算右子树的最大深度
        right_height = self.maxDepth(root.right)
        
        # 当前树的最大深度 = 左右子树中较大的深度 + 1 (当前节点层)
        return max(left_height, right_height) + 1
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树的节点数。每个节点都必须且仅会被访问一次。
* **空间复杂度：$O(H)$**
    * 其中 $H$ 是二叉树的高度。空间复杂度主要取决于递归调用栈的深度：
        * 在最坏情况下（树呈链状），高度 $H = N$，空间复杂度为 $O(N)$。
        * 在最好情况下（平衡二叉树），高度 $H = \log N$，空间复杂度为 $O(\log N)$。
