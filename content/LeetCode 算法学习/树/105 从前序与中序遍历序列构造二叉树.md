# LeetCode 105. 从前序与中序遍历序列构造二叉树 (Construct Binary Tree from Preorder and Inorder Traversal)

### 1. 题目描述
给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**前序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

**示例 1:**
> **输入:** preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]  
> **输出:** [3,9,20,null,null,15,7]

**示例 2:**
> **输入:** preorder = [-1], inorder = [-1]  
> **输出:** [-1]

---

### 2. 题目分析
本题的核心在于利用前序和中序遍历的特性来定位根节点和左右子树。

**关键性质：**
* **前序遍历 (Preorder)**：顺序是 `[ 根节点 | 左子树 | 右子树 ]`。前序数组的第一个元素永远是当前的**根节点**。
* **中序遍历 (Inorder)**：顺序是 `[ 左子树 | 根节点 | 右子树 ]`。如果我们已知根节点的值，就可以在中序数组中找到它，从而确定左右子树的**节点数量**。

**算法逻辑（分治法）：**
1.  **确定根节点**：取前序遍历的第一个元素作为当前的根节点。
2.  **在中序遍历中定位根节点**：找到根节点在中序数组中的索引 `mid`。
3.  **划分左右子树**：
    * 中序数组中 `mid` 左侧的部分即为左子树，右侧为右子树。
    * 根据左子树节点的个数，在前序数组中截取对应长度的部分作为左子树的前序序列，余下的为右子树的前序序列。
4.  **递归构建**：对左右子树分别重复上述步骤。



---

### 3. 代码实现 (Python)

为了提高查找效率，我们可以使用哈希表预存储中序遍历中每个值对应的索引。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 使用哈希表存储中序遍历的值与索引的映射，优化查找速度
        index_map = {val: i for i, val in enumerate(inorder)}
        
        def myBuildTree(pre_left, pre_right, in_left, in_right):
            if pre_left > pre_right:
                return None
            
            # 1. 前序遍历中的第一个节点就是根节点
            root_val = preorder[pre_left]
            root = TreeNode(root_val)
            
            # 2. 在中序遍历中定位根节点
            in_root_index = index_map[root_val]
            
            # 3. 计算左子树的节点数目
            size_left_subtree = in_root_index - in_left
            
            # 4. 递归地构造左子树，并连接到根节点
            # 先序：左边界+1 到 左边界+左子树数量
            # 中序：左边界 到 根节点索引-1
            root.left = myBuildTree(pre_left + 1, pre_left + size_left_subtree, 
                                    in_left, in_root_index - 1)
            
            # 5. 递归地构造右子树，并连接到根节点
            # 先序：左边界+左子树数量+1 到 右边界
            # 中序：根节点索引+1 到 右边界
            root.right = myBuildTree(pre_left + size_left_subtree + 1, pre_right, 
                                     in_root_index + 1, in_right)
            
            return root

        n = len(preorder)
        return myBuildTree(0, n - 1, 0, n - 1)
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是树中的节点数。
    * 利用哈希表查找根节点位置的时间是 $O(1)$，每个节点都会被创建且仅访问一次。
* **空间复杂度：$O(N)$**
    * 哈希表存储中序序列需要 $O(N)$ 空间。
    * 递归调用栈在最坏情况下（树呈链状）深度为 $N$。总体空间复杂度为 $O(N)$。
