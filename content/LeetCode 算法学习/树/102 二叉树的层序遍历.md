# LeetCode 102. 二叉树的层序遍历 (Binary Tree Level Order Traversal)

### 1. 题目描述
给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。 （即逐层地，从左到右访问所有节点）。

**示例 1：**
> **输入：** root = [3,9,20,null,null,15,7]  
> **输出：** [[3],[9,20],[15,7]]

**示例 2：**
> **输入：** root = [1]  
> **输出：** [[1]]

**示例 3：**
> **输入：** root = []  
> **输出：** []

---

### 2. 题目分析
层序遍历要求我们按层访问，这在图论和树的算法中对应 **广度优先搜索 (BFS)**。

**核心逻辑：**
1.  **辅助数据结构**：使用 **队列 (Queue)** 来存储待访问的节点。由于 Python 的 `list` 弹出首元素的时间复杂度为 $O(n)$，通常建议使用 `collections.deque`（双端队列），其弹出操作为 $O(1)$。
2.  **分层处理**：
    * 首先将根节点入队。
    * 进入循环，只要队列不为空：
        * 记录当前队列的长度 `level_size`，这代表当前层有多少个节点。
        * 开启一个循环，迭代 `level_size` 次，依次将当前层的节点弹出。
        * 每弹出一个节点，将其值存入当前层的子列表，并将其非空的左右孩子存入队列（作为下一层的节点）。
3.  **收集结果**：将每一层生成的子列表存入最终的结果列表。



---

### 3. 代码实现 (Python)

```python
from typing import List, Optional
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        # 如果根节点为空，直接返回空列表
        if not root:
            return []
        
        res = []
        # 使用 deque 创建一个队列，初始包含根节点
        queue = deque([root])
        
        # 只要队列不为空，说明还有节点需要遍历
        while queue:
            # 获取当前层的节点个数
            level_size = len(queue)
            current_level = []
            
            # 遍历当前层的所有节点
            for _ in range(level_size):
                # 从队首弹出节点
                node = queue.popleft()
                # 将节点值加入当前层结果
                current_level.append(node.val)
                
                # 如果左孩子不为空，加入队列
                if node.left:
                    queue.append(node.left)
                # 如果右孩子不为空，加入队列
                if node.right:
                    queue.append(node.right)
            
            # 将当前层的结果列表加入最终结果
            res.append(current_level)
            
        return res
```

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树的节点数。每个节点都会入队和出队各一次。
* **空间复杂度：$O(N)$**
    * 队列中最多会同时存储一层的所有节点。在最坏的情况下（满二叉树），最后一层大约有 $N/2$ 个节点，因此空间复杂度为 $O(N)$。结果列表也需要 $O(N)$ 的空间来存储节点值。
