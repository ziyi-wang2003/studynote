# LeetCode 230. 二叉搜索树中第 K 小的元素 (Kth Smallest Element in a BST)

### 1. 题目描述
给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k` 个最小元素（从 1 开始计数）。

**示例 1：**
> **输入：** root = [3,1,4,null,2], k = 1  
> **输出：** 1

**示例 2：**
> **输入：** root = [5,3,6,2,4,null,null,1], k = 3  
> **输出：** 3

---

### 2. 题目分析
本题的核心在于利用 **二叉搜索树 (BST)** 的重要性质：**BST 的中序遍历序列是升序排列的。**

**解题思路：**
1.  **中序遍历**：按照“左 -> 根 -> 右”的顺序访问节点，这样访问到的节点值会从小到大排列。
2.  **计数器**：在遍历过程中维护一个计数器。每访问一个节点，计数器加 1。
3.  **提前终止**：当计数器等于 `k` 时，当前节点的值即为所求，直接记录结果并停止遍历。



**迭代法（推荐）**：使用显式栈进行中序遍历。相比递归法，迭代法可以在找到第 $k$ 个元素后立即停止，不需要走完整个递归栈，效率更高且逻辑清晰。

---

### 3. 代码实现 (Python - 迭代法)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        # 使用栈模拟中序遍历的递归过程
        stack = []
        curr = root
        
        # 只要指针不为空或栈内还有元素，就继续遍历
        while curr or stack:
            # 1. 尽可能向左走，将路径上的节点入栈
            while curr:
                stack.append(curr)
                curr = curr.left
            
            # 2. 弹出栈顶节点（当前中序遍历中的最小值）
            node = stack.pop()
            
            # 3. 处理当前节点：计数器减一
            k -= 1
            if k == 0:
                # 找到第 k 小的元素，直接返回结果
                return node.val
            
            # 4. 转向右子树
            curr = node.right
            
        return -1 # 理论上不会走到这里
```

### 4. 进阶考量：频繁查找
如果二叉搜索树会被频繁修改（插入/删除操作）并且你需要频繁查找第 $k$ 小的元素，该如何优化？

* **优化方法**：在每个节点中存储以该节点为根的 **子树节点总数 (size)**。
* **查找逻辑**：
    * 设左子树节点数为 `left_size`。
    * 如果 `k == left_size + 1`，则根节点就是答案。
    * 如果 `k <= left_size`，则答案在左子树中，去左子树查找第 $k$ 小。
    * 如果 `k > left_size + 1`，则答案在右子树中，去右子树查找第 `k - left_size - 1` 小。
* **复杂度**：这样可以将每次查找的时间复杂度降低到 **$O(H)$**（$H$ 为树的高度）。

---

### 5. 复杂度分析

* **时间复杂度：$O(H + k)$**
    * $H$ 是树的高度，我们需要先下沉到最左侧节点。在找到答案之前，我们访问了 $k$ 个节点。
* **空间复杂度：$O(H)$**
    * 栈的深度取决于树的高度。在最坏情况下（链状树）为 $O(N)$，平衡树情况下为 $O(\log N)$。
