# LeetCode 543. 二叉树的直径 (Diameter of Binary Tree)

### 1. 题目描述
给你一棵二叉树的根节点 `root`，返回该树的 **直径** 。二叉树的 **直径** 是指树中任意两个节点之间最长路径的 **长度** 。这条路径可能经过也可能不经过根节点 `root` 。

两节点之间路径的 **长度** 是以它们之间边的数目表示。

**示例 1：**
> **输入：** root = [1,2,3,4,5]  
> **输出：** 3  
> **解释：** 路径 [4,2,1,3] 或 [5,2,1,3] 为长度为 3 的直径。

**示例 2：**
> **输入：** root = [1,2]  
> **输出：** 1

---

### 2. 题目分析
二叉树的直径问题可以转化为 **深度优先搜索 (DFS)** 的变体。

**核心逻辑：**
1.  **路径定义**：经过某个节点 `u` 的最长路径长度 = `u` 的左子树最大深度 + `u` 的右子树最大深度。
2.  **全局最优**：由于最长路径不一定经过根节点，我们需要在递归计算每个节点深度的同时，维护一个全局变量 `ans` 来记录出现过的最大路径长度（`left_depth + right_depth`）。
3.  **深度定义**：节点 `u` 的深度定义为 `max(left_depth, right_depth) + 1`，这与计算二叉树高度的逻辑一致。



**解题步骤：**
* 定义一个递归函数 `depth(node)`，返回该节点的深度。
* 在递归过程中，计算 `L = depth(node.left)` 和 `R = depth(node.right)`。
* 更新全局最大值：`ans = max(ans, L + R)`。
* 返回当前节点的深度给父节点：`max(L, R) + 1`。

---

### 3. 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        # 使用 self.ans 记录全局最长直径
        self.ans = 0

        def get_depth(node):
            if not node:
                # 访问到空节点，深度为 0
                return 0
            
            # 递归计算左子树的深度
            L = get_depth(node.left)
            # 递归计算右子树的深度
            R = get_depth(node.right)
            
            # 在每个节点处更新直径：左子树深度 + 右子树深度
            # 这里的 L 和 R 分别代表左右子树最长链的节点数（即边数）
            self.ans = max(self.ans, L + R)
            
            # 返回该节点作为根的子树的最大深度，供上一层使用
            return max(L, R) + 1
        
        get_depth(root)
        return self.ans
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N)$**
    * 其中 $N$ 是二叉树的节点数。每个节点在递归过程中只被访问一次。
* **空间复杂度：$O(H)$**
    * 其中 $H$ 是二叉树的高度。空间复杂度主要取决于递归调用栈的深度。
    * 在最坏情况下（树呈链状），高度 $H = N$，空间复杂度为 $O(N)$。
    * 在平衡二叉树的情况下，高度 $H = \log N$，空间复杂度为 $O(\log N)$。
