# LeetCode 11. 盛最多水的容器 (Container With Most Water)

## 1. 题目描述
给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

---

### 示例 1：

* **输入**：`[1,8,6,2,5,4,8,3,7]`
* **输出**：`49`
* **解释**：图中垂直线代表输入数组 `[1,8,6,2,5,4,8,3,7]`。在此情况下，容器能够容纳水（蓝色部分）的最大值为 `49`（由索引 1 和索引 8 的线组成，距离为 7，高度为 7）。

---

## 2. 核心分析：双指针法 (Two Pointers)
容器的面积由两个因素决定：**宽度**（两个指针之间的距离）和**高度**（两侧高度的最小值）。
$$Area = \min(height[i], height[j]) \times (j - i)$$

### 贪心策略：
1.  **初始状态**：设置左右指针 `left` 和 `right` 分别指向数组的两端。此时**宽度最大**。
2.  **移动逻辑**：
    * 每次移动**高度较小**的那一侧指针。
    * **原因**：由于移动指针必然会导致宽度 $(j - i)$ 减小，为了抵消宽度的损失，我们必须寻找更高的高度。
    * 如果移动较高的那一侧，容器的高度依然受限于原有的短板，且宽度变小，面积必然减小。
    * 只有移动较低的那一侧，才有可能遇到更高的一条边，从而在宽度减小的情况下，使面积增大。

---

## 3. Python 代码实现

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        # 初始化左右指针分别指向数组首尾
        left, right = 0, len(height) - 1
        max_water = 0
        
        while left < right:
            # 计算当前容器的宽度
            width = right - left
            # 计算当前容器的高度（取决于较短的那一根）
            current_height = min(height[left], height[right])
            
            # 计算面积并更新全局最大值
            max_water = max(max_water, width * current_height)
            
            # 核心逻辑：移动较短的那一侧指针
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
                
        return max_water
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 左右指针从两端向中间移动，总共遍历数组一次。 |
| **空间复杂度** | $O(1)$ | 只使用了常数个指针变量。 |

---

## 5. 重点总结
* **单调性思考**：这是一个寻找局部最优解来逼近全局最优解的过程。通过排除法（移动短板），我们过滤掉了所有面积必然更小的无效组合。
* **边界处理**：当 `left == right` 时，无法构成容器，循环结束。
