# LeetCode 283. 移动零 (Move Zeroes)

## 1. 题目描述
给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意**，必须在不复制数组的情况下原地对数组进行操作。

---

### 示例 1：
* **输入**: `nums = [0,1,0,3,12]`
* **输出**: `[1,3,12,0,0]`

### 示例 2：
* **输入**: `nums = [0]`
* **输出**: `[0]`

---

## 2. 核心分析：双指针（快慢指针）
由于题目要求**原地（In-place）**修改且保持**相对顺序**，双指针是最直观且高效的解法。

### 算法逻辑：
1.  **定义指针**：
    * `slow`（慢指针）：指向当前已处理好的非零序列的下一个位置（即下一个非零元素应该存放的位置）。
    * `fast`（快指针）：用于遍历整个数组，寻找非零元素。
2.  **遍历过程**：
    * 当 `nums[fast]` 不为 0 时：
        * 交换 `nums[slow]` 和 `nums[fast]` 的值。
        * `slow` 指针向后移动一位。
    * 当 `nums[fast]` 为 0 时：
        * `fast` 继续向前走，`slow` 原地不动。
3.  **结果**：所有非零元素被依次“挤”到了数组左侧，而 0 自然地被换到了数组右侧。



---

## 3. Python 代码实现

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        # slow 指针记录【下一个非零元素应该放的位置】
        slow = 0
        
        # fast 指针遍历整个数组去【寻找非零元素】
        for fast in range(len(nums)):
            # 如果发现了一个非零元素
            if nums[fast] != 0:
                # 交换 fast 和 slow 指向的值
                # 如果 fast 和 slow 相等（即前面没有 0），交换相当于没动
                # 如果 fast 已经跑到了 slow 前面（说明中间有 0），交换就把非零元换到了前面
                nums[slow], nums[fast] = nums[fast], nums[slow]
                
                # 交换后，slow 指向下一个位置
                slow += 1
```

---

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 只需要对数组进行一次线性遍历。 |
| **空间复杂度** | $O(1)$ | 仅使用了两个指针变量，不需要额外的存储空间。 |

---

## 5. 重点总结
* **原地操作**：通过交换元素（Swap）而不是先删除再添加，避免了数组元素大量移动带来的 $O(n^2)$ 复杂度。
* **相对顺序**：快指针 `fast` 总是从左到右寻找非零元素，并依次填入 `slow` 位置，天然地保证了原始顺序。
* **优化细节**：如果数组中全是正数或开头没有 0，`slow` 和 `fast` 会同步进行。只有在遇到第一个 0 之后，`fast` 才会领先于 `slow`。
