# LeetCode 42. 接雨水 (Trapping Rain Water)

## 1. 题目描述
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

---

### 示例 1：

* **输入**：`height = [0,1,0,2,1,0,1,3,2,1,2,1]`
* **输出**：`6`
* **解释**：黑色部分为柱子，蓝色部分为雨水，共接 6 单位雨水。

---

## 2. 核心分析：双指针法 (Two Pointers)
接雨水的核心原理是：**每一个位置能接多少水，取决于它左边最高的柱子和右边最高的柱子中的较小值。**
$$\text{water}[i] = \max(0, \min(\text{left\_max}_i, \text{right\_max}_i) - \text{height}[i])$$

### 算法逻辑：
1.  **初始化**：左右指针 `left`, `right` 分别指向数组首尾，维护 `left_max` 和 `right_max` 记录两侧遇到的最高高度。
2.  **移动策略**：
    * 如果 `left_max < right_max`：说明对于 `left` 指针所在的位置，其“木桶效应”的短板一定是左侧的 `left_max`（因为右侧已经有一个确定的 `right_max` 比它大）。此时我们可以计算 `left` 位置的水量并右移。
    * 反之，如果 `right_max <= left_max`：说明对于 `right` 指针位置，短板一定是右侧的 `right_max`。此时计算 `right` 位置的水量并左移。
3.  **更新最高值**：在移动过程中，不断更新 `left_max` 和 `right_max`。

---

## 3. Python 代码实现

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        # 初始化双指针和两侧的最大高度
        left, right = 0, len(height) - 1
        left_max, right_max = 0, 0
        water = 0

        while left <= right:
            # 找到当前左右两端最高柱子中的较小者（木桶的短板）
            tall = min(left_max, right_max)
            
            # 如果左侧最高值更小，说明左侧是当前的“瓶颈”
            if left_max <= right_max:
                # 当前位置能接的水 = 短板高度 - 当前柱子高度 (结果不能小于0)
                water += max(0, tall - height[left])
                # 更新左侧遇到的最高柱子
                left_max = max(left_max, height[left])
                left += 1
            # 如果右侧最高值更小，说明右侧是当前的“瓶颈”
            else:
                water += max(0, tall - height[right])
                # 更新右侧遇到的最高柱子
                right_max = max(right_max, height[right])
                right -= 1
        
        return water
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 左右指针从两端向中间汇合，每个元素仅访问一次。 |
| **空间复杂度** | $O(1)$ | 仅使用了常数级别的额外空间（指针和变量）。 |

---

## 5. 重点总结
* **空间优化**：相比于使用两个数组分别预处理 `left_max` 和 `right_max`（空间 $O(n)$），双指针法通过比较两端的大小关系，巧妙地省去了存储空间。
* **逻辑核心**：不需要知道另一侧绝对的最高值是多少，只需要知道另一侧**存在**一个比当前侧更高的“墙”，当前侧的积水高度就能被确定下来。
