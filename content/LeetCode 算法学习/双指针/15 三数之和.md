# LeetCode 15. 三数之和 (3Sum)

## 1. 题目描述
给你一个包含 `n` 个整数的数组 `nums`，判断 `nums` 中是否存在三个元素 `a`，`b`，`c` ，使得 `a + b + c = 0` ？请你找出所有和为 `0` 且 **不重复** 的三元组。

**注意：** 答案中不可以包含重复的三元组。

---

### 示例 1：
* **输入**：`nums = [-1,0,1,2,-1,-4]`
* **输出**：`[[-1,-1,2],[-1,0,1]]`

---

## 2. 核心分析：排序 + 双指针 (三指针)
暴力解法（三层循环）的时间复杂度是 $O(n^3)$，且处理去重非常麻烦。为了达到 $O(n^2)$，我们通常使用**排序 + 双指针**。

### 算法逻辑：
1.  **排序**：先对数组进行升序排序。这是使用双指针的前提，同时也方便去重。
2.  **固定第一指针 (`i`)**：遍历数组，以 `nums[i]` 作为三元组的第一个数。
    * **优化**：若 `nums[i] > 0`，由于数组有序，后面两个数也一定大于 0，三数之和不可能为 0，直接结束循环。
    * **去重**：若 `i > 0` 且 `nums[i] == nums[i-1]`，说明该数字已经作为开头处理过了，跳过。
3.  **双指针 (`L` 和 `R`)**：在 `i` 之后的区间 `[i + 1, n - 1]` 内设置左右指针。
    * 令 `sum = nums[i] + nums[L] + nums[R]`。
    * 若 `sum < 0`：说明数值太小，左指针右移 `L += 1`。
    * 若 `sum > 0`：说明数值太大，右指针左移 `R -= 1`。
    * 若 `sum == 0`：找到一组解。
        * **去重**：在记录结果后，需要移动 `L` 和 `R` 并跳过所有重复的数字，防止结果集中出现重复项。



---

## 3. Python 代码实现

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        # 1. 排序：这是双指针的基础
        nums.sort()
        res = []
        
        for i in range(n):
            # 优化：如果当前数字已经大于 0，后面的数字肯定也大于 0，和不可能为 0
            if nums[i] > 0:
                break
                
            # 去重：如果当前数字和前一个一样，跳过，避免重复的三元组
            if i > 0 and nums[i] == nums[i - 1]:
                continue
                
            # 定义双指针，在 [i+1, n-1] 范围内寻找
            L = i + 1
            R = n - 1
            
            while L < R:
                total = nums[i] + nums[L] + nums[R]
                
                if total == 0:
                    res.append([nums[i], nums[L], nums[R]])
                    
                    # 找到结果后，也要对左右指针分别进行去重
                    while L < R and nums[L] == nums[L + 1]:
                        L += 1
                    while L < R and nums[R] == nums[R - 1]:
                        R -= 1
                    
                    # 移动到下一个不同的数字
                    L += 1
                    R -= 1
                    
                elif total < 0:
                    L += 1 # 和太小，左指针右移
                else:
                    R -= 1 # 和太大，右指针左移
                    
        return res
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n^2)$ | 数组排序耗时 $O(n \log n)$。外层循环遍历 $n$ 个数，内层双指针遍历一次是 $O(n)$，嵌套后为 $O(n^2)$。 |
| **空间复杂度** | $O(\log n)$ | 忽略存储返回值的空间，主要是排序所需的栈空间。 |

---

## 5. 重点总结
* **去重的时机**：共有三处去重：第一个数 `i`、第二个数 `L`、第三个数 `R`。这三处去重是保证不重复三元组的关键。
* **排序的作用**：排序不仅让双指针的移动有据可依（单调性），还让相同的数字靠在一起，使得去重逻辑极其简单。
