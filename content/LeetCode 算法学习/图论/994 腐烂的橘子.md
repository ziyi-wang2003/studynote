# LeetCode 994. 腐烂的橘子 (Rotting Oranges)

## 1. 题目描述
在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：
* `0` 代表空单元格；
* `1` 代表新鲜橘子；
* `2` 代表腐烂的橘子。

每分钟，腐烂的橘子 **周围 4 个方向上相邻** 的新鲜橘子都会腐烂。

返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1` 。

---

### 示例 1：

* **输入**：`grid = [[2,1,1],[1,1,0],[0,1,1]]`
* **输出**：`4`
* **解释**：
  第 0 分钟：`[[2, 1, 1], [1, 1, 0], [0, 1, 1]]`
  第 1 分钟：`[[2, 2, 1], [2, 1, 0], [0, 1, 1]]`
  第 2 分钟：`[[2, 2, 2], [2, 2, 0], [0, 1, 1]]`
  第 3 分钟：`[[2, 2, 2], [2, 2, 0], [0, 2, 1]]`
  第 4 分钟：`[[2, 2, 2], [2, 2, 0], [0, 2, 2]]`
  此时没有新鲜橘子了。

---

## 2. 核心分析：多源广度优先搜索 (Multi-source BFS)
这道题要求的是“最短时间”，且腐烂的过程是像波纹一样层层扩散的，这非常符合 **BFS (广度优先搜索)** 的特点。

### 算法步骤：
1.  **初始化**：
    * 扫描整个网格，将所有**初始腐烂的橘子**坐标放入队列。
    * 统计**新鲜橘子**的总数。
2.  **多源扩散**：
    * 从队列中弹出当前所有腐烂的橘子，并向它们的上下左右四个方向寻找新鲜橘子。
    * 一旦发现新鲜橘子，将其变为腐烂（`1` -> `2`），新鲜橘子计数减一，并将新腐烂的坐标推入队列。
3.  **时间计时**：
    * 每一层（即每一分钟）扩散完后，时间 `time` 加 1。注意：只有当本分钟确实传染了新橘子时，才计入时间。
4.  **最终判定**：
    * 如果最后新鲜橘子数量为 0，返回 `time`；否则返回 `-1`。

---

## 3. Python 代码实现

```python
from collections import deque

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        cols = len(grid[0])
        queue = deque()
        fresh_count = 0
        
        # 1. 遍历网格，初始化：将腐烂橘子入队，统计新鲜橘子数量
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    queue.append((r, c))
                elif grid[r][c] == 1:
                    fresh_count += 1
        
        # 如果一开始就没有新鲜橘子，直接返回 0
        if fresh_count == 0:
            return 0
        
        minutes = 0
        # 2. 多源 BFS 开始
        while queue and fresh_count > 0:
            minutes += 1
            # 记录当前分钟需要处理的腐烂橘子数量（当前层的大小）
            for _ in range(len(queue)):
                r, c = queue.popleft()
                
                # 检查四周
                for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                    nr, nc = r + dr, c + dc
                    
                    # 如果在边界内且是新鲜橘子
                    if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                        # 变腐烂，并入队
                        grid[nr][nc] = 2
                        fresh_count -= 1
                        queue.append((nr, nc))
        
        # 3. 最后判断是否还有新鲜橘子
        return minutes if fresh_count == 0 else -1
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(M \times N)$ | $M$ 和 $N$ 是网格的行数和列数。每个单元格最多被访问一次（入队和出队各一次）。 |
| **空间复杂度** | $O(M \times N)$ | 在最坏情况下（例如网格全为腐烂橘子），队列中存储的元素数量与网格大小成正比。 |

---

## 5. 易错点拨
* **起始状态检查**：如果网格中一开始就没有新鲜橘子，应该返回 `0` 而不是累加后的时间。
* **最后一分钟的判定**：在 BFS 中，最后一层腐烂的橘子入队后，它们可能已经无法再感染任何其他橘子了。此时如果不加控制，`minutes` 可能会多算一次。代码中通过 `fresh_count > 0` 来控制计时逻辑，确保只有发生有效感染才增加分钟。
