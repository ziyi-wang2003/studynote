# LeetCode 207. 课程表 (Course Schedule)

## 1. 题目描述
你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。
在选修某些课程之前需要一些先修课程。 例如，想要学习课程 `0` ，你需要先完成课程 `1` ，我们用一个匹配来表示他们：`[0, 1]`。

给定课程总量以及它们的先修条件，请你判断是否可能完成所有课程的学习？

---

### 示例 1：
* **输入**：`numCourses = 2, prerequisites = [[1,0]]`
* **输出**：`true`
* **解释**：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。

### 示例 2：
* **输入**：`numCourses = 2, prerequisites = [[1,0],[0,1]]`
* **输出**：`false`
* **解释**：总共有 2 门课程。学习课程 1 之前，你需要先完成​课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这形成了一个循环，因此不可能完成。

---

## 2. 核心分析：拓扑排序 (Kahn 算法)
这道题的本质是：**判断一个有向图是否存在环**。如果不存在环（即它是一个有向无环图 DAG），则可以完成所有课程。

### 算法逻辑：
1.  **构建邻接表**：表示课程之间的指向关系。
2.  **统计入度 (In-degree)**：记录每门课程有多少门先修课。
3.  **入队操作**：将所有**入度为 0** 的课程（即没有先修课，可以直接修读的课程）放入队列。
4.  **BFS 遍历**：
    * 从队列中弹出一门课，代表这门课已修完。
    * 将该课指向的所有后续课程的入度减 1。
    * 如果某后续课程的入度减到了 0，则将其入队。
5.  **结果判定**：如果最终修完的课程数等于 `numCourses`，返回 `true`；否则说明图中存在环，返回 `false`。



---

## 3. Python 代码实现

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        # 1. 初始化入度数组和邻接表
        indegrees = [0] * numCourses
        adjacency = [[] for _ in range(numCourses)]
        
        # 2. 填充数据
        # info[0] 是当前课，info[1] 是先修课
        # 关系为：先修课 -> 当前课
        for cur, pre in prerequisites:
            indegrees[cur] += 1
            adjacency[pre].append(cur)
            
        # 3. 将所有入度为 0 的节点入队
        queue = deque([i for i in range(numCourses) if indegrees[i] == 0])
        
        # 记录已经修完的课程数量
        count = 0
        
        # 4. 开始 BFS
        while queue:
            pre = queue.popleft()
            count += 1
            
            # 遍历该先修课指向的所有后续课程
            for cur in adjacency[pre]:
                indegrees[cur] -= 1
                # 如果后续课程的先修课都修完了（入度变 0），则入队
                if indegrees[cur] == 0:
                    queue.append(cur)
                    
        # 5. 如果修完的课程数等于总课程数，说明没有环
        return count == numCourses
```

## 4. 复杂度分析

设 $V$ 为课程数量（`numCourses`），$E$ 为先修关系的数量（`prerequisites.length`）。

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(V + E)$ | 遍历一次先修关系构建图，BFS 过程中每个顶点和每条边最多被访问一次。 |
| **空间复杂度** | $O(V + E)$ | 邻接表占用 $O(V+E)$，入度数组和队列占用 $O(V)$。 |

---

## 5. 重点总结
* **入度 (In-degree)**：在有向图中，指向该顶点的边的数量。
* **入度为 0** 的含义：该任务没有前置条件，可以立即开始。
* **环的存在**：如果图中存在环，那么环内所有节点的入度永远不会减到 0，因此无法进入队列，最终修完的课程数会少于总数。
