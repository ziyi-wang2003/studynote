# LeetCode 49. 字母异位词分组 (Group Anagrams)

## 1. 题目描述
给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

---

### 示例 1：
* **输入**: `strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`
* **输出**: `[["bat"],["nat","tan"],["ate","eat","tea"]]`

---

## 2. 核心分析：哈希表 + 排序
字母异位词的核心特征是：**虽然字母顺序不同，但经过排序后的字符串一定是相同的。**

### 算法逻辑：
1.  **统一标识**：对于每一个单词，将其字符进行升序排序。例如 `"eat"` 和 `"tea"` 排序后都变成 `"aet"`。
2.  **分类存储**：使用一个哈希表（在 Python 中使用 `defaultdict(list)`），将 **排序后的字符串** 作为键（Key），将 **原始单词列表** 作为值（Value）。
3.  **结果导出**：最后返回哈希表中所有的值即可。



---

## 3. Python 代码实现

```python
import collections

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # 使用 defaultdict，当 key 不存在时自动创建一个空列表
        # key: 排序后的字符串, value: 属于该异位词组的所有单词列表
        res = collections.defaultdict(list)

        for word in strs:
            # 1. 将单词排序：'eat' -> ['a', 'e', 't']
            # 2. 将列表拼回字符串：['a', 'e', 't'] -> 'aet'
            # 排序后的字符串作为该组异位词的“唯一标识”
            sort_word = ''.join(sorted(word))
            
            # 3. 将原始单词加入到对应的哈希表分组中
            res[sort_word].append(word)
        
        # 4. 返回哈希表中所有的 value 列表
        return list(res.values())
```

---

## 4. 复杂度分析

设 $N$ 为字符串数组 `strs` 的长度，$K$ 为字符串的最大长度。

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(N \cdot K \log K)$ | 需要遍历 $N$ 个字符串，每个字符串排序耗时 $O(K \log K)$。 |
| **空间复杂度** | $O(N \cdot K)$ | 需要哈希表来存储所有的字符串。 |

---

## 5. 拓展思考：计数法 (优化时间)
如果字符串长度 $K$ 非常大，排序可能会成为瓶颈。由于字符仅包含小写字母，我们可以统计每个单词中 `a-z` 出现的次数（一个长度为 26 的元组），将其作为哈希表的 Key。这样可以将时间复杂度优化到 $O(N \cdot K)$。
