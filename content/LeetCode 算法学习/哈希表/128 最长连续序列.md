# LeetCode 128. 最长连续序列 (Longest Consecutive Sequence)

## 1. 题目描述
给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 $O(n)$ 的算法解决此问题。

---

### 示例 1：
* **输入**：`nums = [100, 4, 200, 1, 3, 2]`
* **输出**：`4`
* **解释**：最长数字连续序列是 `[1, 2, 3, 4]`。它的长度为 4。

---

## 2. 核心分析：哈希集合与起始点判定
要在 $O(n)$ 时间内解决问题，关键在于避免重复枚举序列中的每一个元素。

### 算法逻辑：
1.  **去重与 $O(1)$ 查询**：首先将所有数字存入哈希集合（`set`），这样可以在常数时间内判断某个数字是否存在。
2.  **寻找序列起点**：遍历集合中的每个数字 `num`。
    * **关键判断**：如果 `num - 1` 在集合中，说明 `num` 不是序列的开头（它是某个更长序列的中间部分），直接跳过。
    * **启动计数**：只有当 `num - 1` 不在集合中时，才说明 `num` 是一个新序列的**起点**。
3.  **枚举连续长度**：从起点开始，不断检查 `num + 1, num + 2...` 是否存在，直到序列中断。



---

## 3. Python 代码实现

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        # 1. 使用 set 进行去重，并提供 O(1) 的查询效率
        num_set = set(nums)
        res = 0

        # 2. 遍历集合（注意：遍历 set 比遍历原列表更高效，且处理了重复值）
        for num in num_set:
            # 3. 核心优化：判断 num 是否为序列的“起点”
            # 如果 num - 1 在集合中，说明当前数字已经在某个序列中了
            # 我们只需要从序列的最小值开始计数，从而避免重复计算
            if num - 1 in num_set:
                continue
            
            # 4. 进入计数逻辑（仅对每个序列的起点执行一次）
            curr = num
            length = 1
            # 检查后续数字是否连续存在
            while curr + 1 in num_set:
                curr += 1
                length += 1
            
            # 5. 更新全局最大长度
            res = max(res, length)
        
        return res 
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 虽然有嵌套的 `while` 循环，但由于 `if num-1` 的判定，每个数字实际上只会被访问常数次（一次作为 `num` 遍历，最多一次进入 `while` 循环）。 |
| **空间复杂度** | $O(n)$ | 需要一个哈希集合存储所有的 $n$ 个数字。 |

---

## 5. 重点总结
* **为什么不是 $O(n^2)$？** 许多同学看到循环套循环就觉得是 $O(n^2)$。实际上，内部的 `while` 循环只有在遇到序列起点时才会执行。对于任何一个连续序列，`while` 循环跑完后，序列中的其他成员都会被 `if num - 1 in num_set` 挡住。因此，整个数组的每个元素最多只会被处理两次。
