# LeetCode 48. 旋转图像 (Rotate Image)

### 1. 题目描述
给定一个 $n \times n$ 的二维矩阵 `matrix` 表示图像。请你将图像顺时针旋转 **90** 度。你必须在 **原地** 修改输入矩阵，这意味着你需要直接修改输入的二维矩阵。请不要使用另一个矩阵来旋转图像。

**示例 1：**
> **输入：** matrix = [[1,2,3],[4,5,6],[7,8,9]]  
> **输出：** [[7,4,1],[8,5,2],[9,6,3]]

**示例 2：**
> **输入：** matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]  
> **输出：** [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

---

### 2. 题目分析
直接进行顺时针 90 度旋转的坐标变换较为复杂。通过观察可以发现，**顺时针旋转 90 度** 可以拆解为两个简单的几何变换步骤：

1.  **垂直翻转（上下对折）**：将第一行与最后一行交换，第二行与倒数第二行交换，依此类推。
2.  **主对角线对称轴翻转（矩阵转置）**：沿左上角到右下角的对角线，交换 `matrix[i][j]` 与 `matrix[j][i]`。



**变换推导：**
* 原始坐标：$(i, j)$
* 垂直翻转后：$(n-1-i, j)$
* 对角线翻转后：$(j, n-1-i)$
* 这正是顺时针旋转 90 度后的目标坐标。

---

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        不要返回任何内容，直接原地修改 matrix。
        """
        # 1. 垂直翻转（上下对折）
        # matrix.reverse() 会直接翻转行序列，如：
        # [[1,2,3], [4,5,6], [7,8,9]] -> [[7,8,9], [4,5,6], [1,2,3]]
        matrix.reverse()

        n = len(matrix)

        # 2. 矩阵转置（主对角线翻转）
        # 遍历矩阵的上三角部分 (j > i)，与下三角对应位置交换
        for i in range(0, n - 1):
            for j in range(i + 1, n):
                # 交换 matrix[i][j] 和 matrix[j][i]
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
```

---

### 4. 复杂度分析

* **时间复杂度：$O(N^2)$**
    * `matrix.reverse()` 的时间复杂度为 $O(N)$（交换 $N/2$ 次行引用）。
    * 转置操作使用了嵌套循环，遍历了约一半的矩阵元素，复杂度为 $O(N^2)$。
    * 总体复杂度由元素总数决定。
* **空间复杂度：$O(1)$**
    * 所有操作均在原矩阵上通过元素交换完成，仅使用了常数个额外变量。
