# LeetCode 240. 搜索二维矩阵 II (Search a 2D Matrix II)

### 1. 题目描述
编写一个高效的算法来搜索 $m \times n$ 矩阵 `matrix` 中的一个目标值 `target` 。该矩阵具有以下特性：
* 每行的元素从左到右升序排列。
* 每列的元素从上到下升序排列。

**示例 1：**
> **输入：** matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5  
> **输出：** true

---

### 2. 题目分析
本题利用矩阵的排序特性，可以采用 **“Z字形查找”**（也称为“右上角删减法”）。

**核心思路：**
从矩阵的 **右上角** $(0, n-1)$ 开始搜索：
1.  如果当前值 **等于** `target`，直接返回 `true`。
2.  如果当前值 **大于** `target`，由于列是升序的，当前值下方的所有元素必然都大于 `target`，因此可以排除当前 **列**，向左移动 (`j -= 1`)。
3.  如果当前值 **小于** `target`，由于行是升序的，当前值左侧的所有元素必然都小于 `target`，因此可以排除当前 **行**，向下移动 (`i += 1`)。



这种方法类似于在二叉搜索树中查找，每次比较都能排除掉一行或一列，从而缩小搜索范围。

---

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        # 获取矩阵的行数 m 和列数 n
        m, n = len(matrix), len(matrix[0])

        # 初始化指针，从矩阵的右上角开始 (第一行，最后一列)
        i, j = 0, n - 1

        # 当指针仍在矩阵范围内时进行循环
        while i < m and j >= 0:
            if matrix[i][j] == target:
                # 找到目标值
                return True
            elif matrix[i][j] < target:
                # 当前值小于目标值，说明目标值可能在更下方的行
                # 排除当前行
                i += 1
            else:
                # matrix[i][j] > target
                # 当前值大于目标值，说明目标值可能在更左侧的列
                # 排除当前列
                j -= 1
        
        # 遍历结束仍未找到，返回 False
        return False
```

---

### 4. 复杂度分析

* **时间复杂度：$O(m + n)$**
    * 在最坏的情况下，我们会从右上角移动到左下角。
    * 每次操作都会使 `i` 增加 1 或者 `j` 减少 1。
    * 总共最多移动 $m + n$ 次。
* **空间复杂度：$O(1)$**
    * 只使用了两个指针变量 `i` 和 `j`，不需要额外的存储空间。
