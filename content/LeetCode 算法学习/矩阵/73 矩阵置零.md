# LeetCode 73. 矩阵置零 (Set Matrix Zeroes)

### 1. 题目描述
给定一个 `m x n` 的矩阵，如果一个元素为 **0** ，则将其所在行和列的所有元素都设为 **0** 。请使用 **原地** 算法。

**示例 1：**
> **输入：** matrix = [[1,1,1],[1,0,1],[1,1,1]]  
> **输出：** [[1,0,1],[0,0,0],[1,0,1]]

**示例 2：**
> **输入：** matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]  
> **输出：** [[0,0,0,0],[0,4,5,0],[0,3,1,0]]

---

### 2. 题目分析
解决此题的关键在于**如何标记需要置零的行和列**，同时不使用额外的 $O(mn)$ 或 $O(m+n)$ 空间。

**最优策略：使用原矩阵的第一行和第一列作为标记数组。**

1.  **确定首行首列状态**：首先检查第一行和第一列本身是否包含 0。如果包含，分别用两个布尔变量 `row_zero_flag` 和 `col_zero_flag` 记录（因为第一行和第一列将被用来存储其他行列的状态，其自身原本的状态会被覆盖）。
2.  **标记其他行列**：遍历矩阵中除首行首列外的所有元素 `matrix[i][j]` (其中 $i > 0, j > 0$)。如果 `matrix[i][j] == 0`，则将该行对应的首元素 `matrix[i][0]` 和该列对应的首元素 `matrix[0][j]` 设为 0。
3.  **根据标记置零**：再次遍历除首行首列外的区域。如果 `matrix[i][0] == 0` 或 `matrix[0][j] == 0`，则将 `matrix[i][j]` 置为 0。
4.  **最后处理首行首列**：根据第一步记录的 `row_zero_flag` 和 `col_zero_flag`，决定是否将第一行和第一列全部置零。



---

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        if not matrix or not matrix[0]:
            return
        
        m, n = len(matrix), len(matrix[0])
        
        # 1. 记录第一行和第一列是否原本包含 0
        row_zero_flag = any(matrix[0][j] == 0 for j in range(n))
        col_zero_flag = any(matrix[i][0] == 0 for i in range(m))
        
        # 2. 使用第一行和第一列作为标记位
        # 遍历 matrix[1:][1:]，如果发现 0，则在对应的首行和首列做标记
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0
        
        # 3. 根据首行和首列的标记，将对应的内部元素置零
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        
        # 4. 最后单独处理第一行
        if row_zero_flag:
            for j in range(n):
                matrix[0][j] = 0
                
        # 5. 最后单独处理第一列
        if col_zero_flag:
            for i in range(m):
                matrix[i][0] = 0
```

### 4. 复杂度分析

* **时间复杂度：$O(m \times n)$**
    * 需要遍历矩阵两次：第一次用于设置标记，第二次用于根据标记更新数值。处理首行首列的时间复杂度为 $O(m+n)$。总操作次数与矩阵元素个数成正比。
* **空间复杂度：$O(1)$**
    * 除了使用了常数级的变量（`row_zero_flag`, `col_zero_flag`）外，所有的标记操作都在原矩阵内部完成，没有申请额外的数组或哈希表。
