# LeetCode 3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

## 1. 题目描述
给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

---

### 示例 1：
* **输入**: `s = "abcabcbb"`
* **输出**: `3` 
* **解释**: 因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。

### 示例 2：
* **输入**: `s = "pwwkew"`
* **输出**: `3`
* **解释**: 因为无重复字符的最长子串是 `"wke"`，所以其长度为 3。请注意，你的答案必须是 **子串** 的长度，`"pwke"` 是一个子序列，不是子串。

---

## 2. 核心分析：滑动窗口 (Sliding Window)
为了在一次遍历中解决问题，我们使用“滑动窗口”技术，维护一个不包含重复字符的动态窗口 `[left, right]`。

### 算法逻辑：
1.  **哈希表记录**：使用字典 `dic` 记录每个字符**最后一次出现的索引位置**。
2.  **移动右边界 (`right`)**：遍历字符串，逐个将字符加入窗口。
3.  **更新左边界 (`left`)**：
    * 如果当前字符 `s[right]` 已经在哈希表中，说明遇到了重复。
    * 为了保证窗口内没有重复，左边界 `left` 必须跳到 `dic[s[right]] + 1` 的位置。
    * **注意**：为了防止 `left` 向左回跳（例如处理 "abba" 时），需要取 `max(left, dic[s[right]] + 1)`。
4.  **计算长度**：每次移动右边界后，计算当前窗口长度 `right - left + 1`，并更新全局最大值。



---

## 3. Python 代码实现

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 哈希表记录字符最后出现的索引位置
        char_map = {}
        # 左指针
        left = 0
        # 结果最大长度
        max_len = 0
        
        # right 指针遍历整个字符串
        for right in range(len(s)):
            # 如果当前字符在哈希表中，说明之前出现过
            if s[right] in char_map:
                # 更新左指针位置
                # 取 max 是为了防止 left 指针往回跳（例如 "abba" 字符串）
                left = max(left, char_map[s[right]] + 1)
            
            # 更新/记录当前字符的最新位置
            char_map[s[right]] = right
            
            # 计算当前窗口长度：右指针 - 左指针 + 1
            max_len = max(max_len, right - left + 1)
            
        return max_len
```

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | $n$ 是字符串长度，只需要对字符串进行一次线性扫描。 |
| **空间复杂度** | $O(min(m, n))$ | $m$ 是字符集的大小（如 ASCII 字符集为 128）。哈希表存储的键值对数量取决于字符集大小和字符串长度的较小值。 |

---

## 5. 重点总结
* **子串 vs 子序列**：子串必须是原字符串中**连续**的一段；子序列可以不连续。
* **滑动窗口思想**：通过移动左右边界，将寻找所有子串的 $O(n^2)$ 过程优化为 $O(n)$。
* **左边界更新策略**：使用哈希表直接跳转 `left` 指针，比逐个删除窗口左侧元素的效率更高。
