# LeetCode 438. 找到字符串中所有字母异位词 (Find All Anagrams in a String)

## 1. 题目描述
给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **字母异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**字母异位词** 指字母相同，但排列不同的字符串。

**示例 1：**
* **输入**: `s = "cbaebabacd", p = "abc"`
* **输出**: `[0, 6]`
* **解释**:
    起始索引等于 0 的子串是 "cba", 它是 "abc" 的字母异位词。
    起始索引等于 6 的子串是 "bac", 它是 "abc" 的字母异位词。

---

## 2. 核心分析：定长滑动窗口
由于字母异位词的长度必须与字符串 `p` 的长度相同，因此我们可以使用一个**固定长度为 `len(p)`** 的滑动窗口在 `s` 上移动。

**算法逻辑：**
1.  **频率统计**：使用数组或哈希表统计字符串 `p` 中每个字符出现的频次。由于只包含小写字母，使用长度为 26 的数组即可。
2.  **初始化窗口**：先统计 `s` 中前 `len(p)` 个字符的频次。
3.  **滑动并比较**：
    * 比较当前窗口的频次数组与 `p` 的频次数组是否相同。若相同，记录起始索引。
    * 窗口向右滑动：右边新进一个字符，左边移出一个字符，更新频次数组。
4.  **边界处理**：如果 `len(s) < len(p)`，直接返回空列表。



---

## 3. Python 代码实现

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        s_len, p_len = len(s), len(p)
        if s_len < p_len:
            return []

        res = []
        # 使用长度为 26 的数组统计字符频率（a-z）
        p_count = [0] * 26
        s_count = [0] * 26

        # 1. 统计 p 的字符频率，并初始化 s 的第一个窗口
        for i in range(p_len):
            p_count[ord(p[i]) - ord('a')] += 1
            s_count[ord(s[i]) - ord('a')] += 1

        # 2. 检查初始窗口是否匹配
        if s_count == p_count:
            res.append(0)

        # 3. 开始滑动窗口
        # 窗口范围：[left, right]，长度固定为 p_len
        for i in range(s_len - p_len):
            # 移除窗口最左边的字符
            s_count[ord(s[i]) - ord('a')] -= 1
            # 加入窗口右边的新字符
            s_count[ord(s[i + p_len]) - ord('a')] += 1
            
            # 比较当前窗口和 p 的频率数组
            # 在 Python 中，数组/列表相等比较的时间复杂度是 O(字符集大小)，即 O(26)
            if s_count == p_count:
                res.append(i + 1)

        return res
```

---

## 4. 复杂度分析

设 $n$ 为字符串 `s` 的长度，$m$ 为字符串 `p` 的长度，$\Sigma$ 为字符集大小（此处为小写字母，大小为 26）。

| 维度 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 窗口滑动 $n$ 次。虽然每次比较了频率数组，但由于数组长度固定为 26，比较操作耗时 $O(26)$，属于常数级别，总复杂度为 $O(n \times 26)$，即 $O(n)$。 |
| **空间复杂度** | $O(\Sigma)$ | 使用了两个长度为 26 的数组，空间消耗与输入字符串长度无关，仅与字符集大小有关。 |

---

## 5. 重点总结
* **定长窗口**：这是解决“子串与目标串长度一致”类问题的标准模板。
* **数组比较**：对于仅包含小写字母的题目，使用 `[0]*26` 的数组比使用哈希表（Dictionary）效率更高，且在 Python 中直接用 `==` 比较两个列表非常方便。
* **优化技巧**：如果想进一步优化，可以维护一个 `diff` 变量记录两个数组中不同频次的字符个数，从而将每次滑动的比较复杂度从 $O(26)$ 降至 $O(1)$，但在面试中，上述代码已经足够优秀且易于理解。
