# LeetCode 1143. 最长公共子序列 (Longest Common Subsequence, LCS)

### 1. 题目描述
给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在公共子序列，返回 `0` 。

**子序列** 是指从原字符串中删去若干个（也可以不删）字符后形成的新字符串，且剩余字符的相对顺序不变（例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是）。

**示例：**
> **输入：** text1 = "abcde", text2 = "ace"  
> **输出：** 3  
> **解释：** 最长公共子序列是 "ace" ，它的长度为 3 。

---

### 2. 题目分析
这是动态规划中最经典的**双序列**问题。

**核心思想：**
我们需要通过比较 `text1` 的前 $i$ 个字符和 `text2` 的前 $j$ 个字符，来推导它们的最长公共子序列长度。



**状态转移方程：**
设 `dp[i][j]` 表示 `text1[0...i-1]` 和 `text2[0...j-1]` 的最长公共子序列长度：

1.  **如果 `text1[i-1] == text2[j-1]`**：
    *   说明当前这两个字符可以作为公共子序列的一部分。
    *   长度等于“去掉这两个字符后的结果”再加 1。
    *   **$dp[i][j] = dp[i-1][j-1] + 1$**
2.  **如果 `text1[i-1] != text2[j-1]`**：
    *   说明这两个字符不可能同时出现在同一个 LCS 的末尾。
    *   此时我们需要看：是保留 `text1[i-1]` 放弃 `text2[j-1]` 结果更好，还是反之。
    *   **$dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$**

---

### 3. 代码实现 (Python)

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)

        # 1. 初始化 dp 矩阵
        # 维度为 (m+1) x (n+1)，多出的一行一列代表空字符串的情况
        # dp[i][0] 和 dp[0][j] 默认初始为 0
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 2. 填充 dp 矩阵
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 如果字符相等
                if text1[i-1] == text2[j-1]:
                    # 来自左上方对角线 + 1
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    # 如果字符不等，取左方或上方的最大值
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        
        # 3. 返回右下角最终结果
        return dp[m][n]
```

---

### 4. 为什么 `dp` 数组的大小是 `(m+1) x (n+1)`？
*   **处理边界**：当其中一个字符串为空时，公共子序列长度显然为 0。通过增加“第 0 行”和“第 0 列”，我们可以避免在循环内编写复杂的 `if i == 0` 或 `if j == 0` 判断。
*   **对应关系**：`dp[i][j]` 对应的是字符串中下标为 `i-1` 和 `j-1` 的字符。

---

### 5. 复杂度分析

*   **时间复杂度：$O(M \times N)$**
    *   其中 $M$ 和 $N$ 分别是两个字符串的长度。我们需要填满整个二维矩阵。
*   **空间复杂度：$O(M \times N)$**
    *   使用了二维数组存储状态。
    *   *注：可以使用滚动数组优化到 $O(\min(M, N))$，但面试中写出二维版本通常已足够。*
