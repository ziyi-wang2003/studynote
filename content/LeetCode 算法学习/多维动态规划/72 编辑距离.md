# LeetCode 72. 编辑距离 (Edit Distance)

### 1. 题目描述
给你两个单词 `word1` 和 `word2`， 请返回将 `word1` 转换成 `word2` 所使用的 **最少操作数** 。

你可以对一个单词进行如下三种操作：
*   **插入**一个字符
*   **删除**一个字符
*   **替换**一个字符

**示例：**
> **输入：** word1 = "horse", word2 = "ros"  
> **输出：** 3  
> **解释：**  
> horse -> rorse (将 'h' 替换为 'r')  
> rorse -> rose (删除 'r')  
> rose -> ros (删除 'e')

---

### 2. 题目分析
这是动态规划中解决 **字符串匹配/转换** 类问题的天花板级别题目。

**状态定义：**
设 `dp[i][j]` 表示将 `word1` 的前 `i` 个字符转换成 `word2` 的前 `j` 个字符所需要的最少操作数。

**状态转移方程：**
1.  **如果 `word1[i-1] == word2[j-1]`**：
    *   当前字符相等，不需要任何操作。
    *   `dp[i][j] = dp[i-1][j-1]`
2.  **如果 `word1[i-1] != word2[j-1]`**，我们需要从三种操作中选代价最小的：
    *   **替换**：将 `word1[i-1]` 换成 `word2[j-1]`。对应 `dp[i-1][j-1] + 1`。
    *   **删除**：把 `word1[i-1]` 删掉。对应 `dp[i-1][j] + 1`。
    *   **插入**：在 `word1` 末尾加一个跟 `word2[j-1]` 一样的字符。对应 `dp[i][j-1] + 1`。
    *   **$dp[i][j] = \min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1$**

---

### 3. 代码实现 (Python)

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)

        # 1. 初始化 dp 矩阵 (m+1) x (n+1)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 2. 边界初始化
        # 当 word2 为空，要把 word1 全删了，操作数就是 i
        for i in range(m + 1):
            dp[i][0] = i 
        # 当 word1 为空，要在 word1 里不停插入，操作数就是 j
        for j in range(n + 1):
            dp[0][j] = j

        # 3. 填充状态表
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 字符相等，继承左上方的值
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                # 字符不等，取 (替换、删除、插入) 三者中的最小值 + 1
                else:
                    dp[i][j] = min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1
        
        return dp[m][n]
```

---

### 4. 逻辑要点：为什么 `dp[i][j-1]` 是插入？
很多人在这里会绕晕。其实逻辑是这样的：
*   `dp[i-1][j]`：已经把 `word1` 前 `i-1` 个变好了，现在多出一个 `word1[i]`，把它**删了**就行。
*   `dp[i][j-1]`：已经把 `word1` 前 `i` 个变成 `word2` 前 `j-1` 个了，还差一个 `word2[j]`，直接在 `word1` 后面**插入**一个。

---

### 5. 复杂度分析

*   **时间复杂度：$O(M \times N)$**
    *   其中 $M, N$ 为两个字符串的长度。
*   **空间复杂度：$O(M \times N)$**
    *   创建了一个二维数组。同样可以使用滚动数组优化到 $O(\min(M, N))$。

### 6. 个人碎碎念
这道题和 **最长公共子序列 (LCS)** 非常像，区别在于 LCS 字符不等时是取 `max`（找相同），而编辑距离不等时是取 `min + 1`（找最少改动）。把这两道题放一起看，动态规划的真谛就掌握一半了。
