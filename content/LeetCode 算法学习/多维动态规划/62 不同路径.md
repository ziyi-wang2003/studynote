# LeetCode 62. 不同路径 (Unique Paths)

### 1. 题目描述
一个机器人位于一个 `m x n` 网格的左上角。机器人每次只能 **向下** 或者 **向右** 移动一步。机器人试图达到网格的右下角。问总共有多少条不同的路径？

**示例 1：**
> **输入：** m = 3, n = 7  
> **输出：** 28

**示例 2：**
> **输入：** m = 3, n = 2  
> **输出：** 3  
> **解释：** 从左上角开始，总共有 3 条路径可以到达右下角：
> 1. 向右 -> 向下 -> 向下
> 2. 向下 -> 向下 -> 向右
> 3. 向下 -> 向右 -> 向下

---

### 2. 题目分析
这是一个经典的 **动态规划 (Dynamic Programming)** 问题。

**核心逻辑：**
1.  **状态定义**：设 `dp[i][j]` 为到达坐标 `(i, j)` 的不同路径总数。
2.  **状态转移方程**：由于机器人只能向右或向下移动，那么要到达 `(i, j)`，它只能从 `(i-1, j)`（上方）或者 `(i, j-1)`（左方）走过来。
    *   $$dp[i][j] = dp[i-1][j] + dp[i][j-1]$$
3.  **边界条件**：
    *   第一行 `dp[0][j]`：只能一直向右走，路径数均为 1。
    *   第一列 `dp[i][0]`：只能一直向下走，路径数均为 1。

---

### 3. 代码实现 (Python)

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 1. 初始化 DP 数组，将所有位置初始设为 1
        # 这同时也处理了第一行和第一列的边界条件（它们的值始终为 1）
        dp = [[1] * n for _ in range(m)]

        # 2. 从 (1, 1) 开始填充数组
        for i in range(1, m):
            for j in range(1, n):
                # 到达当前格子的路径数 = 上方路径数 + 左方路径数
                dp[i][j] = dp[i-1][j] + dp[i][j-1]
            
        # 3. 返回右下角的值
        return dp[m-1][n-1]
```

---

### 4. 优化建议：空间压缩
观察发现，`dp[i][j]` 仅依赖于“当前行”的左边值和“上一行”的同位置值。因此我们可以将二维空间优化为一维：
```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 使用一维数组记录当前行的路径数
        row = [1] * n
        for i in range(1, m):
            for j in range(1, n):
                # row[j] 还没更新前代表上一行同列的值，row[j-1] 代表当前行左侧值
                row[j] += row[j-1]
        return row[n-1]
```

---

### 5. 复杂度分析

*   **时间复杂度：$O(m \times n)$**
    *   需要遍历整个 $m \times n$ 的矩阵一次。
*   **空间复杂度：$O(m \times n)$**
    *   使用了二维数组存储状态（若使用一维数组优化则为 $O(n)$）。
