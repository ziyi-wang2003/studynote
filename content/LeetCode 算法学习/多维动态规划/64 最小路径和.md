# LeetCode 64. 最小路径和 (Minimum Path Sum)

### 1. 题目描述
给定一个包含非负整数的 `m x n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：** 每次只能向下或者向右移动一步。

**示例 1：**
> **输入：** grid = [[1,3,1],[1,5,1],[4,2,1]]  
> **输出：** 7  
> **解释：** 因为路径 1→3→1→1→1 的总和最小。

**示例 2：**
> **输入：** grid = [[1,2,3],[4,5,6]]  
> **输出：** 12

---

### 2. 题目分析
这是一个经典的 **动态规划 (Dynamic Programming)** 问题。由于每次只能向右或向下移动，到达当前格子的路径只可能来自**左边**或**上边**。

**状态转移方程：**
设 $dp[i][j]$ 为到达坐标 $(i, j)$ 的最小路径和：
1.  **起点**：$dp[0][0] = grid[0][0]$
2.  **第一行**（只能从左边来）：$dp[0][j] = dp[0][j-1] + grid[0][j]$
3.  **第一列**（只能从上边来）：$dp[i][0] = dp[i-1][0] + grid[i][0]$
4.  **普通格子**：$dp[i][j] = \min(dp[i-1][j], dp[i][j-1]) + grid[i][j]$

**优化：**
为了节省空间，我们可以直接在原矩阵 `grid` 上进行修改（原地 DP），将空间复杂度从 $O(mn)$ 降低到 $O(1)$。

---

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        # 获取矩阵的行数和列数
        m, n = len(grid), len(grid[0])

        # 1. 初始化第一列：每个位置的值等于自身加上方的累积和
        for i in range(1, m):
            grid[i][0] += grid[i-1][0]
            
        # 2. 初始化第一行：每个位置的值等于自身加左方的累积和
        for j in range(1, n):
            grid[0][j] += grid[0][j-1]
        
        # 3. 填充剩余网格
        for i in range(1, m):
            for j in range(1, n):
                # 到达当前格子的最小路径 = 当前值 + min(左方值, 上方值)
                grid[i][j] += min(grid[i-1][j], grid[i][j-1])
        
        # 返回右下角的最终结果
        return grid[m-1][n-1]
```

---

### 4. 复杂度分析

* **时间复杂度：$O(m \times n)$**
    * 我们需要遍历整个矩阵一次来更新每个格子的值。
* **空间复杂度：$O(1)$**
    * 代码直接在原始输入的 `grid` 矩阵上进行累加操作，没有使用额外的辅助空间（如额外的 DP 数组）。注意，某些面试场合如果不允许修改原数据，则空间复杂度为 $O(mn)$ 或通过滑动数组优化至 $O(n)$。
