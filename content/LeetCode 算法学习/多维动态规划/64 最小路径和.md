# LeetCode 62. 不同路径 (Unique Paths)

## 题目描述
一个机器人位于一个 $m \times n$ 网格的左上角（起始点在下图中标记为 “Start” ）。
机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。
问总共有多少条不同的路径？

### 示例：
**输入：** `m = 3, n = 7`
**输出：** `28`

**输入：** `m = 3, n = 2`
**输出：** `3`
**解释：**
从左上角开始，总共有 3 条路径可以到达右下角：
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下

---

## 题目分析
这是一个典型的坐标类 **动态规划 (Dynamic Programming)** 问题。

### 核心思路
1.  **状态定义**：设 `dp[i][j]` 为到达网格中 $(i, j)$ 位置的不同路径总数。
2.  **转移方程**：
    * 机器人只能从 **左边** 或 **上边** 走过来。
    * 因此，到达 $(i, j)$ 的路径数等于到达其左边格子的路径数加上到达其上边格子的路径数。
    * 方程：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`
3.  **边界条件**：
    * 第一行的所有格子 `dp[0][j]` 只有一种走法（一直向右）。
    * 第一列的所有格子 `dp[i][0]` 只有一种走法（一直向下）。
    * 初始值：`dp[0][0] = 1`。



### 空间优化
由于 `dp[i][j]` 仅依赖于上一行 `dp[i-1][j]` 和左侧 `dp[i][j-1]`，我们可以将二维数组压缩为一维数组 `dp[j]`，实时更新当前行。

---

## Python 代码实现 (空间优化版)

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 1. 空间优化：只使用一维数组记录当前行的路径数
        # 初始化第一行，所有位置的路径数均为 1
        dp = [1] * n
        
        # 2. 从第二行开始（i=1），计算到第 m 行
        for i in range(1, m):
            # 3. 从左往右更新，j=0（第一列）始终为 1，所以从 j=1 开始
            for j in range(1, n):
                # 当前位置的路径数 = 上方格子的路径数 (旧的 dp[j]) 
                #                   + 左方格子的路径数 (刚更新的 dp[j-1])
                dp[j] = dp[j] + dp[j-1]
                
        # 4. 最后一个元素即为到达右下角的路径数
        return dp[-1]
```

---

## 复杂度分析

### 时间复杂度
* **$O(m \times n)$**：我们需要遍历整个网格的所有单元格（除了第一行和第一列）。

### 空间复杂度
* **$O(n)$**：通过一维数组优化，我们只需要存储一行的数据。

## 补充（数学解法）
该问题本质上是一个组合问题。机器人总共需要走 $(m-1) + (n-1)$ 步，其中必须有 $m-1$ 步向下走。因此，结果等于从总步数中选出向下步数的组合数：
$$C_{m+n-2}^{m-1} = \frac{(m+n-2)!}{(m-1)!(n-1)!}$$
