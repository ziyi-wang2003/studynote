# LeetCode 5. 最长回文子串 (Longest Palindromic Substring)

### 1. 题目描述
给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**示例 1：**
> **输入：** s = "babad"  
> **输出：** "bab"  
> **解释：** "aba" 同样也是符合题意的答案。

**示例 2：**
> **输入：** s = "cbbd"  
> **输出：** "bb"

---

### 2. 题目分析
回文串具有高度的对称性。除了使用动态规划，最直观且高效的方法是 **中心扩展法 (Center Expansion)**。

**核心思想：**
1.  **遍历中心**：回文串一定有一个中心。我们可以遍历字符串中的每一个位置，假设它是回文串的中心，然后尝试向两边扩展。
2.  **处理奇偶**：
    *   **奇数长度**：中心是一个字符，如 `aba`，中心是 `b`。
    *   **偶数长度**：中心是两个字符之间的间隙，如 `abba`，中心是 `bb`。
3.  **扩展逻辑**：只要左右两侧的字符相等，就继续向外扩展；一旦不相等或触碰边界，停止扩展并记录此时的边界。
4.  **全局更新**：对比每次扩展得到的长度，保留最长的那一个。

---

### 3. 代码实现 (Python)

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        # 辅助函数：从给定的左、右索引开始向两边扩展
        def expand(left, right):
            # 当满足：索引不越界 且 左右字符相等 时，继续扩展
            while 0 <= left and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            # 注意：退出循环时，s[left] != s[right]，
            # 所以实际回文区域是 (left + 1) 到 (right - 1)
            return left + 1, right - 1
        
        start, end = 0, 0
        for i in range(len(s)):
            # 1. 奇数长度扩展：以 i 为中心（如 aba）
            left1, right1 = expand(i, i)
            # 2. 偶数长度扩展：以 i 和 i+1 之间的间隙为中心（如 abba）
            left2, right2 = expand(i, i + 1)

            # 更新全局最长回文串的起始和结束索引
            if right1 - left1 > end - start:
                start, end = left1, right1
            if right2 - left2 > end - start:
                start, end = left2, right2
        
        # 切片返回最长子串，注意 end+1
        return s[start:end + 1]
```

---

### 4. 复杂度分析

*   **时间复杂度：$O(N^2)$**
    *   其中 $N$ 是字符串的长度。我们需要遍历 $N$ 个中心，每个中心最多向外扩展 $O(N)$ 次。
*   **空间复杂度：$O(1)$**
    *   只使用了常数个变量来存储索引。相对于动态规划 $O(N^2)$ 的空间复杂度，中心扩展法更加节省内存。

---

### 5. 算法小贴士
*   **为什么不用 DP？** DP 法的空间复杂度较高。而中心扩展法逻辑简单且空间极省。
*   **进阶：** 如果面试中被要求 $O(N)$ 的时间复杂度，那考察的是 **Manacher 算法 (马拉车算法)**，但该算法极其复杂，通常掌握中心扩展法已足够应对绝大多数场景。
