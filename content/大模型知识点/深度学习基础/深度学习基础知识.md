# 深度神经网络核心组件与训练技术

现代深度学习的成功建立在大量精巧设计之上，从基础的前馈计算单元到训练过程中的动态调整策略，每一环节都对最终模型的收敛速度、稳定性和泛化能力有决定性的影响。本笔记以系统化视角梳理多层感知机、激活函数、反向传播、参数初始化、优化算法、学习率调度、正则化、归一化技术、残差连接以及序列建模基础，刻画这些组件相互协同的完整图景。

## 多层感知机与前向传播

多层感知机（MLP）是最基本的前馈神经网络结构，其设计动机在于打破线性模型的局限性。若无非线性变换，多个线性层的叠加将退化为单个线性映射，表达能力等同于线性分类器。MLP 通过交替堆叠线性变换与非线性激活函数，使模型能够学习输入与输出之间的复杂高维映射。

形式上，一个 \(L\) 层的 MLP 以输入向量 \(\mathbf{x} = \mathbf{a}^{(0)}\) 出发，按层执行如下计算：
\[
\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}, \quad \mathbf{a}^{(l)} = \sigma\!\left(\mathbf{z}^{(l)}\right), \quad l = 1, \dots, L,
\]
其中 \(\mathbf{W}^{(l)} \in \mathbb{R}^{d_l \times d_{l-1}}\) 为第 \(l\) 层的权重矩阵，\(\mathbf{b}^{(l)}\) 为偏置向量，\(\sigma(\cdot)\) 是激活函数。最后一层的输出通常根据任务目标再经过特定输出函数（如 softmax 或恒等映射）。整个计算过程从输入层向输出层逐层推进，称为**前向传播**。在训练中，前向传播不仅产生预测值，还需要缓存每一层的输入 \(\mathbf{a}^{(l-1)}\) 与激活前的 \(\mathbf{z}^{(l)}\)，以供后续反向传播计算梯度。

## 激活函数

激活函数的核心任务是引入**非线性**，同时其导数特性对梯度传播至关重要。早期常用的 Sigmoid 与 Tanh 因饱和区导数趋近于零，容易导致训练深层网络时的梯度消失。以下三种现代激活函数在不同场景下被广泛采纳。

**ReLU（Rectified Linear Unit）** 定义为
\[
\operatorname{ReLU}(x) = \max(0, x).
\]
其梯度在正半轴恒为 1，避免了饱和问题，大幅缓解了梯度消失，并且计算极其简单。但负半轴梯度为零会导致部分神经元永久停止更新，称为“死亡 ReLU”现象。

**GELU（Gaussian Error Linear Unit）** 引入概率视角，将输入乘以标准正态分布的累积概率：
\[
\operatorname{GELU}(x) = x \,\Phi(x) = x \cdot \frac{1}{2}\left[1 + \operatorname{erf}\!\left(\frac{x}{\sqrt{2}}\right)\right],
\]
常用其快速近似形式
\[
\operatorname{GELU}(x) \approx 0.5x\left(1 + \tanh\!\left(\sqrt{\frac{2}{\pi}}\left(x + 0.044715x^3\right)\right)\right).
\]
GELU 在全区间光滑，且对输入具有随机正则化的解释，被 BERT 和 GPT 等 Transformer 模型普遍采用。

**Swish**（也记为 SiLU）定义为
\[
\operatorname{Swish}(x) = x\,\sigma(x) = \frac{x}{1 + e^{-x}}.
\]
它是一种自门控激活函数，拥有非单调的平滑形状。在较大正值区域近似线性，在负值区域趋近于零且保留微小梯度。搜索和实验表明 Swish 在深层网络中常优于 ReLU，在 EfficientNet 等架构中成为默认选择。

## 反向传播与链式法则

神经网络的训练依赖梯度下降及其变体，而梯度的计算由**反向传播**算法完成。反向传播本质上是微积分中链式法则在计算图上的高效实现。

考虑标量损失 \(\mathcal{L}\)，对第 \(l\) 层的权重 \(\mathbf{W}^{(l)}\) 的梯度可组织为：
\[
\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}} = \boldsymbol{\delta}^{(l)} \big(\mathbf{a}^{(l-1)}\big)^\mathsf{T},
\quad
\boldsymbol{\delta}^{(l)} = \frac{\partial \mathcal{L}}{\partial \mathbf{z}^{(l)}} = \left(\big(\mathbf{W}^{(l+1)}\big)^\mathsf{T} \boldsymbol{\delta}^{(l+1)}\right) \odot \sigma'(\mathbf{z}^{(l)}),
\]
其中 \(\odot\) 表示逐元素乘积，\(\sigma'\) 为激活函数的导数。误差向量 \(\boldsymbol{\delta}^{(l)}\) 从输出层开始递归计算，逐层向后传播。这一公式直观表明，深层梯度的量级由权重矩阵的连乘和激活导数的连乘共同决定。

**梯度消失与梯度爆炸**正源于这种连乘结构。若各层的权重矩阵的谱范数与激活导数的乘积系统性地小于 1，反向传播的梯度将指数级衰减，浅层参数几乎无法学习；若该乘积系统性地大于 1，则梯度指数级增长，导致更新量巨大进而训练崩溃。因此，激活函数的导数尺度（如 ReLU 正半轴为 1）与权重的合理初始范围共同决定了深层网络的训练可行性。

## 参数初始化

在训练开始时赋予权重恰当的初始值，可以使前向信号和反向梯度的方差在网络层间保持稳定，从根本上抑制梯度消失与爆炸。两种主流初始化策略分别针对不同的激活函数设计。

**Xavier 初始化**（Glorot 初始化）基于“线性激活”假设（如 Tanh 中心区域），同时考虑前向传播与反向传播的方差一致性，推导出权重方差应满足：
\[
\operatorname{Var}[W] = \frac{2}{n_{\text{in}} + n_{\text{out}}},
\]
其中 \(n_{\text{in}}\) 和 \(n_{\text{out}}\) 分别为该层输入与输出维度。通常从均匀分布 \(\mathcal{U}\big[-\frac{\sqrt{6}}{\sqrt{n_{\text{in}}+n_{\text{out}}}},\frac{\sqrt{6}}{\sqrt{n_{\text{in}}+n_{\text{out}}}}\big]\) 或相应正态分布中采样。该初始化适合与 Sigmoid、Tanh 等激活函数配合。

**Kaiming 初始化**（He 初始化）针对 ReLU 及其变体设计，考虑到 ReLU 将负半轴置零导致输出方差减半的特性，修正方差条件为：
\[
\operatorname{Var}[W] = \frac{2}{n_{\text{in}}}.
\]
实践中常以均值为 0、标准差为 \(\sqrt{2 / n_{\text{in}}}\) 的正态分布进行采样。当使用 Leaky ReLU 等推广时，方差系数可乘上相应的增益，公式化为 \(\operatorname{Var}[W] = \text{gain}^2 / n_{\text{in}}\)。Kaiming 初始化使带 ReLU 的深层网络能够顺畅训练，成为卷积神经网络与 MLP 的事实标准。

## 优化算法

给定梯度，如何更新参数直接影响收敛速度与最终精度。以下从基础随机梯度下降逐步演进到现代自适应优化器，并重点讨论权重衰减的精确处理。

**朴素的 SGD** 仅按学习率 \(\eta\) 沿负梯度方向移动：
\[
\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \mathbf{g}_t,
\]
其中 \(\mathbf{g}_t = \nabla_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta}_t)\)。SGD 在陡峭方向上易产生剧烈震荡，且收敛缓慢。

**动量法** 引入速度变量以累积历史梯度，平滑更新方向：
\[
\mathbf{v}_t = \beta \mathbf{v}_{t-1} + (1 - \beta) \mathbf{g}_t, \quad
\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \mathbf{v}_t,
\]
其中 \(\beta \in [0, 1)\) 控制动量记忆，通常取 0.9。动量在持续下降方向上加速，在震荡方向上互相抵消，显著加快收敛。

**Adam** 将动量与自适应学习率相结合，维护梯度的一阶矩 \(\mathbf{m}_t\) 和二阶矩 \(\mathbf{v}_t\) 的指数滑动平均：
\[
\mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1 - \beta_1) \mathbf{g}_t, \quad
\mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1 - \beta_2) \mathbf{g}_t^2.
\]
为消除初始时刻估计的偏差，进行偏差校正：
\[
\hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1 - \beta_1^t}, \quad
\hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1 - \beta_2^t}.
\]
参数更新公式为
\[
\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \varepsilon}.
\]
每个参数依据自身梯度历史获得独立的自适应步长，Adam 因此对超参数具有较强的鲁棒性。

**AdamW 与权重衰减解耦** 此处必须严格区分**权重衰减**和 **L2 正则化**。L2 正则化在损失函数上添加惩罚 \(\frac{\lambda}{2}\|\boldsymbol{\theta}\|^2\)，从而梯度变为 \(\mathbf{g}_{\text{total}} = \mathbf{g} + \lambda \boldsymbol{\theta}\)。在 SGD 的更新中，这一梯度直接导致更新包含 \(-\eta \lambda \boldsymbol{\theta}\) 项，等同于权重衰减。然而在 Adam 框架下，该 \(\lambda \boldsymbol{\theta}\) 项同时被融入一阶矩和二阶矩的滑动平均，并通过自适应系数 \(1/(\sqrt{\hat{\mathbf{v}}_t} + \varepsilon)\) 缩放，使得实际施加在参数上的衰减强度受历史梯度方差调制，**不再等价于直接按比例缩减权重**。

**AdamW** 将权重衰减从自适应梯度计算中解耦，直接在参数更新时施加衰减：
\[
\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \left( \frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \varepsilon} + \lambda \boldsymbol{\theta}_t \right).
\]
这种形式使衰减强度严格由超参数 \(\lambda\) 和 \(\eta\) 协同控制，而不受自适应步长干扰，在实践中往往获得更好的泛化性能和对复杂损失曲面的适应能力。

## 学习率调度

学习率的大小直接影响每次参数更新的幅度，合理的学习率计划可以在训练的不同阶段平衡收敛速度与稳定性。

**预热** 指在训练初始的若干步内，将学习率从一个极小值线性地增加到设定的基学习率。该策略的动机在于：训练的早期，模型参数处于随机初始化状态，梯度的统计量（尤其是 Adam 中的二阶矩）极不稳定，若骤然使用较大学习率可能导致参数被推向次优区域甚至引发发散。通过逐步预热，优化器得以积累稳健的梯度统计信息，从而在稳定状态下进入常规训练。

**余弦退火** 使学习率依照余弦曲线递减：
\[
\eta_t = \eta_{\min} + \frac{1}{2} (\eta_{\max} - \eta_{\min}) \left(1 + \cos\!\left(\pi \frac{t}{T}\right)\right),
\]
其中 \(T\) 为一个周期内的总步数。该调度在开始时缓慢衰减，中间加速衰减，末尾变化再次平缓，常配合周期重启使用，以帮助优化器逃离局部极小值。

**Noam 调度** 来自 Transformer 的原始工作，结合了热身与平方根倒数衰减，形式为：
\[
\eta_t = d_{\text{model}}^{-0.5} \cdot \min\left(t^{-0.5}, \, t \cdot w^{-1.5}\right),
\]
其中 \(d_{\text{model}}\) 为模型的特征维度，\(w\) 为预热步数。其设计思想是：在预热阶段学习率呈线性增长，之后按步数的平方根倒数逐渐衰减，使得参数更新在早期不过于剧烈，后期以稳定幅度精细调整。该调度与本模型架构紧密关联，实践中往往被更通用的余弦或线性策略取代。

## 正则化

正则化旨在缩小训练误差与测试误差之间的鸿沟，防止模型记忆噪声而损害泛化能力。

**Dropout** 在训练过程中以概率 \(p\) 随机将部分神经元的输出置为零，同时将保留的神经元输出乘以 \(1/(1-p)\)（即 inverted dropout）。这一操作相当于每次迭代只训练一个稀疏子网络，推理时则使用完整网络，可视为对指数级子网络进行几何平均的近似集成。Dropout 能够有效抑制神经元间的共适应，使网络学习更鲁棒的特征。实际使用时需注意不同位置（如注意力权重上）是否适用，现代 Transformer 中通常仅在 MLP 子层或嵌入层上使用 Dropout。

**权重衰减**与前文优化算法中的讨论一脉相承，它通过对大权重施加系统性惩罚，限制模型复杂度。在 SGD 下与 L2 正则化等价，而在自适应优化器下应使用解耦的 AdamW 实现，确保正则化强度独立于梯度统计特征。

**标签平滑** 作用于损失函数一侧，将 one-hot 形式的硬目标分布替换为软目标：
\[
q_i = \begin{cases}
1 - \varepsilon + \frac{\varepsilon}{K}, & i = y, \\
\frac{\varepsilon}{K}, & i \neq y,
\end{cases}
\]
其中 \(\varepsilon\) 为平滑系数，\(K\) 为类别总数。交叉熵损失变为 \(-\sum_i q_i \log p_i\)。这种软约束迫使模型不让正确类的 logit 远超其他类，从而降低输出置信度的极端化倾向，提升模型校准能力与泛化性能，并在知识蒸馏等场景中具有天然连接。

## 归一化技术

归一化层通过标准化中间激活的分布来加速训练并增强数值稳定性，三种常见变体在标准化维度与实现细节上存在关键差异。

**批归一化** 对小批量数据中每个特征通道独立归一化。对于维度为 \((B, D)\) 的小批量（\(B\) 为批量大小，\(D\) 为特征维数），计算每个特征维度上的均值 \(\mu_B\) 和方差 \(\sigma_B^2\)，再执行：
\[
\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \varepsilon}}, \quad y = \gamma \hat{x} + \beta,
\]
其中 \(\gamma, \beta\) 是可学习的缩放与平移参数。推理时使用训练阶段积累的全局均值与方差。批归一化允许较大学习率并带来微弱正则效果，但其有效性依赖足够大的批量，且在序列长度可变的循环网络中难以直接应用。

**层归一化** 转而在**单个样本的特征维度**上进行归一化。对每个样本 \(\mathbf{x} \in \mathbb{R}^D\)，计算其所有特征的均值 \(\mu\) 和方差 \(\sigma^2\)，再以相同的 \(\gamma, \beta\) 逐特征进行仿射变换。层归一化完全独立于批量大小，天然适用于 RNN 和 Transformer 等序列模型，成为目前预训练语言模型的主流归一化方案。

**RMSNorm** 是层归一化的简化版，仅使用均方根进行缩放而省略减去均值的步骤：
\[
\operatorname{RMS}(\mathbf{x}) = \sqrt{\mathbb{E}[x^2] + \varepsilon}, \quad y = \frac{x}{\operatorname{RMS}(\mathbf{x})} \cdot \gamma.
\]
去中心化操作在多数情况下并未带来明显增益，而省略均值计算可以降低计算量并提升稳定性。LLaMA 等大语言模型系列即采用 RMSNorm 作为归一化层。

## 残差连接

深度加深至数十甚至数百层时，网络出现退化问题：训练误差不降反升。残差连接的引入使得网络获得能够轻易近似恒等映射的能力，其基本形式为：
\[
\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x},
\]
其中 \(\mathcal{F}\) 为待学习的残差函数，\(\mathbf{x}\) 为恒等映射。若维度不匹配，则使用线性投影 \(\mathbf{W}_s \mathbf{x}\) 对齐。在梯度反向传播时，加法操作将梯度无损地传递给浅层，形成**恒等梯度高速通路**，极大缓解优化深层网络的难题。

残差连接与归一化层的相对位置衍生出两类范式，对训练稳定性影响迥异。**Post-Norm** 遵循原始 Transformer 结构，将归一化置于残差加法之后：
\[
\mathbf{y} = \operatorname{LayerNorm}(\mathbf{x} + \operatorname{Sublayer}(\mathbf{x})).
\]
此时网络输出的归一化使主路径上的梯度被 LayerNorm 的导数缩放，可能放大浅层梯度消失风险，训练初期需要谨慎的学习率预热。

**Pre-Norm** 则将归一化前置到子层之前：
\[
\mathbf{y} = \mathbf{x} + \operatorname{Sublayer}(\operatorname{LayerNorm}(\mathbf{x})).
\]
梯度可通过跳跃连接径直回传，子层的梯度仅起附加调整作用，因此训练更为稳定，对学习率调整的要求更低。当代大型 Transformer 多采用 Pre-Norm 设计，以换取更稳健的扩展性。

## 序列建模基础

诸多任务涉及顺序数据，神经网络需要建模序列内部的时间或位置依赖。从循环网络到编码器-解码器框架，构成了序列建模的基本脉络。

**RNN** 通过隐藏状态 \(\mathbf{h}_t\) 在时间步间共享参数，实现序列递推：
\[
\mathbf{h}_t = \tanh(\mathbf{W}_{hh} \mathbf{h}_{t-1} + \mathbf{W}_{xh} \mathbf{x}_t + \mathbf{b}),
\]
输出由 \(\mathbf{h}_t\) 映射得到。RNN 在时域展开后可沿时间步进行反向传播，但权重矩阵的连乘同样导致**长期依赖问题**：早期信号的梯度会指数级衰减或爆炸，难以捕获远距离的依赖关系。

**LSTM** 通过精巧的门控机制和细胞状态 \(\mathbf{c}_t\) 设计来缓解该问题：
\[
\begin{aligned}
\mathbf{f}_t &= \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f), \\
\mathbf{i}_t &= \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i), \\
\tilde{\mathbf{c}}_t &= \tanh(\mathbf{W}_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c), \\
\mathbf{c}_t &= \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t, \\
\mathbf{o}_t &= \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o), \\
\mathbf{h}_t &= \mathbf{o}_t \odot \tanh(\mathbf{c}_t).
\end{aligned}
\]
遗忘门 \(\mathbf{f}_t\)、输入门 \(\mathbf{i}_t\) 和输出门 \(\mathbf{o}_t\) 动态调节信息流，细胞状态 \(\mathbf{c}_t\) 以线性更新为主导，使梯度能跨越多步平滑传播，从而有效保留长期记忆。LSTM 长期是序列任务的默认基线。

**Seq2Seq** 模型采用编码器-解码器框架，将任意长度的输入序列映射为任意长度的输出序列。**编码器**将输入序列编码为一个上下文向量 \(\mathbf{c}\)（通常取最后时刻的隐藏状态），**解码器**则以 \(\mathbf{c}\) 为初始条件，自回归地生成目标序列。训练时采用教师强制策略，将正确目标作为下一时刻的输入，推理时则用上一步的预测作为输入。尽管基础的 Seq2Seq 受限于上下文向量的容量，注意力机制的引入后来彻底改变了序列转换的面貌，但编码器-解码器的分体结构仍是众多序列生成模型的原型。

以上各个主题交织成深度学习模型训练的核心知识网络，透彻理解它们各自的工作机理与相互影响，是构建并稳定训练现代深度模型的理论基石。
