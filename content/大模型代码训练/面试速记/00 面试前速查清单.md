这组笔记用于面试前快速回忆。每篇只保留**一句话原理 → 最小代码 → 易错点 → 口头回答**。题目是按基础模块和容易考察的张量操作选的，不是面试频次排名。

## 半小时怎么复习

| 时间 | 看什么 | 至少能脱口而出什么 |
|---|---|---|
| 5 分钟 | 原有 Transformer 分组的多头注意力 | `QKᵀ / √d`，沿 key 维 softmax，乘 V，再合并头 |
| 4 分钟 | 本分组的稳定 Softmax 与交叉熵 | 先减 max；CE 输入是 logits；下一 token 标签要错一位 |
| 4 分钟 | LayerNorm 与 RMSNorm | 最后一维归一化；LN 减均值，RMSNorm 不减 |
| 4 分钟 | RoPE | Q/K 成对旋转；缓存解码的位置不能从 0 重新开始 |
| 5 分钟 | KV Cache 与因果注意力 | K/V 沿序列维追加；单步 Q 长度 1；多 token 需要偏移 mask |
| 4 分钟 | Top-k、Top-p 与温度采样 | 温度改分布，k 限数量，p 限累计概率 |
| 4 分钟 | DPO 损失 | 两个回答的策略/参考 log 概率差，乘 beta，负 log-sigmoid |

## 上来先约定形状

- 隐藏状态：`[B, T, D]`，分别是 batch、序列长度、隐藏维度。
- 分头后的 Q/K/V：`[B, H, T, Dh]`，`D = H * Dh`。
- 注意力分数：`[B, H, Tq, Tk]`，softmax 在 `Tk` 维。
- 词表 logits：`[B, T, Vocab]`，归一化和采样在词表维。
- 写 `transpose` 时先说清楚它交换哪两维；合并头前记得换回 `[B, T, H, Dh]`。

## 看到这些题干就写这些操作

| 题干 | 核心操作 |
|---|---|
| 手写 Softmax / CE | `max → exp → sum`；CE 用 log-sum-exp |
| 手写归一化 | `mean(..., keepdim=True)` + `rsqrt` + 可学习缩放 |
| 手写 RoPE | `arange(0, Dh, 2)` + 位置外积 + 二维旋转 |
| 支持 KV Cache | `cat(..., dim=-2)` + 带历史长度的 causal mask |
| 手写采样 | temperature → top-k → top-p → softmax → multinomial |
| 手写 DPO | `(pi_w - pi_l) - (ref_w - ref_l)` → `-logsigmoid` |

## 提交代码前只检查五件事

1. softmax / 均值到底沿哪个维度？
2. 需要广播的地方有没有 `keepdim=True`？
3. mask 里 `True` 代表可见还是屏蔽？未来位置应填 `-inf`。
4. 位置、mask、临时张量是否和输入在同一 device？
5. 用一个小输入确认输出形状和关键边界即可；不用把面试代码写成工程框架。
