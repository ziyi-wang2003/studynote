面试官让你手撕自注意力（Self-Attention）核心代码时，通常考察的是 **缩放点积注意力（Scaled Dot-Product Attention）** 的实现，并可能扩展到 **多头注意力（Multi-Head Attention）**。下面给出一个清晰、可直接运行的 PyTorch 实现，并附上关键形状注释。

---

### 1. 核心：缩放点积注意力（带可选 Mask）

```python
import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    缩放点积注意力
    Q, K, V: [batch_size, num_heads, seq_len, d_k]
    mask:    [batch_size, 1, 1, seq_len] 或可广播的形状，True/1 表示需要屏蔽的位置
    """
    d_k = Q.size(-1)
    
    # 1. 计算注意力分数
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # 2. 可选 mask（将屏蔽位置填为极小值）
    if mask is not None:
        scores = scores.masked_fill(mask == 1, float('-inf'))
    
    # 3. Softmax 得到注意力权重
    attn_weights = F.softmax(scores, dim=-1)
    
    # 4. 加权求和
    output = torch.matmul(attn_weights, V)
    
    return output, attn_weights
```

**要点解释：**
- `scores = Q @ K^T / sqrt(d_k)` 是缩放步骤，防止点积过大导致 softmax 梯度消失。
- `masked_fill` 用于处理 padding 或因果遮罩（Decoder 自回归），将禁止关注的位置置为 `-inf`，softmax 后权重接近 0。
- 返回的 `attn_weights` 便于可视化调试。

### 2. 扩展：多头自注意力模块（完整 `nn.Module`）

```python
class MultiHeadSelfAttention(torch.nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # Q、K、V 的线性投影（合并为一个矩阵，效率更高）
        self.W_qkv = torch.nn.Linear(d_model, 3 * d_model)
        self.W_o   = torch.nn.Linear(d_model, d_model)
        self.dropout = torch.nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        """
        x:    [batch_size, seq_len, d_model]
        mask: [batch_size, seq_len] 或可广播形状，1 表示屏蔽位置
        """
        batch_size, seq_len, d_model = x.shape
        
        # 1. 线性投影并分割成 Q, K, V
        qkv = self.W_qkv(x)  # [batch, seq_len, 3 * d_model]
        qkv = qkv.reshape(batch_size, seq_len, 3, self.num_heads, self.d_k)
        qkv = qkv.permute(2, 0, 3, 1, 4)  # [3, batch, num_heads, seq_len, d_k]
        Q, K, V = qkv[0], qkv[1], qkv[2]  # 各自形状: [batch, num_heads, seq_len, d_k]
        
        # 2. 如有 mask，增加维度以匹配 heads
        if mask is not None:
            mask = mask.unsqueeze(1).unsqueeze(2)  # [batch, 1, 1, seq_len]
        
        # 3. 缩放点积注意力
        attn_output, attn_weights = scaled_dot_product_attention(Q, K, V, mask)
        
        # 4. 拼接多头并投影
        attn_output = attn_output.transpose(1, 2).contiguous().reshape(batch_size, seq_len, d_model)
        output = self.W_o(attn_output)
        
        return output, attn_weights
```

**说明：**
- 将 `d_model` 拆分成 `num_heads` 个头，每个头维度为 `d_k = d_model // num_heads`。
- 输入 `x` 同时作为 Q、K、V 的来源（自注意力），经过一个大的线性层再切分，减少计算和参数量。
- 最后通过 `W_o` 将拼接结果映射回原维度。
- 返回注意力权重可用于分析。

### 手撕时的注意事项

1. **形状控制**：面试官会特别在意张量 shape 的变化，写清每一步的注释。
2. **缩放因子**：必须除以 $\sqrt{d_k}$，这是 Transformer 成功的关键细节。
3. **Mask 处理**：通常有两种 —— 用于 Padding 的 mask（`mask == 1` 的位置屏蔽）和用于 Decoder 的下三角因果 mask（`torch.triu` 生成）。实现时统一对待，要求 mask 中 `1` 表示屏蔽位置。
4. **数值稳定性**：softmax 前用 `-inf` 填充屏蔽位置，这是标准做法。
5. **效率**：如果被追问优化，可以提 `einops` 或 `torch.baddbmm`，但初版代码保持清晰可读最重要。
