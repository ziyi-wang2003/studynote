面试官让你手撕自注意力（Self-Attention）核心代码时，通常考察的是 **缩放点积注意力（Scaled Dot-Product Attention）** 的实现，并可能扩展到 **多头注意力（Multi-Head Attention）**。下面给出一个清晰、可直接运行的 PyTorch 实现，并附上关键形状注释。

---

### 1. 缩放点积注意力（带可选 Mask）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class ScaledDotProductAttention(nn.Module):
    def __init__(self, dropout=0.0):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

    def forward(self, Q, K, V, mask=None):
        """
        Q, K, V: (batch, num_heads, seq_len, d_k)
        mask: (batch, 1, 1, seq_len) 或可广播形状，True/1 表示屏蔽位置
        """
        d_k = Q.size(-1)

        # 1. 计算注意力分数
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
        # scores: (batch, num_heads, seq_len, seq_len)

        # 2. 可选 mask
        if mask is not None:
            scores = scores.masked_fill(mask == 1, float('-inf'))

        # 3. softmax 得到注意力权重
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)

        # 4. 加权求和
        output = torch.matmul(attn_weights, V)
        # output: (batch, num_heads, seq_len, d_k)

        return output, attn_weights
```

### 2. 多头自注意力（独立定义 Q/K/V 投影）

```python
class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads

        # 独立定义 Q、K、V 三个线性投影
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

        self.dropout = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        """
        x:    (batch, seq_len, d_model)
        mask: (batch, seq_len) 或可广播形状，1 表示屏蔽位置
        """
        batch_size, seq_len, _ = x.shape

        # 1. 线性投影
        Q = self.W_q(x)  # (batch, seq_len, d_model)
        K = self.W_k(x)
        V = self.W_v(x)

        # 2. 切分多头: (batch, seq_len, d_model) → (batch, num_heads, seq_len, d_k)
        Q = Q.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)

        # 3. 处理 mask
        if mask is not None:
            mask = mask.unsqueeze(1).unsqueeze(2)  # (batch, 1, 1, seq_len)

        # 4. 缩放点积注意力
        d_k = Q.size(-1)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
        # scores: (batch, num_heads, seq_len, seq_len)

        if mask is not None:
            scores = scores.masked_fill(mask == 1, float('-inf'))

        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)

        attn_output = torch.matmul(attn_weights, V)
        # attn_output: (batch, num_heads, seq_len, d_k)

        # 5. 拼接多头: (batch, num_heads, seq_len, d_k) → (batch, seq_len, d_model)
        attn_output = attn_output.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model)

        # 6. 输出投影
        output = self.W_o(attn_output)

        return output, attn_weights


if __name__ == "__main__":
    batch, seq_len, d_model, num_heads = 2, 10, 64, 8
    x = torch.randn(batch, seq_len, d_model)

    mha = MultiHeadSelfAttention(d_model, num_heads)
    output, attn = mha(x)

    print(f"Output shape: {output.shape}")      # (2, 10, 64)
    print(f"Attention shape: {attn.shape}")      # (2, 8, 10, 10)

    # 因果 mask (decoder 自回归)
    causal_mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
    output_masked, _ = mha(x, mask=causal_mask)
    print(f"Masked output shape: {output_masked.shape}")
```

### 逐步形状变化

```
输入:  x → (batch, seq_len, d_model)       = (2, 10, 64)

1. 线性投影:
   Q = W_q(x) → (2, 10, 64)
   K = W_k(x) → (2, 10, 64)
   V = W_v(x) → (2, 10, 64)

2. 切分多头:
   Q → view(2, 10, 8, 8) → transpose(1,2) → (2, 8, 10, 8)
                                               B  h  S   d_k

3. 注意力计算:
   scores = Q @ K^T / sqrt(d_k) → (2, 8, 10, 10)
   attn = softmax(scores) → (2, 8, 10, 10)
   out = attn @ V → (2, 8, 10, 8)

4. 拼接多头:
   out → transpose(1,2) → (2, 10, 8, 8) → view → (2, 10, 64)
                                                    B  S   d_model

5. 输出映射:
   output = W_o(out) → (2, 10, 64)
```

### 手撕时的注意事项

1. **形状控制**：面试官会特别在意张量 shape 的变化，写清每一步的注释
2. **缩放因子**：必须除以 $\sqrt{d_k}$，这是 Transformer 成功的关键细节
3. **Mask 处理**：通常有两种 —— 用于 Padding 的 mask 和用于 Decoder 的下三角因果 mask（`torch.triu` 生成）。统一用 `1` 表示屏蔽位置
4. **数值稳定性**：softmax 前用 `-inf` 填充屏蔽位置，这是标准做法
5. **`contiguous()`**：`transpose` 后张量不连续，`view` 前必须调用 `contiguous()`
